## Цепочка 1: Brute Force → Account Lockout + Alert

### Сценарий атаки
Атакующий подбирает пароль к учётной записи через RDP, SMB или веб-форму. Генерируется множество неудачных попыток входа за короткое время с одного IP-адреса.

### Телеметрия (что генерирует атака)
- **Windows Event ID 4625** — неудачная попытка входа (Logon Type 3 — сетевой, 10 — RDP)
- **Windows Event ID 4740** — блокировка учётной записи
- **Sysmon Event ID 3** — сетевое подключение на порт 3389/445
- **Linux:** `/var/log/auth.log` — `Failed password for`
- **Сетевая сигнатура:** множественные TCP SYN на порт 3389/445/22 с одного IP

### Автоматизация: Python-скрипт детекции

```python
#!/usr/bin/env python3
"""
Обнаружение брутфорса в реальном времени.
Мониторит Windows Security Log (Event ID 4625).
Порог: 10 неудач с одного IP за 5 минут → алерт + блокировка.
"""

import subprocess
import json
import time
from collections import defaultdict
from datetime import datetime, timedelta

THRESHOLD = 10
WINDOW_SECONDS = 300
BLOCK_DURATION_HOURS = 1
LOG_FILE = "/var/log/bruteforce_detector.log"

attempts = defaultdict(list)
blocked_ips = {}


def log_event(message: str):
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    entry = f"[{timestamp}] {message}"
    print(entry)
    with open(LOG_FILE, "a") as f:
        f.write(entry + "\n")


def block_ip(ip: str):
    """Блокировка IP через iptables (Linux) или netsh (Windows)."""
    if ip in blocked_ips:
        return
    try:
        subprocess.run(
            ["iptables", "-A", "INPUT", "-s", ip, "-j", "DROP"],
            check=True, capture_output=True
        )
        blocked_ips[ip] = datetime.now()
        log_event(f"BLOCKED IP {ip} (brute force: {len(attempts[ip])} attempts)")
    except FileNotFoundError:
        # Windows: используем netsh
        subprocess.run(
            ["netsh", "advfirewall", "firewall", "add", "rule",
             f"name=BruteForceBlock_{ip}", "dir=in", "action=block",
             f"remoteip={ip}"],
            check=True, capture_output=True
        )
        blocked_ips[ip] = datetime.now()
        log_event(f"BLOCKED IP {ip} via Windows Firewall")


def unblock_expired():
    """Снять блокировку по истечении срока."""
    now = datetime.now()
    expired = [
        ip for ip, t in blocked_ips.items()
        if now - t > timedelta(hours=BLOCK_DURATION_HOURS)
    ]
    for ip in expired:
        try:
            subprocess.run(
                ["iptables", "-D", "INPUT", "-s", ip, "-j", "DROP"],
                check=True, capture_output=True
            )
        except FileNotFoundError:
            subprocess.run(
                ["netsh", "advfirewall", "firewall", "delete", "rule",
                 f"name=BruteForceBlock_{ip}"],
                capture_output=True
            )
        del blocked_ips[ip]
        log_event(f"UNBLOCKED IP {ip} (block expired)")


def check_failed_logins_linux():
    """Чтение /var/log/auth.log для SSH brute force."""
    import re
    pattern = re.compile(
        r"Failed password for .* from (\d+\.\d+\.\d+\.\d+)"
    )
    try:
        proc = subprocess.run(
            ["tail", "-n", "100", "/var/log/auth.log"],
            capture_output=True, text=True
        )
        for line in proc.stdout.splitlines():
            match = pattern.search(line)
            if match:
                ip = match.group(1)
                now = datetime.now()
                attempts[ip].append(now)
                # Очистить старые
                cutoff = now - timedelta(seconds=WINDOW_SECONDS)
                attempts[ip] = [t for t in attempts[ip] if t > cutoff]
                if len(attempts[ip]) >= THRESHOLD and ip not in blocked_ips:
                    log_event(
                        f"ALERT: Brute force detected from {ip} "
                        f"({len(attempts[ip])} failures in {WINDOW_SECONDS}s)"
                    )
                    block_ip(ip)
    except FileNotFoundError:
        pass


def main():
    log_event("Brute Force Detector started")
    log_event(f"Threshold: {THRESHOLD} failures / {WINDOW_SECONDS}s window")
    while True:
        check_failed_logins_linux()
        unblock_expired()
        time.sleep(5)


if __name__ == "__main__":
    main()
```

### Автоматизация: Bash-скрипт реагирования

```bash
#!/bin/bash
# brute_force_response.sh — автоблокировка IP при brute force (Linux)
# Запуск: ./brute_force_response.sh &

THRESHOLD=10
WINDOW=300   # секунд
LOGFILE="/var/log/auth.log"
BLOCKLIST="/var/log/blocked_bruteforce.txt"

touch "$BLOCKLIST"

echo "[$(date)] Brute Force Auto-Response запущен (порог: $THRESHOLD за ${WINDOW}с)"

tail -Fn0 "$LOGFILE" | while read -r line; do
    if echo "$line" | grep -q "Failed password"; then
        IP=$(echo "$line" | grep -oP 'from \K[\d.]+')
        [ -z "$IP" ] && continue

        # Считаем попытки за окно
        COUNT=$(grep "Failed password.*from $IP" "$LOGFILE" \
            | tail -n "$THRESHOLD" \
            | awk -v window="$WINDOW" '
                BEGIN { count=0 }
                {
                    cmd = "date -d\""$1" "$2" "$3"\" +%s 2>/dev/null"
                    cmd | getline ts; close(cmd)
                    if (systime() - ts < window) count++
                }
                END { print count }
            ')

        if [ "$COUNT" -ge "$THRESHOLD" ]; then
            if ! grep -q "^$IP$" "$BLOCKLIST"; then
                echo "$IP" >> "$BLOCKLIST"
                iptables -A INPUT -s "$IP" -j DROP
                echo "[$(date)] BLOCKED $IP ($COUNT failed attempts in ${WINDOW}s)"
                logger -t bruteforce "BLOCKED $IP after $COUNT failed login attempts"
            fi
        fi
    fi
done
```

## Цепочка 2: Port Scan → IDS Alert + Firewall Block

### Сценарий атаки
Атакующий проводит сканирование портов (Nmap SYN scan, connect scan или UDP scan) для обнаружения открытых сервисов на целевой сети.

### Телеметрия (что генерирует атака)
- **Сетевая сигнатура:** множественные TCP SYN без завершения handshake (SYN scan), подключения к >20 портам за секунды
- **Firewall log:** множественные DROP на закрытых портах
- **Suricata/Snort:** ET SCAN alerts
- **Sysmon Event ID 3** — множественные исходящие соединения (если скан изнутри)
- **Linux:** `/var/log/kern.log` — iptables DROP записи

### Автоматизация: Python-скрипт детекции

```python
#!/usr/bin/env python3
"""
Обнаружение сканирования портов через анализ netflow / iptables log.
Порог: подключения к 20+ уникальным портам с одного IP за 60 секунд.
"""

import re
import time
import subprocess
from collections import defaultdict
from datetime import datetime, timedelta

THRESHOLD_PORTS = 20
WINDOW_SECONDS = 60
IPTABLES_LOG = "/var/log/kern.log"

connections = defaultdict(lambda: {"ports": set(), "first_seen": None})


def parse_iptables_log():
    """Извлечение данных из лога iptables (ядро)."""
    pattern = re.compile(
        r"SRC=(\d+\.\d+\.\d+\.\d+).*DPT=(\d+)"
    )
    proc = subprocess.run(
        ["tail", "-n", "500", IPTABLES_LOG],
        capture_output=True, text=True
    )
    now = datetime.now()
    cutoff = now - timedelta(seconds=WINDOW_SECONDS)

    for line in proc.stdout.splitlines():
        match = pattern.search(line)
        if match:
            src_ip = match.group(1)
            dst_port = int(match.group(2))
            entry = connections[src_ip]
            if entry["first_seen"] is None or entry["first_seen"] < cutoff:
                entry["ports"] = set()
                entry["first_seen"] = now
            entry["ports"].add(dst_port)


def detect_scans():
    """Проверить, превысил ли кто-то порог."""
    alerts = []
    for ip, data in connections.items():
        if len(data["ports"]) >= THRESHOLD_PORTS:
            alerts.append({
                "ip": ip,
                "unique_ports": len(data["ports"]),
                "sample_ports": sorted(list(data["ports"]))[:10],
            })
    return alerts


def block_scanner(ip: str):
    """Автоматическая блокировка сканера."""
    subprocess.run(
        ["iptables", "-I", "INPUT", "1", "-s", ip, "-j", "DROP"],
        check=True, capture_output=True
    )
    print(f"[{datetime.now()}] BLOCKED scanner: {ip}")


def main():
    print(f"Port Scan Detector: threshold={THRESHOLD_PORTS} ports / {WINDOW_SECONDS}s")
    while True:
        parse_iptables_log()
        alerts = detect_scans()
        for alert in alerts:
            print(
                f"[ALERT] Port scan from {alert['ip']}: "
                f"{alert['unique_ports']} unique ports. "
                f"Sample: {alert['sample_ports']}"
            )
            block_scanner(alert["ip"])
            connections[alert["ip"]]["ports"] = set()
        time.sleep(5)


if __name__ == "__main__":
    main()
```

### Автоматизация: Bash-скрипт реагирования

```bash
#!/bin/bash
# port_scan_blocker.sh — блокировка сканеров на основе iptables LOG
# Требуется правило: iptables -A INPUT -j LOG --log-prefix "IPT_DROP:"

THRESHOLD=25   # уникальных портов
WINDOW=60      # секунд
LOGFILE="/var/log/kern.log"

echo "[$(date)] Port Scan Blocker запущен (порог: $THRESHOLD портов за ${WINDOW}с)"

while true; do
    # Находим IP с > THRESHOLD уникальных портов за окно
    SCANNERS=$(grep "IPT_DROP:" "$LOGFILE" \
        | awk -v cutoff="$(date -d "-${WINDOW} seconds" +%s 2>/dev/null || echo 0)" '
        {
            match($0, /SRC=([0-9.]+)/, src)
            match($0, /DPT=([0-9]+)/, dpt)
            if (src[1] && dpt[1]) {
                key = src[1] "|" dpt[1]
                if (!seen[key]++) {
                    count[src[1]]++
                }
            }
        }
        END {
            for (ip in count)
                if (count[ip] >= '"$THRESHOLD"')
                    print ip, count[ip]
        }')

    if [ -n "$SCANNERS" ]; then
        echo "$SCANNERS" | while read -r IP COUNT; do
            if ! iptables -C INPUT -s "$IP" -j DROP 2>/dev/null; then
                iptables -I INPUT 1 -s "$IP" -j DROP
                echo "[$(date)] BLOCKED scanner $IP ($COUNT unique ports)"
                logger -t portscan "BLOCKED $IP: $COUNT unique ports in ${WINDOW}s"
            fi
        done
    fi
    sleep 10
done
```

## Цепочка 3: Phishing Email → Sandbox + User Alert

### Сценарий атаки

### Автоматизация: Python-скрипт анализа email-заголовков

```python
#!/usr/bin/env python3
"""
Анализ email-заголовков на признаки фишинга.
Проверяет: SPF, DKIM, подозрительные URL, typosquatting, свежие домены.
"""

import re
import email
import sys
from email import policy
from urllib.parse import urlparse
from datetime import datetime


TRUSTED_DOMAINS = {"company.ru", "company.com", "mail.company.ru"}
SUSPICIOUS_TLDS = {".xyz", ".top", ".click", ".work", ".buzz", ".icu", ".tk", ".ml"}
KNOWN_PHISHING_KEYWORDS = [
    "срочно", "заблокирован", "подтвердите", "verify", "urgent",
    "account suspended", "пароль истекает", "invoice", "payment"
]


def analyze_headers(msg: email.message.EmailMessage) -> list:
    """Анализ заголовков письма."""
    findings = []

    # SPF
    spf = msg.get("Received-SPF", "") or msg.get("Authentication-Results", "")
    if "fail" in spf.lower() or "softfail" in spf.lower():
        findings.append(("HIGH", "SPF FAIL — домен отправителя не подтверждён"))

    # DKIM
    auth_results = msg.get("Authentication-Results", "")
    if "dkim=fail" in auth_results.lower():
        findings.append(("HIGH", "DKIM FAIL — подпись письма невалидна"))

    # Reply-To не совпадает с From
    from_addr = msg.get("From", "")
    reply_to = msg.get("Reply-To", "")
    if reply_to and reply_to != from_addr:
        from_domain = re.search(r"@([\w.-]+)", from_addr)
        reply_domain = re.search(r"@([\w.-]+)", reply_to)
        if from_domain and reply_domain and from_domain.group(1) != reply_domain.group(1):
            findings.append(("MEDIUM", f"Reply-To домен отличается: {reply_to} vs {from_addr}"))

    # Подозрительная тема
    subject = msg.get("Subject", "")
    for keyword in KNOWN_PHISHING_KEYWORDS:
        if keyword.lower() in subject.lower():
            findings.append(("MEDIUM", f"Подозрительное ключевое слово в теме: '{keyword}'"))
            break

    return findings


def analyze_urls(body: str) -> list:
    """Поиск подозрительных URL в теле письма."""
    findings = []
    urls = re.findall(r'https?://[^\s<>"\']+', body)

    for url in urls:
        parsed = urlparse(url)
        domain = parsed.hostname or ""

        # Подозрительные TLD
        for tld in SUSPICIOUS_TLDS:
            if domain.endswith(tld):
                findings.append(("HIGH", f"Подозрительный TLD в URL: {url}"))

        # URL-shorteners
        if any(s in domain for s in ["bit.ly", "tinyurl", "t.co", "rb.gy", "clck.ru"]):
            findings.append(("MEDIUM", f"Сокращённая ссылка (redirect): {url}"))

        # IP вместо домена
        if re.match(r'\d+\.\d+\.\d+\.\d+', domain):
            findings.append(("HIGH", f"URL с IP-адресом вместо домена: {url}"))

        # Подозрительный путь
        if any(p in parsed.path.lower() for p in ["/login", "/signin", "/verify", "/secure"]):
            if domain not in TRUSTED_DOMAINS:
                findings.append(("HIGH", f"Фишинговый URL (login на чужом домене): {url}"))

    return findings


def analyze_attachments(msg: email.message.EmailMessage) -> list:
    """Проверка вложений."""
    findings = []
    dangerous_ext = {".exe", ".scr", ".bat", ".cmd", ".hta", ".vbs", ".js",
                     ".lnk", ".pif", ".wsf", ".ps1"}
    macro_ext = {".docm", ".xlsm", ".pptm", ".dotm"}

    for part in msg.walk():
        filename = part.get_filename()
        if filename:
            ext = "." + filename.rsplit(".", 1)[-1].lower() if "." in filename else ""
            if ext in dangerous_ext:
                findings.append(("CRITICAL", f"Опасное вложение: {filename}"))
            elif ext in macro_ext:
                findings.append(("HIGH", f"Вложение с макросами: {filename}"))
            elif ext == ".zip" and part.get("Content-Type", "").find("password") != -1:
                findings.append(("HIGH", f"Запароленный ZIP (обход антивируса): {filename}"))

    return findings


def main():
    if len(sys.argv) < 2:
        print("Использование: python3 phishing_analyzer.py <email_file.eml>")
        sys.exit(1)

    with open(sys.argv[1], "rb") as f:
        msg = email.message_from_binary_file(f, policy=policy.default)

    print(f"{'='*60}")
    print(f"  АНАЛИЗ ФИШИНГА: {msg.get('Subject', 'N/A')}")
    print(f"  From: {msg.get('From', 'N/A')}")
    print(f"  Date: {msg.get('Date', 'N/A')}")
    print(f"{'='*60}\n")

    all_findings = []
    all_findings.extend(analyze_headers(msg))

    body = msg.get_body(preferencelist=("plain", "html"))
    if body:
        body_text = body.get_content()
        all_findings.extend(analyze_urls(body_text))

    all_findings.extend(analyze_attachments(msg))

    if not all_findings:
        print("[OK] Признаков фишинга не обнаружено")
    else:
        for severity, detail in sorted(all_findings, key=lambda x: x[0]):
            print(f"  [{severity}] {detail}")

    score = sum(1 for s, _ in all_findings if s == "CRITICAL") * 4 + \
            sum(1 for s, _ in all_findings if s == "HIGH") * 2 + \
            sum(1 for s, _ in all_findings if s == "MEDIUM")
    print(f"\nРиск-скор: {score}/20")
    if score >= 6:
        print(">>> ВЕРДИКТ: ФИШИНГ — отправить в карантин")
    elif score >= 3:
        print(">>> ВЕРДИКТ: ПОДОЗРИТЕЛЬНО — ручная проверка")
    else:
        print(">>> ВЕРДИКТ: вероятно легитимно")


if __name__ == "__main__":
    main()
```

### Автоматизация: Python-скрипт обнаружения beaconing

```python
#!/usr/bin/env python3
"""
Обнаружение C2 beaconing по регулярности интервалов подключений.
Анализирует Zeek conn.log или netflow-данные.
"""

import re
import math
from collections import defaultdict
from datetime import datetime


def parse_zeek_conn_log(filepath: str) -> dict:
    """Парсинг Zeek conn.log, группировка по src_ip → dst_ip:port."""
    flows = defaultdict(list)
    with open(filepath) as f:
        for line in f:
            if line.startswith("#"):
                continue
            fields = line.strip().split("\t")
            if len(fields) < 8:
                continue
            ts = float(fields[0])
            src_ip = fields[2]
            dst_ip = fields[4]
            dst_port = fields[5]
            key = f"{src_ip} -> {dst_ip}:{dst_port}"
            flows[key].append(ts)
    return flows


def detect_beaconing(flows: dict, min_connections: int = 10,
                     max_jitter_pct: float = 15.0) -> list:
    """
    Обнаружение beaconing: регулярные интервалы между подключениями.
    Beacon = стандартное отклонение интервалов < max_jitter_pct% от среднего.
    """
    beacons = []
    for key, timestamps in flows.items():
        if len(timestamps) < min_connections:
            continue
        timestamps.sort()
        intervals = [
            timestamps[i+1] - timestamps[i]
            for i in range(len(timestamps) - 1)
        ]
        if not intervals:
            continue
        mean_interval = sum(intervals) / len(intervals)
        if mean_interval == 0:
            continue
        variance = sum((x - mean_interval) ** 2 for x in intervals) / len(intervals)
        std_dev = math.sqrt(variance)
        jitter_pct = (std_dev / mean_interval) * 100

        if jitter_pct < max_jitter_pct:
            beacons.append({
                "flow": key,
                "connections": len(timestamps),
                "mean_interval_sec": round(mean_interval, 1),
                "jitter_pct": round(jitter_pct, 1),
                "duration_min": round((timestamps[-1] - timestamps[0]) / 60, 1),
            })
    return sorted(beacons, key=lambda x: x["jitter_pct"])


def main():
    import sys
    if len(sys.argv) < 2:
        print("Использование: python3 beacon_detector.py <conn.log>")
        print("\nПример с тестовыми данными:")

        # Тестовые данные: регулярный beacon каждые ~60с
        test_flows = {
            "192.168.1.100 -> 45.33.32.156:443": [
                1000, 1060, 1121, 1180, 1242, 1300, 1361, 1420, 1481, 1540, 1601
            ],
            "192.168.1.100 -> 8.8.8.8:53": [
                1000, 1005, 1100, 1500, 1501, 2000, 2100, 2200, 2205, 2210, 2500
            ],
        }
        beacons = detect_beaconing(test_flows)
        for b in beacons:
            print(f"  [BEACON] {b['flow']}")
            print(f"    Подключений: {b['connections']}")
            print(f"    Интервал: {b['mean_interval_sec']}с ± {b['jitter_pct']}%")
            print(f"    Длительность: {b['duration_min']} мин")
        return

    flows = parse_zeek_conn_log(sys.argv[1])
    beacons = detect_beaconing(flows)

    if not beacons:
        print("[OK] Beaconing не обнаружен")
    else:
        print(f"[ALERT] Обнаружено {len(beacons)} подозрительных beacon-потоков:\n")
        for b in beacons:
            print(f"  {b['flow']}")
            print(f"    Подключений: {b['connections']}, интервал: {b['mean_interval_sec']}с, jitter: {b['jitter_pct']}%\n")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""
Обнаружение Pass-the-Hash: NTLM Type 3 логоны
от непривычных пар (user, source_host).
"""

import json
from collections import defaultdict
from datetime import datetime

# Базовая линия: известные пары user → [хосты откуда входит]
BASELINE = {
    "admin": {"WORKSTATION1", "WORKSTATION2"},
    "svc_backup": {"BACKUP-SRV"},
}

ALERT_LOG = "/var/log/pth_detector.log"


def is_anomalous(username: str, source_host: str) -> bool:
    """Проверить, входит ли пользователь с непривычного хоста."""
    known_hosts = BASELINE.get(username.lower(), set())
    if not known_hosts:
        return True  # неизвестный пользователь
    return source_host.upper() not in {h.upper() for h in known_hosts}


def analyze_logon_event(event: dict) -> dict | None:
    """Анализ события 4624 на признаки PtH."""
    logon_type = event.get("LogonType")
    auth_package = event.get("AuthenticationPackageName", "")
    username = event.get("TargetUserName", "")
    source_ip = event.get("IpAddress", "")
    source_host = event.get("WorkstationName", "")

    if logon_type != 3:
        return None
    if "NTLM" not in auth_package:
        return None
    if username.endswith("$"):
        return None  # machine account

    if is_anomalous(username, source_host):
        return {
            "alert": "PASS-THE-HASH suspected",
            "user": username,
            "source_ip": source_ip,
            "source_host": source_host,
            "auth": auth_package,
            "timestamp": datetime.now().isoformat(),
            "action": "DISABLE_ACCOUNT + ISOLATE_SOURCE"
        }
    return None


def respond_to_pth(alert: dict):
    """Автоматическое реагирование на PtH."""
    import subprocess
    user = alert["user"]
    source_ip = alert["source_ip"]

    print(f"[CRITICAL] {alert['alert']}: {user} from {source_ip}")

    # Отключить учётную запись
    try:
        subprocess.run(
            ["net", "user", user, "/active:no", "/domain"],
            capture_output=True, timeout=10
        )
        print(f"  [ACTION] Account {user} disabled")
    except Exception as e:
        print(f"  [ERROR] Cannot disable account: {e}")

    # Заблокировать IP источника
    try:
        subprocess.run(
            ["netsh", "advfirewall", "firewall", "add", "rule",
             f"name=PtH_Block_{source_ip}", "dir=in", "action=block",
             f"remoteip={source_ip}"],
            capture_output=True, timeout=10
        )
        print(f"  [ACTION] Source IP {source_ip} blocked")
    except Exception as e:
        print(f"  [ERROR] Cannot block IP: {e}")


def main():
    # Тестовые события
    events = [
        {"LogonType": 3, "AuthenticationPackageName": "NTLM",
         "TargetUserName": "admin", "IpAddress": "10.0.0.50",
         "WorkstationName": "UNKNOWN-PC"},
        {"LogonType": 3, "AuthenticationPackageName": "Kerberos",
         "TargetUserName": "admin", "IpAddress": "10.0.0.10",
         "WorkstationName": "WORKSTATION1"},
        {"LogonType": 3, "AuthenticationPackageName": "NTLM",
         "TargetUserName": "admin", "IpAddress": "10.0.0.10",
         "WorkstationName": "WORKSTATION1"},
    ]

    for event in events:
        result = analyze_logon_event(event)
        if result:
            respond_to_pth(result)
        else:
            user = event.get("TargetUserName", "N/A")
            print(f"[OK] Легитимный вход: {user} via {event.get('AuthenticationPackageName')}")


if __name__ == "__main__":
    main()
```

"""
Ransomware Canary Monitor.
Создаёт файлы-приманки в ключевых директориях.
При их модификации — немедленный алерт и изоляция.
"""

import os
import hashlib
import time
import subprocess
from pathlib import Path
from datetime import datetime

CANARY_DIRS = [
    "/srv/share",
    "/home",
    "/var/data",
    "C:\\Users\\Public\\Documents",
    "C:\\Shares",
]

CANARY_NAMES = [
    "~$budget_2026.xlsx",
    "~$project_plan.docx",
    "~$financial_report.pdf",
    "~$passwords.txt",
    "~$employee_list.csv",
]

CANARY_CONTENT = "CANARY FILE — DO NOT MODIFY — SECURITY MONITORING ACTIVE"
LOG_FILE = "/var/log/ransomware_canary.log"


def log_event(msg: str):
    ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    line = f"[{ts}] {msg}"
    print(line)
    with open(LOG_FILE, "a") as f:
        f.write(line + "\n")


def deploy_canaries() -> dict:
    """Расставить файлы-приманки и запомнить хэши."""
    canaries = {}
    for directory in CANARY_DIRS:
        if not os.path.isdir(directory):
            continue
        for name in CANARY_NAMES:
            filepath = os.path.join(directory, name)
            try:
                with open(filepath, "w") as f:
                    f.write(CANARY_CONTENT)
                file_hash = hashlib.sha256(CANARY_CONTENT.encode()).hexdigest()
                canaries[filepath] = {
                    "hash": file_hash,
                    "size": len(CANARY_CONTENT),
                    "mtime": os.path.getmtime(filepath),
                }
                log_event(f"Canary deployed: {filepath}")
            except PermissionError:
                pass
    return canaries


def check_canaries(canaries: dict) -> list:
    """Проверить целостность файлов-приманок."""
    alerts = []
    for filepath, expected in canaries.items():
        if not os.path.exists(filepath):
            alerts.append(("DELETED", filepath))
            continue
        try:
            with open(filepath, "r") as f:
                content = f.read()
            current_hash = hashlib.sha256(content.encode()).hexdigest()
            if current_hash != expected["hash"]:
                alerts.append(("MODIFIED", filepath))
            elif os.path.getmtime(filepath) != expected["mtime"]:
                alerts.append(("TOUCHED", filepath))
        except Exception:
            alerts.append(("UNREADABLE", filepath))
    return alerts


def emergency_response():
    """Экстренное реагирование при обнаружении ransomware."""
    log_event("!!! RANSOMWARE DETECTED — EMERGENCY RESPONSE !!!")

        pass

        subprocess.run(
            ["iptables", "-A", "INPUT", "-p", "tcp", "--dport", "445", "-j", "DROP"],
            capture_output=True, timeout=5
        )
        log_event("[ACTION] SMB port 445 blocked")
    except Exception:
        pass

    # 3. Отправить алерт
    log_event("[ACTION] Alert sent — isolate ALL file servers NOW")


def main():
    log_event("Ransomware Canary Monitor started")
    canaries = deploy_canaries()
    log_event(f"Deployed {len(canaries)} canary files")

    while True:
        alerts = check_canaries(canaries)
        if alerts:
            for alert_type, filepath in alerts:
                log_event(f"[ALERT] Canary {alert_type}: {filepath}")
            emergency_response()
            break  # после экстренного реагирования — ручной контроль

### Автоматизация: Python — анализ DNS на tunneling

```python
#!/usr/bin/env python3
"""
Обнаружение DNS Tunneling по энтропии поддоменов и частоте запросов.
Анализирует Zeek dns.log или pcap.
"""

import math
import re
from collections import defaultdict


def entropy(s: str) -> float:
    """Информационная энтропия строки (Shannon)."""
    if not s:
        return 0.0
    freq = defaultdict(int)
    for c in s:
        freq[c] += 1
    length = len(s)
    return -sum(
        (count / length) * math.log2(count / length)
        for count in freq.values()
    )


def analyze_dns_log(filepath: str) -> list:
    """Анализ Zeek dns.log на признаки tunneling."""
    domain_stats = defaultdict(lambda: {
        "count": 0, "total_subdomain_len": 0,
        "unique_subdomains": set(), "txt_count": 0,
        "max_subdomain_entropy": 0.0,
    })

    with open(filepath) as f:
        for line in f:
            if line.startswith("#"):
                continue
            fields = line.strip().split("\t")
            if len(fields) < 10:
                continue
            query = fields[9] if len(fields) > 9 else ""
            qtype = fields[13] if len(fields) > 13 else ""

            parts = query.split(".")
            if len(parts) < 3:
                continue

            # Базовый домен = последние 2 части
            base_domain = ".".join(parts[-2:])
            subdomain = ".".join(parts[:-2])

            stats = domain_stats[base_domain]
            stats["count"] += 1
            stats["total_subdomain_len"] += len(subdomain)
            stats["unique_subdomains"].add(subdomain)
            if qtype in ("TXT", "16"):
                stats["txt_count"] += 1

            ent = entropy(subdomain)
            if ent > stats["max_subdomain_entropy"]:
                stats["max_subdomain_entropy"] = ent

    # Детекция
    alerts = []
    for domain, stats in domain_stats.items():
        score = 0
        reasons = []

        avg_sub_len = stats["total_subdomain_len"] / max(stats["count"], 1)
        if avg_sub_len > 30:
            score += 3
            reasons.append(f"длинные поддомены (avg {avg_sub_len:.0f} символов)")

        if stats["max_subdomain_entropy"] > 3.5:
            score += 3
            reasons.append(f"высокая энтропия ({stats['max_subdomain_entropy']:.2f})")

        unique_ratio = len(stats["unique_subdomains"]) / max(stats["count"], 1)
        if unique_ratio > 0.9 and stats["count"] > 20:
            score += 2
            reasons.append(f"уникальность запросов {unique_ratio:.0%}")

        if stats["txt_count"] > 10:
            score += 2
            reasons.append(f"TXT-запросов: {stats['txt_count']}")

        if stats["count"] > 100:
            score += 1
            reasons.append(f"частота: {stats['count']} запросов")

        if score >= 5:
            alerts.append({
                "domain": domain,
                "score": score,
                "requests": stats["count"],
                "unique_subdomains": len(stats["unique_subdomains"]),
                "reasons": reasons,
            })

    return sorted(alerts, key=lambda x: x["score"], reverse=True)


def main():
    import sys
    if len(sys.argv) < 2:
        # Демо с тестовыми данными
        print("DNS Tunnel Detector v1.0\n")
        print("Демо: анализ тестовых DNS-запросов\n")

        test_queries = [
            ("AAAARQZ3Rva2VuLWRhdGEtaGVyZS1pcw.tunnel.evil.com", "TXT"),
            ("bWFsd2FyZS1leGZpbHRyYXRpb24tZGF0YQ.tunnel.evil.com", "A"),
            ("dGhpcy1pcy1hLXRlc3QtcGF5bG9hZA.tunnel.evil.com", "TXT"),
            ("www.google.com", "A"),
            ("mail.company.ru", "MX"),
        ]

        for query, qtype in test_queries:
            parts = query.split(".")
            if len(parts) >= 3:
                subdomain = ".".join(parts[:-2])
                ent = entropy(subdomain)
                suspicious = ent > 3.5 or len(subdomain) > 30
                status = "SUSPICIOUS" if suspicious else "OK"
                print(f"  [{status}] {query}")
                print(f"    Subdomain len: {len(subdomain)}, entropy: {ent:.2f}")
        return

    alerts = analyze_dns_log(sys.argv[1])
    if not alerts:
        print("[OK] DNS tunneling не обнаружен")
    else:
        for a in alerts:
            print(f"[ALERT] DNS Tunnel: {a['domain']} (score: {a['score']})")
            print(f"  Запросов: {a['requests']}, уникальных: {a['unique_subdomains']}")
            for r in a["reasons"]:
                print(f"  → {r}")


if __name__ == "__main__":
    main()
```

#!/usr/bin/env python3
"""
Мониторинг подозрительного присвоения привилегий.
Алерт при SeDebugPrivilege / SeImpersonatePrivilege у обычных пользователей.
"""

DANGEROUS_PRIVS = {
    "SeDebugPrivilege": "Доступ к чужим процессам (credential dumping)",
    "SeImpersonatePrivilege": "Имперсонация других пользователей (potato attacks)",
    "SeAssignPrimaryTokenPrivilege": "Назначение токенов процессам",
    "SeTcbPrivilege": "Действие от имени ОС",
    "SeLoadDriverPrivilege": "Загрузка драйверов ядра",
    "SeRestorePrivilege": "Восстановление файлов (обход ACL)",
    "SeTakeOwnershipPrivilege": "Захват владения объектами",
}

SYSTEM_ACCOUNTS = {"SYSTEM", "LOCAL SERVICE", "NETWORK SERVICE"}
ADMIN_ACCOUNTS = {"Administrator", "admin"}  # легитимные админы


def analyze_event_4672(event: dict) -> dict | None:
    user = event.get("SubjectUserName", "")
    privs = event.get("PrivilegeList", "")

    if user.upper() in {a.upper() for a in SYSTEM_ACCOUNTS}:
        return None

    dangerous_found = []
    for priv, desc in DANGEROUS_PRIVS.items():
        if priv in privs:
            dangerous_found.append((priv, desc))

    if not dangerous_found:
        return None

    is_admin = user in ADMIN_ACCOUNTS
    severity = "MEDIUM" if is_admin else "HIGH"

    return {
        "severity": severity,
        "user": user,
        "privileges": dangerous_found,
        "message": f"Привилегии {[p for p, _ in dangerous_found]} у {'админа' if is_admin else 'обычного пользователя'} {user}"
    }


def main():
    test_events = [
        {"SubjectUserName": "SYSTEM", "PrivilegeList": "SeDebugPrivilege"},
        {"SubjectUserName": "john.doe", "PrivilegeList": "SeDebugPrivilege SeImpersonatePrivilege"},
        {"SubjectUserName": "Administrator", "PrivilegeList": "SeDebugPrivilege"},
        {"SubjectUserName": "svc_web", "PrivilegeList": "SeImpersonatePrivilege"},
    ]

    for event in test_events:
        result = analyze_event_4672(event)
        if result:
            print(f"[{result['severity']}] {result['message']}")
            for priv, desc in result["privileges"]:
                print(f"  → {priv}: {desc}")
        else:
            print(f"[OK] {event['SubjectUserName']}: системная учётка, пропуск")


if __name__ == "__main__":
    main()

### Python: автоматическое удаление подозрительных записей

```python
#!/usr/bin/env python3
"""
Мониторинг и автоматическое удаление подозрительных записей
в Registry Run Keys (Windows).
"""

import subprocess
import re
from datetime import datetime

RUN_KEYS = [
    r"HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run",
    r"HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce",
    r"HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run",
    r"HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce",
]

WHITELIST = {
    "SecurityHealth",
    "WindowsDefender",
    "OneDrive",
    "Teams",
    "Outlook",
}

LOG_FILE = "C:\\Logs\\registry_monitor.log"


def log_event(msg: str):
    ts = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    line = f"[{ts}] {msg}"
    print(line)
    try:
        with open(LOG_FILE, "a") as f:
            f.write(line + "\n")
    except Exception:
        pass


def get_run_key_values(key_path: str) -> dict:
    """Получить все значения из ключа реестра."""
    values = {}
    try:
        result = subprocess.run(
            ["reg", "query", key_path],
            capture_output=True, text=True, timeout=5
        )
        for line in result.stdout.splitlines():
            match = re.match(r'\s+(\S+)\s+REG_\w+\s+(.+)', line)
            if match:
                name = match.group(1)
                data = match.group(2).strip()
                values[name] = data
    except Exception:
        pass
    return values


def is_suspicious(name: str, value: str) -> tuple[bool, str]:
    """Проверить, подозрительна ли запись автозапуска."""
    if name in WHITELIST:
        return False, ""

    reasons = []
    val_lower = value.lower()

    # Подозрительные пути
    if any(p in val_lower for p in [r"\temp\\", r"\tmp\\", r"\appdata\local\temp",
                                      "users\\public", r"\programdata\\"]):
        reasons.append("Запуск из временной/подозрительной директории")

    # Подозрительные расширения
    if any(val_lower.endswith(e) for e in [".vbs", ".js", ".hta", ".bat", ".ps1", ".scr"]):
        reasons.append(f"Подозрительное расширение файла")

    # PowerShell с аргументами
    if "powershell" in val_lower and any(a in val_lower for a in ["-enc", "-hidden", "bypass"]):
        reasons.append("PowerShell с подозрительными аргументами")

    # Rundll32 / regsvr32 / mshta
    if any(t in val_lower for t in ["rundll32", "regsvr32", "mshta", "wscript", "cscript"]):
        reasons.append("Использование LOLBin для запуска")

    return (len(reasons) > 0, "; ".join(reasons))


def remove_value(key_path: str, name: str):
    """Удалить значение из реестра."""
    try:
        subprocess.run(
            ["reg", "delete", key_path, "/v", name, "/f"],
            capture_output=True, timeout=5
        )
        log_event(f"[ACTION] Removed: {key_path}\\{name}")
    except Exception as e:
        log_event(f"[ERROR] Cannot remove {key_path}\\{name}: {e}")


def scan():
    """Просканировать все Run Keys."""
    for key in RUN_KEYS:
        values = get_run_key_values(key)
        for name, data in values.items():
            suspicious, reason = is_suspicious(name, data)
            if suspicious:
                log_event(f"[ALERT] Suspicious autorun: {key}\\{name} = {data}")
                log_event(f"  Причина: {reason}")
                remove_value(key, name)
            else:
                log_event(f"[OK] {name}: {data[:50]}...")


def main():
    log_event("Registry Persistence Monitor started")
    scan()


if __name__ == "__main__":
    main()
```

### Автоматизация: Python — анализ дерева процессов

```python
#!/usr/bin/env python3
"""
Анализ дерева процессов: обнаружение необычных parent-child связей.
Работает с psutil (кросс-платформенно).
"""

import psutil
from datetime import datetime

SUSPICIOUS_TREES = [
    {"parent": "winword.exe", "children": {"cmd.exe", "powershell.exe", "wscript.exe", "mshta.exe"}},
    {"parent": "excel.exe", "children": {"cmd.exe", "powershell.exe", "wscript.exe"}},
    {"parent": "outlook.exe", "children": {"cmd.exe", "powershell.exe", "mshta.exe"}},
    {"parent": "wmiprvse.exe", "children": {"cmd.exe", "powershell.exe"}},
    {"parent": "svchost.exe", "children": {"cmd.exe", "powershell.exe"}},
    {"parent": "mshta.exe", "children": {"cmd.exe", "powershell.exe", "cscript.exe"}},
    {"parent": "wscript.exe", "children": {"cmd.exe", "powershell.exe"}},
]


def scan_process_tree():
    """Сканировать все процессы на подозрительные parent-child связи."""
    alerts = []
    for proc in psutil.process_iter(['pid', 'name', 'ppid', 'cmdline', 'username']):
        try:
            pinfo = proc.info
            child_name = (pinfo['name'] or '').lower()
            parent = psutil.Process(pinfo['ppid'])
            parent_name = (parent.name() or '').lower()

            for rule in SUSPICIOUS_TREES:
                if parent_name == rule["parent"] and child_name in rule["children"]:
                    alerts.append({
                        "child_pid": pinfo['pid'],
                        "child": child_name,
                        "parent_pid": pinfo['ppid'],
                        "parent": parent_name,
                        "user": pinfo.get('username', 'N/A'),
                        "cmdline": ' '.join(pinfo.get('cmdline', []) or []),
                    })
        except (psutil.NoSuchProcess, psutil.AccessDenied):
            continue
    return alerts


def kill_suspicious(pid: int, name: str):
    """Завершить подозрительный процесс и всё его дерево."""
    try:
        proc = psutil.Process(pid)
        children = proc.children(recursive=True)
        for child in children:
            child.kill()
        proc.kill()
        print(f"  [ACTION] Killed PID {pid} ({name}) and {len(children)} children")
    except Exception as e:
        print(f"  [ERROR] Cannot kill PID {pid}: {e}")


def main():
    print(f"Process Tree Analyzer — {datetime.now()}\n")
    alerts = scan_process_tree()
    if not alerts:
        print("[OK] Подозрительных деревьев процессов не обнаружено")
    else:
        for a in alerts:
            print(f"[ALERT] {a['parent']} (PID {a['parent_pid']}) → {a['child']} (PID {a['child_pid']})")
            print(f"  User: {a['user']}")
            print(f"  Cmdline: {a['cmdline'][:100]}")
            kill_suspicious(a['child_pid'], a['child'])


if __name__ == "__main__":
    main()
```

### Python: мониторинг исходящего трафика

```python
#!/usr/bin/env python3
"""
Мониторинг подозрительных исходящих передач (DLP).
Отслеживает объём upload по хостам и алертит при превышении порога.
"""

import subprocess
import re
from collections import defaultdict
from datetime import datetime

UPLOAD_THRESHOLD_MB = 50
MONITORING_WINDOW_SEC = 300

host_uploads = defaultdict(float)


def parse_network_stats():
    """Анализ текущих сетевых подключений (Linux: ss + proc)."""
    try:
        result = subprocess.run(
            ["ss", "-tnp", "-o", "state", "established"],
            capture_output=True, text=True
        )
        for line in result.stdout.splitlines():
            parts = line.split()
            if len(parts) >= 5:
                # Извлекаем Send-Q (байт в очереди на отправку)
                send_q = int(parts[2]) if parts[2].isdigit() else 0
                remote = parts[4]
                if send_q > 0:
                    host_uploads[remote] += send_q / (1024 * 1024)
    except Exception:
        pass


def check_thresholds() -> list:
    alerts = []
    for host, mb in host_uploads.items():
        if mb > UPLOAD_THRESHOLD_MB:
            alerts.append({"host": host, "upload_mb": round(mb, 2)})
    return alerts


def main():
    print(f"DLP Monitor: threshold={UPLOAD_THRESHOLD_MB}MB / {MONITORING_WINDOW_SEC}s")
    parse_network_stats()
    alerts = check_thresholds()
    for a in alerts:
        print(f"[ALERT] Exfiltration: {a['upload_mb']}MB uploaded to {a['host']}")


if __name__ == "__main__":
    main()
```

#!/bin/bash
# webshell_monitor.sh — мониторинг создания файлов в webroot
# Зависимости: inotifywait (inotify-tools)

WEBROOT="/var/www/html"
QUARANTINE="/var/quarantine"
LOG="/var/log/webshell_monitor.log"

mkdir -p "$QUARANTINE"
echo "[$(date)] Web Shell Monitor started for $WEBROOT" | tee -a "$LOG"

inotifywait -m -r -e create -e modify --format '%w%f' "$WEBROOT" | while read -r FILE; do
    # Проверить расширение
    case "$FILE" in
        *.php|*.php?|*.phtml|*.jsp|*.jspx|*.aspx|*.ashx|*.asp|*.cfm)
            # Проверить содержимое на признаки веб-шелла
            if grep -qPi '(eval\s*\(|base64_decode|system\s*\(|exec\s*\(|passthru|shell_exec|assert\s*\(|\$_(?:GET|POST|REQUEST)\s*\[)' "$FILE" 2>/dev/null; then

                echo "[$(date)] [ALERT] Web shell detected: $FILE (SHA256: $HASH)" | tee -a "$LOG"
                # Переместить в карантин
                mv "$FILE" "$QUARANTINE/$(basename "$FILE")_$(date +%s)"
                echo "[$(date)] [ACTION] Quarantined: $FILE" | tee -a "$LOG"
                logger -t webshell "QUARANTINED $FILE hash=$HASH"
            fi
            ;;
    esac
done

- [ ] Связаться с ISP / CDN (Cloudflare, Akamai) для фильтрации
- [ ] Blackhole routing для наиболее агрессивных IP-диапазонов
- [ ] Мониторить доступность сервисов

## Цепочка 20: USB Device → Policy Enforcement → Block

### Сценарий атаки
Атакующий (или инсайдер) подключает USB-устройство для кражи данных, внедрения малвари или BadUSB-атаки.

### Телеметрия
- **Sysmon Event ID 6** — загрузка драйвера (USB mass storage)
- **Windows Event ID 6416** — подключение нового устройства (Plug and Play)
- **Windows Event ID 4663** — доступ к файлам на USB

### Детекция: Sigma-правило

```yaml
title: Подключение USB mass storage устройства
id: b8c9d0e1-f2a3-4b5c-6d7e-8f9a0b1c2d3e
status: stable
logsource:
  product: windows
  service: security
detection:
  selection:
    EventID: 6416
    ClassName: 'DiskDrive'
  condition: selection
level: medium
tags:
  - attack.initial_access
  - attack.t1091
```

### Bash: блокировка USB на Linux

```bash
#!/bin/bash
# usb_block.sh — блокировка USB mass storage

echo "[$(date)] Blocking USB mass storage"

# Метод 1: Blacklist модуля ядра
echo "blacklist usb-storage" > /etc/modprobe.d/block-usb.conf
echo "install usb-storage /bin/false" >> /etc/modprobe.d/block-usb.conf
modprobe -r usb-storage 2>/dev/null

# Метод 2: udev-правило (логировать + блокировать)
cat > /etc/udev/rules.d/99-usb-block.rules << 'EOF'
ACTION=="add", SUBSYSTEM=="usb", ATTR{bInterfaceClass}=="08", \
  RUN+="/usr/bin/logger -t usb-block 'USB storage blocked: %k'" \
  RUN+="/bin/sh -c 'echo 0 > /sys$env{DEVPATH}/authorized'"
EOF

udevadm control --reload-rules
echo "[$(date)] USB mass storage blocked"
```

### PowerShell: блокировка USB на Windows

```powershell
# Блокировать USB mass storage через GPO / реестр
$path = "HKLM:\SYSTEM\CurrentControlSet\Services\USBSTOR"
Set-ItemProperty -Path $path -Name "Start" -Value 4 -Type DWord
# 4 = Disabled, 3 = Enabled (по умолчанию)

# Через Device Installation Restrictions (GPO):
# Computer Config → Admin Templates → System → Device Installation → Device Installation Restrictions
# "Prevent installation of devices using drivers that match these device setup classes"
# Class GUID: {36fc9e60-c465-11cf-8056-444553540000}  (USB Mass Storage)
```

### Wazuh

```xml

  <rule id="100290" level="8">

    <field name="win.system.eventID">6416</field>

  </rule>

```

### Checklist для SOC-аналитика

- [ ] Кто подключил устройство? (user, hostname)
- [ ] Какое устройство? (VID/PID, серийный номер)
- [ ] Были ли файлы скопированы? (Event 4663)
- [ ] Устройство в белом списке?
- [ ] Если не в списке → конфисковать, расследовать
