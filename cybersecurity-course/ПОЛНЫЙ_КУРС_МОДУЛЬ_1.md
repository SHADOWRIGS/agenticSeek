## Урок 1.1 · Сетевые основы: OSI, TCP/IP, протоколы

### Теория

**Модель OSI (7 уровней):**

| Уровень | Название | Протоколы | Для SOC |
|---------|----------|-----------|---------|
| 7 | Application | HTTP, DNS, SMTP, FTP | WAF, прокси-логи |
| 6 | Presentation | SSL/TLS, MIME | Сертификаты, шифрование |
| 5 | Session | NetBIOS, RPC | Сессии SMB/RDP |
| 4 | Transport | TCP, UDP | Порты, файрвол |
| 3 | Network | IP, ICMP, ARP | Маршрутизация, NAT |
| 2 | Data Link | Ethernet, Wi-Fi | MAC-адреса, VLAN |
| 1 | Physical | Кабели, радио | Физическая безопасность |

**Модель TCP/IP (4 уровня):**

| Уровень | Протоколы |
|---------|-----------|
| Application | HTTP, DNS, DHCP, SSH, SMTP |
| Transport | TCP (надёжный), UDP (быстрый) |
| Internet | IP, ICMP, ARP |
| Network Access | Ethernet, Wi-Fi |

**TCP Three-Way Handshake:**
```
Client → SYN → Server
Client ← SYN-ACK ← Server
Client → ACK → Server
```

**Ключевые порты для SOC-аналитика:**

| Порт | Протокол | Сервис | Почему важен |
|------|----------|--------|-------------|
| 22 | TCP | SSH | Удалённый доступ, brute-force |
| 25/587 | TCP | SMTP | Email, фишинг |
| 53 | TCP/UDP | DNS | DNS tunneling, C2 |
| 80 | TCP | HTTP | Веб-атаки |
| 443 | TCP | HTTPS | Шифрованный C2 |
| 445 | TCP | SMB | Lateral movement, ransomware |
| 3389 | TCP | RDP | Lateral movement |
| 5985/5986 | TCP | WinRM | PowerShell Remoting |

**DNS — как работает:**
```
Браузер → Локальный кэш → DNS-резолвер → Root DNS → TLD DNS → Авторитативный DNS → IP-адрес
```

**ARP — Address Resolution Protocol:**
ARP связывает IP-адрес с MAC-адресом в локальной сети. ARP Spoofing — атака, при которой злоумышленник подменяет ARP-таблицу и перехватывает трафик (Man-in-the-Middle).

### Скрипт: сетевой сканер на Python

```python
#!/usr/bin/env python3
"""
Базовый сетевой сканер — проверка открытых портов.
Используется SOC-аналитиком для инвентаризации сети.
"""

import socket
import sys
from concurrent.futures import ThreadPoolExecutor, as_completed
from datetime import datetime

COMMON_PORTS = {
    21: "FTP", 22: "SSH", 23: "Telnet", 25: "SMTP",
    53: "DNS", 80: "HTTP", 110: "POP3", 143: "IMAP",
    443: "HTTPS", 445: "SMB", 993: "IMAPS", 995: "POP3S",
    1433: "MSSQL", 3306: "MySQL", 3389: "RDP",
    5432: "PostgreSQL", 5985: "WinRM", 8080: "HTTP-Alt",
    8443: "HTTPS-Alt",
}


def scan_port(host, port, timeout=1):
    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
            s.settimeout(timeout)
            result = s.connect_ex((host, port))
            if result == 0:
                service = COMMON_PORTS.get(port, "Unknown")
                return port, service, True
    except (socket.timeout, OSError):
        pass
    return port, "", False


def scan_host(host, ports=None):
    if ports is None:
        ports = list(COMMON_PORTS.keys())

    print(f"[*] Сканирование {host} — {len(ports)} портов")
    print(f"[*] Начало: {datetime.now().strftime('%H:%M:%S')}")

    open_ports = []
    with ThreadPoolExecutor(max_workers=50) as executor:
        futures = {executor.submit(scan_port, host, p): p for p in ports}
        for future in as_completed(futures):
            port, service, is_open = future.result()
            if is_open:
                open_ports.append((port, service))
                print(f"  [OPEN] {port}/tcp — {service}")

    print(f"\n[+] Открытых портов: {len(open_ports)}")
    return sorted(open_ports)


if __name__ == "__main__":
    target = sys.argv[1] if len(sys.argv) > 1 else "127.0.0.1"
    scan_host(target)
```

## Урок 1.2 · Linux для SOC-аналитика

### Теория

Linux — основа большинства серверов, SIEM, IDS/IPS. SOC-аналитик должен свободно работать в терминале.

**Файловая система:**

| Директория | Содержимое | Для SOC |
|-----------|-----------|---------|
| `/var/log/` | Системные логи | auth.log, syslog, kern.log |
| `/etc/` | Конфигурации | passwd, shadow, crontab, ssh |
| `/proc/` | Информация о процессах | PID, cmdline, environ |
| `/tmp/` | Временные файлы | Малварь часто живёт тут |
| `/home/` | Домашние директории | .bash_history, .ssh/ |

### Ключевые команды


### Скрипт: аудит безопасности Linux

```bash
#!/bin/bash
# Быстрый аудит безопасности Linux-хоста для SOC

echo "=== Linux Security Audit ==="
echo "Хост: $(hostname) | Дата: $(date)"
echo ""

echo "[1] Пользователи с UID 0 (root-права):"
awk -F: '$3 == 0 {print "  "$1}' /etc/passwd
echo ""

echo "[2] Пользователи с shell (могут логиниться):"
grep -v '/nologin\|/false' /etc/passwd | awk -F: '{print "  "$1" -> "$7}'
echo ""

echo "[3] SUID-файлы (потенциальный privilege escalation):"
find / -perm -4000 -type f 2>/dev/null | while read f; do
    echo "  $f"
done
echo ""

echo "[4] Crontab (scheduled tasks):"
for user in $(cut -f1 -d: /etc/passwd); do
    crontab -l -u "$user" 2>/dev/null | grep -v '^#' | while read line; do
        [ -n "$line" ] && echo "  [$user] $line"
    done
done
ls -la /etc/cron.d/ 2>/dev/null
echo ""

echo "[5] Открытые порты:"
ss -tulnp 2>/dev/null | grep LISTEN
echo ""

echo "[6] Последние 5 неудачных логинов:"
lastb -n 5 2>/dev/null || echo "  (lastb недоступен)"
echo ""

echo "[7] Файлы в /tmp:"
ls -la /tmp/ 2>/dev/null | head -20
echo ""

echo "[8] SSH-конфигурация:"
grep -E "^(PermitRootLogin|PasswordAuthentication|Port)" /etc/ssh/sshd_config 2>/dev/null
echo ""

echo "=== Аудит завершён ==="
```

## Урок 1.3 · Windows для SOC-аналитика

### Теория

**Windows Event Log** — основной источник данных для SOC. Логи хранятся в формате EVTX в `C:\Windows\System32\winevt\Logs\`.

**Ключевые журналы:**

| Журнал | Содержимое |
|--------|-----------|
| Security | Логины, логауты, аудит доступа, изменения политик |
| System | Сервисы, драйверы, ошибки системы |
| Application | Ошибки приложений |
| Sysmon/Operational | Расширенный мониторинг (если установлен) |
| PowerShell/Operational | Выполнение PowerShell-скриптов |

**Критические Event ID:**

| Event ID | Журнал | Что фиксирует |
|----------|--------|---------------|
| 4624 | Security | Успешный логин |
| 4625 | Security | Неудачный логин |
| 4648 | Security | Логин с явными credentials |
| 4672 | Security | Назначение привилегий |
| 4688 | Security | Создание процесса |
| 4698 | Security | Scheduled task создан |
| 4720 | Security | Создан пользователь |
| 4732 | Security | Пользователь добавлен в группу |
| 7045 | System | Установка сервиса |
| 1102 | Security | Очистка журнала |

**Типы логонов (Logon Type):**

| Type | Описание | Пример |
|------|----------|--------|
| 2 | Interactive | Физический вход |
| 3 | Network | SMB, PsExec |
| 4 | Batch | Scheduled task |
| 5 | Service | Запуск сервиса |
| 7 | Unlock | Разблокировка экрана |
| 10 | RemoteInteractive | RDP |
| 11 | CachedInteractive | Кэшированные credentials |

```powershell
    ForEach-Object {
        Write-Host "  $($_.TimeCreated) | User: $($_.Properties[5].Value) | IP: $($_.Properties[19].Value)"

# 3. Новые сервисы за неделю
Write-Host "`n[3] Новые сервисы (последняя неделя):" -ForegroundColor Yellow

    ForEach-Object {
        Write-Host "  $($_.TimeCreated) | $($_.Properties[0].Value) | $($_.Properties[1].Value)"

Write-Host "`n[4] Registry Run Keys:" -ForegroundColor Yellow
@("HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run",

        Get-ItemProperty $_ | ForEach-Object {

Write-Host "`n[6] Listening Ports:" -ForegroundColor Yellow

    Select-Object LocalPort, @{N='Process';E={(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).ProcessName}} |
```

## Урок 1.4 · Криптография для SOC

### Теория

**Симметричное шифрование** — один ключ для шифрования и расшифровки.
- AES-256 (стандарт), ChaCha20
- Быстро, но проблема передачи ключа

**Асимметричное шифрование** — пара ключей (публичный + приватный).
- RSA, ECDSA, Ed25519
- Медленнее, но решает проблему обмена ключами

**Хэш-функции** — необратимое преобразование, фиксированная длина.
- MD5 (128 бит) — **устарел**, не использовать для безопасности
- SHA-1 (160 бит) — **устарел**
- SHA-256 (256 бит) — **стандарт**, используется повсюду
- SHA-512 (512 бит) — ещё надёжнее

**TLS (Transport Layer Security):**
```
Client → ClientHello (версия TLS, cipher suites) → Server
Client ← ServerHello (выбранный cipher, сертификат) ← Server
Client → Key Exchange (предмастер-ключ, зашифрованный публичным ключом) → Server
Обе стороны вычисляют session key → шифрованная передача данных
```

**PKI (Public Key Infrastructure):**
- CA (Certificate Authority) — удостоверяющий центр
- Сертификат = публичный ключ + информация о владельце + подпись CA
- Цепочка доверия: Root CA → Intermediate CA → Сертификат сайта

**Python: хэширование и проверка файлов**

```python
#!/usr/bin/env python3
"""
Утилита хэширования файлов для SOC.
Вычисление и проверка хэшей для IoC-анализа.
"""

import hashlib
import sys
import os


def hash_file(filepath):
    """Вычислить MD5, SHA-1, SHA-256 хэши файла."""
    md5 = hashlib.md5()
    sha1 = hashlib.sha1()
    sha256 = hashlib.sha256()

    with open(filepath, "rb") as f:
        while chunk := f.read(8192):
            md5.update(chunk)
            sha1.update(chunk)
            sha256.update(chunk)

    return {
        "md5": md5.hexdigest(),
        "sha1": sha1.hexdigest(),
        "sha256": sha256.hexdigest(),
        "size": os.path.getsize(filepath),
    }


def check_ioc(filepath, ioc_list_file):
    """Проверить хэш файла по списку IoC."""
    hashes = hash_file(filepath)

    with open(ioc_list_file) as f:
        iocs = set(line.strip().lower() for line in f if line.strip())

    for algo, value in hashes.items():
        if algo == "size":
            continue
        if value.lower() in iocs:
            return True, algo, value

    return False, None, None


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Использование: python hash_util.py <file> [ioc_list.txt]")
        sys.exit(1)

    filepath = sys.argv[1]
    hashes = hash_file(filepath)

    print(f"Файл: {filepath}")
    print(f"  MD5:    {hashes['md5']}")
    print(f"  SHA-1:  {hashes['sha1']}")
    print(f"  SHA-256: {hashes['sha256']}")
    print(f"  Размер: {hashes['size']} bytes")

    if len(sys.argv) > 2:
        found, algo, value = check_ioc(filepath, sys.argv[2])
        if found:
            print(f"\n[!!!] НАЙДЕН IoC! {algo}: {value}")
        else:
            print("\n[OK] IoC не найден.")
```

### Python: анализ PCAP

```python
#!/usr/bin/env python3
"""
Анализатор PCAP-файлов для SOC.
pip install scapy
"""

from scapy.all import rdpcap, IP, TCP, UDP, DNS, DNSQR
from collections import Counter
import sys


def analyze_pcap(filepath):
    packets = rdpcap(filepath)
    print(f"[*] Пакетов: {len(packets)}")

    src_ips = Counter()
    dst_ips = Counter()
    dst_ports = Counter()
    dns_queries = Counter()
    syn_scans = Counter()

    for pkt in packets:
        if IP in pkt:
            src_ips[pkt[IP].src] += 1
            dst_ips[pkt[IP].dst] += 1

        if TCP in pkt:
            dst_ports[pkt[TCP].dport] += 1
            if pkt[TCP].flags == 0x02:  # SYN only
                syn_scans[pkt[IP].src] += 1

        if DNS in pkt and pkt.haslayer(DNSQR):
            dns_queries[pkt[DNSQR].qname.decode()] += 1

    print("\n[TOP 10 Source IPs]")
    for ip, count in src_ips.most_common(10):
        print(f"  {ip}: {count}")

    print("\n[TOP 10 Destination Ports]")
    for port, count in dst_ports.most_common(10):
        print(f"  {port}: {count}")

    print("\n[TOP 10 DNS Queries]")
    for query, count in dns_queries.most_common(10):
        print(f"  {query}: {count}")

    if syn_scans:
        print("\n[!!! SYN Scan Sources]")
        for ip, count in syn_scans.most_common(5):
            print(f"  {ip}: {count} SYN packets")


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Использование: python pcap_analyzer.py <file.pcap>")
        sys.exit(1)
    analyze_pcap(sys.argv[1])
```

## Урок 2.2 · Sysmon: расширенный мониторинг Windows

### Теория

**Sysmon (System Monitor)** — утилита Sysinternals, расширяющая мониторинг Windows. Логирует создание процессов, сетевые соединения, изменения файлов и реестра, загрузку DLL, доступ к процессам.

**Ключевые Event ID:**

| Event ID | Описание | Для чего |
|----------|----------|---------|
| 1 | Process Create | Запуск процессов + command line |
| 3 | Network Connect | Исходящие соединения |
| 6 | Driver Load | Загрузка драйверов |
| 7 | Image Load | Загрузка DLL |
| 8 | CreateRemoteThread | Process injection |
| 10 | ProcessAccess | Доступ к другим процессам (LSASS) |
| 11 | FileCreate | Создание файлов |
| 12/13/14 | Registry | Создание/изменение/переименование ключей реестра |
| 22 | DNSQuery | DNS-запросы |
| 23 | FileDelete | Удаление файлов (с сохранением) |

### Конфигурация Sysmon (расширенная)

```xml
      <Image condition="is">C:\Windows\System32\conhost.exe</Image>
      <Image condition="is">C:\Windows\System32\backgroundTaskHost.exe</Image>
    </ProcessCreate>

    <!-- Event 3: Network — исходящие подключения -->
    <NetworkConnect onmatch="include">
      <DestinationPort condition="is">80</DestinationPort>
      <DestinationPort condition="is">443</DestinationPort>
      <DestinationPort condition="is">53</DestinationPort>
      <DestinationPort condition="is">445</DestinationPort>
      <DestinationPort condition="is">3389</DestinationPort>
      <DestinationPort condition="is">5985</DestinationPort>
      <DestinationPort condition="is">4444</DestinationPort>
      <DestinationPort condition="is">8080</DestinationPort>
    </NetworkConnect>

    <!-- Event 7: Image Load — DLL из подозрительных мест -->
    <ImageLoad onmatch="include">
      <ImageLoaded condition="contains">\Temp\</ImageLoaded>
      <ImageLoaded condition="contains">\Users\Public\</ImageLoaded>
      <ImageLoaded condition="contains">\Downloads\</ImageLoaded>
      <ImageLoaded condition="contains">\AppData\</ImageLoaded>
    </ImageLoad>

    <!-- Event 8: CreateRemoteThread — всегда -->
    <CreateRemoteThread onmatch="exclude" />

    <!-- Event 10: Process Access — LSASS -->
    <ProcessAccess onmatch="include">
      <TargetImage condition="end with">\lsass.exe</TargetImage>
    </ProcessAccess>

    <!-- Event 11: File Create — критические пути -->
    <FileCreate onmatch="include">
      <TargetFilename condition="contains">\Startup\</TargetFilename>
      <TargetFilename condition="contains">\Start Menu\</TargetFilename>
      <TargetFilename condition="end with">.exe</TargetFilename>
      <TargetFilename condition="end with">.dll</TargetFilename>
      <TargetFilename condition="end with">.ps1</TargetFilename>
      <TargetFilename condition="end with">.bat</TargetFilename>
      <TargetFilename condition="end with">.vbs</TargetFilename>
    </FileCreate>

    <!-- Event 12/13/14: Registry — автозапуск -->
    <RegistryEvent onmatch="include">
      <TargetObject condition="contains">\CurrentVersion\Run</TargetObject>
      <TargetObject condition="contains">\Image File Execution Options</TargetObject>
      <TargetObject condition="contains">\Classes\CLSID</TargetObject>
      <TargetObject condition="contains">\Winlogon</TargetObject>
    </RegistryEvent>

    <!-- Event 22: DNS Query — всё -->
    <DnsQuery onmatch="exclude" />
  </EventFiltering>
</Sysmon>
```

```yaml
# Формат правила Suricata:
# action protocol src_ip src_port -> dst_ip dst_port (options;)

# Обнаружение ICMP-пингов
alert icmp $EXTERNAL_NET any -> $HOME_NET any (
    msg:"CRS: ICMP Ping Detected";
    itype:8;
    sid:1000001; rev:1;
)

alert tcp $EXTERNAL_NET any -> $HOME_NET 22 (

    sid:1000002; rev:1;
)

    msg:"CRS: Nmap SYN Scan";
    flags:S;
    threshold: type both, track by_src, count 50, seconds 10;
    sid:1000003; rev:1;
)

# HTTP с подозрительным User-Agent
alert http $HOME_NET any -> $EXTERNAL_NET any (
    msg:"CRS: Suspicious User-Agent (Python)";
    http.user_agent; content:"python-requests";
    sid:1000004; rev:1;
)

# DNS-запрос к известному C2
alert dns $HOME_NET any -> any 53 (
    msg:"CRS: DNS Query to Known C2 Domain";
```

## Урок 2.5 · Анализ логов: построение таймлайна

### Теория

**Timeline Analysis** — ключевой навык SOC-аналитика. При расследовании инцидента необходимо построить хронологию событий из разных источников.

**Источники для таймлайна:**

| Источник | Что даёт |
|----------|---------|
| Windows Security Log | Логины, процессы, доступ |
| Sysmon | Процессы, сеть, файлы, реестр |
| Suricata/Zeek | Сетевые события |
| Firewall logs | Разрешённые/заблокированные соединения |
| Web proxy logs | HTTP-запросы |
| Linux auth.log | SSH-логины |

### Python: построение таймлайна

```python
#!/usr/bin/env python3
"""
Timeline Builder — построение хронологии из нескольких источников.
"""

import json
import csv
import sys
from datetime import datetime


def parse_eve_json(filepath):
    """Парсинг Suricata eve.json."""
    events = []
    with open(filepath) as f:
        for line in f:
            try:
                record = json.loads(line)
                events.append({
                    "timestamp": record.get("timestamp", ""),
                    "source": "Suricata",
                    "type": record.get("event_type", ""),
                    "details": record.get("alert", {}).get("signature", "")
                              or f"{record.get('src_ip','')} -> {record.get('dest_ip','')}",
                })
            except json.JSONDecodeError:
                continue
    return events


def parse_auth_log(filepath):
    """Парсинг Linux auth.log."""
    events = []
    with open(filepath) as f:
        for line in f:
            if "Failed password" in line or "Accepted" in line or "session opened" in line:
                parts = line.split()
                timestamp = " ".join(parts[:3])
                events.append({
                    "timestamp": timestamp,
                    "source": "auth.log",
                    "type": "authentication",
                    "details": line.strip(),
                })
    return events


def build_timeline(sources):
    """Объединить и отсортировать события из всех источников."""
    all_events = []
    for source_file, parser in sources:
        try:
            all_events.extend(parser(source_file))
        except FileNotFoundError:
            print(f"[!] Файл не найден: {source_file}")
    all_events.sort(key=lambda e: e["timestamp"])
    return all_events


def export_csv(events, output_path):
    with open(output_path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=["timestamp", "source", "type", "details"])
        writer.writeheader()
        writer.writerows(events)
    print(f"[+] Timeline сохранён: {output_path} ({len(events)} событий)")


if __name__ == "__main__":
    sources = [
        ("/var/log/suricata/eve.json", parse_eve_json),
        ("/var/log/auth.log", parse_auth_log),
    ]
    timeline = build_timeline(sources)
    export_csv(timeline, "incident_timeline.csv")

    print("\n[*] Последние 10 событий:")
    for evt in timeline[-10:]:
        print(f"  [{evt['timestamp']}] ({evt['source']}) {evt['details'][:80]}")
```

1. Соберите логи из 3 источников: auth.log, Suricata eve.json, Sysmon.
2. Постройте таймлайн с помощью Python-скрипта.
3. Найдите корреляцию: SSH brute-force → успешный логин → подозрительный процесс.
4. Экспортируйте таймлайн в CSV и визуализируйте в Excel/LibreOffice.

## Урок 3.1 · Sigma: универсальный язык детекции

### Теория

**Sigma** — открытый формат правил детекции, который можно конвертировать в формат любого SIEM (Splunk, ELK, QRadar, Wazuh).

### Структура Sigma-правила

```yaml
title: Descriptive Title
id: unique-uuid
status: stable | test | experimental
description: Что и зачем обнаруживает
author: SOC Team
date: 2026/01/01
references:
    - https://attack.mitre.org/techniques/T1059/
logsource:
    product: windows       # ОС или продукт
    category: process_creation  # Тип события
    service: security      # Журнал
detection:
    selection:
        FieldName|modifier: value
    filter:
        FieldName: value
    condition: selection and not filter
level: low | medium | high | critical
tags:
    - attack.execution
    - attack.t1059
falsepositives:
    - Legitimate admin activity
```

**Модификаторы полей:**

| Модификатор | Значение | Пример |
|------------|----------|--------|
| `contains` | Содержит подстроку | `CommandLine\|contains: 'mimikatz'` |
| `endswith` | Заканчивается на | `Image\|endswith: '\cmd.exe'` |
| `startswith` | Начинается с | `Path\|startswith: 'C:\Temp'` |
| `re` | Регулярное выражение | `CommandLine\|re: '.*-enc.*'` |
| `all` | Все значения должны совпасть | `CommandLine\|contains\|all:` |

### Практическое задание

## Урок 3.2 · YARA: поиск малвари по сигнатурам

### Теория

**YARA** — инструмент для классификации и идентификации малвари по паттернам (строки, байт-последовательности, условия).

### Структура YARA-правила

```yara
rule ExampleMalware
{
    meta:
        description = "Обнаружение примера малвари"
        author = "SOC Team"
        severity = "high"
        date = "2026-01-01"

    strings:
        $string1 = "malicious_function" ascii wide
        $string2 = { 4D 5A 90 00 }  // MZ header
        $url = /https?:\/\/evil[a-z]+\.com/ nocase

    condition:
        uint16(0) == 0x5A4D and   // PE file
        filesize < 1MB and
        (2 of ($string*) or $url)
}
```

## Урок 3.3 · Hardening: CIS Benchmarks

### Теория

**CIS Benchmarks** — стандарты безопасной конфигурации для ОС, сетевых устройств, СУБД. Содержат конкретные настройки с уровнями (Level 1 — базовый, Level 2 — продвинутый).

### Чеклист hardening Windows (топ-15)

```powershell
# 1. Включить Windows Firewall
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True

# 2. Отключить SMBv1
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol -NoRestart

# 3. Включить аудит
auditpol /set /subcategory:"Logon" /success:enable /failure:enable
auditpol /set /subcategory:"Process Creation" /success:enable

# 4. Включить PowerShell Script Block Logging
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" -Force
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" -Name "EnableScriptBlockLogging" -Value 1

# 5. Установить Account Lockout Policy
net accounts /lockoutthreshold:5 /lockoutduration:30 /lockoutwindow:30

# 6. Отключить WDigest
reg add "HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest" /v UseLogonCredential /t REG_DWORD /d 0 /f

# 7. Включить RunAsPPL
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Lsa" /v RunAsPPL /t REG_DWORD /d 1 /f

# 8. Установить Sysmon
# (см. урок 2.2)

# 9. Настроить Windows Update на автоматическое обновление
# GPO: Computer Configuration → Administrative Templates → Windows Components → Windows Update

# 10. Ограничить использование PowerShell
# Set-ExecutionPolicy AllSigned  (для подписанных скриптов)
```

### Чеклист hardening Linux (топ-15)

```bash
# 1. Обновить систему
sudo apt update && sudo apt upgrade -y

# 2. Настроить SSH hardening (см. урок 1.2)

# 3. Установить fail2ban
sudo apt install fail2ban -y

# 4. Настроить файрвол (UFW)
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw enable

# 5. Отключить ненужные сервисы
sudo systemctl disable cups avahi-daemon bluetooth

# 6. Настроить auditd
sudo apt install auditd -y
sudo auditctl -w /etc/passwd -p wa -k passwd_changes
sudo auditctl -w /etc/shadow -p wa -k shadow_changes
sudo auditctl -w /var/log/ -p wa -k log_changes

# 7. Настроить sysctl (network hardening)
cat >> /etc/sysctl.conf << 'EOF'
net.ipv4.conf.all.rp_filter = 1
net.ipv4.conf.default.rp_filter = 1
net.ipv4.icmp_echo_ignore_broadcasts = 1
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.all.send_redirects = 0
net.ipv4.tcp_syncookies = 1
EOF
sudo sysctl -p

# 8. Установить AIDE (file integrity monitoring)
sudo apt install aide -y
sudo aideinit
```
