## Урок 6.1 · Persistence-техники и их детекция

### Теория

**Persistence (закрепление)** — набор техник, позволяющих атакующему сохранить доступ к системе после перезагрузки, смены пароля или обновления. Это первое, что делает злоумышленник после получения начального доступа: он «закрепляется», чтобы не потерять плацдарм.

С точки зрения MITRE ATT&CK это тактика **TA0003 — Persistence**. Основные суб-техники, которые мы разберём в этом уроке:

| Техника | MITRE ID | Где живёт | Как выживает |
|---------|----------|-----------|--------------|
| Registry Run Keys | T1547.001 | `HKLM/HKCU\...\Run` | Автозапуск при входе |
| Scheduled Tasks | T1053.005 | Task Scheduler XML | Запуск по расписанию |
| New Service | T1543.003 | `HKLM\SYSTEM\...\Services` | Запуск при старте ОС |
| Startup Folder | T1547.001 | `%AppData%\...\Startup` | Запуск при входе |

**Почему это опасно:** persistence-механизмы работают тихо. Пользователь не видит ни окон, ни сообщений. Малварь запускается автоматически при каждой загрузке, а удаление самого файла без очистки persistence-точки бесполезно — он будет скачан/восстановлен заново.

**Задача SOC-аналитика:** мониторить все точки автозапуска и мгновенно реагировать на появление новых или изменение существующих записей.

### Ключевые артефакты для мониторинга

**Windows Event Log:**

| Event ID | Источник | Что фиксирует |

### Скрипты детекции

**PowerShell: Полный сканер persistence-точек**

```powershell
<#
.SYNOPSIS
    Сканер точек persistence (автозапуска) Windows.
    Собирает информацию из реестра, планировщика, сервисов и Startup-папок.
.DESCRIPTION
    Используется SOC-аналитиком для аудита и поиска подозрительных закреплений.
#>

function Get-PersistencePoints {
    [CmdletBinding()]
    param(
        [switch]$ExportCsv,
        [string]$OutputPath = ".\persistence_report.csv"
    )

    $results = @()
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"

    # --- 1. Registry Run Keys ---
    Write-Host "[*] Проверяю Registry Run Keys..." -ForegroundColor Cyan

    $regPaths = @(
        "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run",
        "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce",
        "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run",
        "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce",
        "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer\Run",
        "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer\Run",
        "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\RunServices",
        "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\RunServicesOnce",
        "HKLM:\SOFTWARE\Wow6432Node\Microsoft\Windows\CurrentVersion\Run",
        "HKLM:\SOFTWARE\Wow6432Node\Microsoft\Windows\CurrentVersion\RunOnce"
    )

    foreach ($path in $regPaths) {
        if (Test-Path $path) {
            $entries = Get-ItemProperty -Path $path -ErrorAction SilentlyContinue
            $entries.PSObject.Properties | Where-Object {
                $_.Name -notin @("PSPath","PSParentPath","PSChildName","PSProvider","PSDrive")
            } | ForEach-Object {
                $results += [PSCustomObject]@{
                    Timestamp   = $timestamp
                    Type        = "Registry Run Key"
                    Location    = $path
                    Name        = $_.Name
                    Value       = $_.Value
                    Suspicious  = if ($_.Value -notmatch "Program Files|Windows\\System32") {"YES"} else {"NO"}
                }
            }
        }
    }

    # --- 2. Scheduled Tasks ---
    Write-Host "[*] Проверяю Scheduled Tasks..." -ForegroundColor Cyan

    $tasks = Get-ScheduledTask -ErrorAction SilentlyContinue |
             Where-Object { $_.State -ne 'Disabled' }

    foreach ($task in $tasks) {
        $actions = $task.Actions
        foreach ($action in $actions) {
            $exe = $action.Execute
            $suspicious = "NO"
            if ($exe -and $exe -notmatch "System32|SysWOW64|Program Files") {
                $suspicious = "YES"
            }
            $results += [PSCustomObject]@{
                Timestamp   = $timestamp
                Type        = "Scheduled Task"
                Location    = $task.TaskPath + $task.TaskName
                Name        = $task.TaskName
                Value       = "$exe $($action.Arguments)"
                Suspicious  = $suspicious
            }
        }
    }

    # --- 3. Services ---
    Write-Host "[*] Проверяю Services..." -ForegroundColor Cyan

    $services = Get-CimInstance -ClassName Win32_Service -ErrorAction SilentlyContinue |
                Where-Object { $_.StartMode -in @('Auto', 'Manual') }

    foreach ($svc in $services) {
        $suspicious = "NO"
        if ($svc.PathName -and $svc.PathName -notmatch "System32|SysWOW64|Program Files") {
            $suspicious = "YES"
        }
        $results += [PSCustomObject]@{
            Timestamp   = $timestamp
            Type        = "Service"
            Location    = "Services"
            Name        = "$($svc.Name) ($($svc.DisplayName))"
            Value       = $svc.PathName
            Suspicious  = $suspicious
        }
    }

    # --- 4. Startup Folders ---
    Write-Host "[*] Проверяю Startup Folders..." -ForegroundColor Cyan

    $startupPaths = @(
        "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup",
        "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup"
    )

    foreach ($sp in $startupPaths) {
        if (Test-Path $sp) {
            Get-ChildItem -Path $sp -File -ErrorAction SilentlyContinue | ForEach-Object {
                $results += [PSCustomObject]@{
                    Timestamp   = $timestamp
                    Type        = "Startup Folder"
                    Location    = $sp
                    Name        = $_.Name
                    Value       = $_.FullName
                    Suspicious  = "REVIEW"
                }
            }
        }
    }

    # --- Вывод ---
    $suspCount = ($results | Where-Object { $_.Suspicious -eq "YES" }).Count
    Write-Host "`n[РЕЗУЛЬТАТ] Найдено точек автозапуска: $($results.Count)" -ForegroundColor Green
    Write-Host "[!] Подозрительных: $suspCount" -ForegroundColor $(if ($suspCount -gt 0) {"Red"} else {"Green"})

    if ($ExportCsv) {
        $results | Export-Csv -Path $OutputPath -NoTypeInformation -Encoding UTF8
        Write-Host "[*] Отчёт сохранён: $OutputPath" -ForegroundColor Yellow
    }

    $results | Where-Object { $_.Suspicious -in @("YES","REVIEW") } |
        Format-Table -AutoSize

    return $results
}

# Запуск:
# Get-PersistencePoints -ExportCsv -OutputPath "C:\Reports\persistence.csv"
```

**Python: Парсинг Windows Event Log для persistence-событий**

```python
#!/usr/bin/env python3
"""
Парсер Windows Event Log: детекция persistence-событий.
Работает с экспортированными .evtx файлами через python-evtx.
pip install python-evtx
"""

import sys
import json
from datetime import datetime

try:
    import Evtx.Evtx as evtx
    import Evtx.Views as views
except ImportError:
    print("[!] Установите: pip install python-evtx")
    sys.exit(1)

import xml.etree.ElementTree as ET

PERSISTENCE_EVENTS = {
    "Security": {
        4698: "Scheduled Task Created",
        4699: "Scheduled Task Deleted",
        4702: "Scheduled Task Updated",
    },
    "System": {
        7045: "New Service Installed",
        7040: "Service Start Type Changed",
    },
    "Sysmon": {
        12: "Registry Key Created",
        13: "Registry Value Set",
        11: "File Created",
    }
}

PERSISTENCE_REG_PATHS = [
    "CurrentVersion\\Run",
    "CurrentVersion\\RunOnce",
    "Policies\\Explorer\\Run",
    "CurrentVersion\\RunServices",
]


def parse_evtx(filepath, log_type="Security"):
    alerts = []
    target_ids = PERSISTENCE_EVENTS.get(log_type, {})

    with evtx.Evtx(filepath) as log:
        for record in log.records():
            try:
                root = ET.fromstring(record.xml())
                ns = {"ns": "http://schemas.microsoft.com/win/2004/08/events/event"}
                event_id_el = root.find(".//ns:EventID", ns)
                if event_id_el is None:
                    continue
                eid = int(event_id_el.text)

                if eid not in target_ids:
                    continue

                time_el = root.find(".//ns:TimeCreated", ns)
                timestamp = time_el.get("SystemTime", "") if time_el is not None else ""

                data_fields = {}
                for data in root.findall(".//ns:Data", ns):
                    name = data.get("Name", "unknown")
                    data_fields[name] = data.text or ""

                is_persistence = True
                if eid in (12, 13):
                    target = data_fields.get("TargetObject", "")
                    is_persistence = any(p in target for p in PERSISTENCE_REG_PATHS)

                if is_persistence:
                    alerts.append({
                        "timestamp": timestamp,
                        "event_id": eid,
                        "description": target_ids[eid],
                        "data": data_fields,
                    })

            except Exception:
                continue

    return alerts


def main():
    if len(sys.argv) < 2:
        print("Использование: python persistence_detector.py <file.evtx> [log_type]")
        print("  log_type: Security | System | Sysmon")
        sys.exit(1)

    filepath = sys.argv[1]
    log_type = sys.argv[2] if len(sys.argv) > 2 else "Security"

    print(f"[*] Анализирую {filepath} (тип: {log_type})...")
    alerts = parse_evtx(filepath, log_type)

    print(f"[+] Найдено persistence-событий: {len(alerts)}\n")
    for a in alerts:
        print(f"  [{a['timestamp']}] Event {a['event_id']}: {a['description']}")
        for k, v in a["data"].items():
            if v:
                print(f"    {k}: {v}")
        print()

    output = filepath.replace(".evtx", "_persistence_alerts.json")
    with open(output, "w", encoding="utf-8") as f:
        json.dump(alerts, f, indent=2, ensure_ascii=False)
    print(f"[*] Сохранено: {output}")


if __name__ == "__main__":
    main()
```

## Урок 6.2 · DLL Hijacking, COM Hijacking, IFEO — обнаружение и блокировка

### Теория

**DLL Search Order Hijacking (T1574.001)** — атакующий размещает вредоносную DLL в директории, откуда легитимное приложение загрузит её раньше оригинальной. Windows ищет DLL в определённом порядке:

1. Директория приложения
2. System32
3. System (16-bit)
4. Windows directory
5. Текущая директория
6. Директории из PATH

Если атакующий положит `version.dll` рядом с уязвимым .exe — его DLL загрузится первой.

**COM Object Hijacking (T1546.015)** — подмена CLSID (идентификатора COM-объекта) в реестре. Когда система или приложение вызывают COM-объект по CLSID, загружается вредоносная DLL вместо легитимной. Часто используется для persistence: COM-объект вызывается при каждом входе.

**Image File Execution Options (T1546.012, IFEO)** — ключ реестра `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\<exe>`. Позволяет назначить «дебаггер» для любого .exe. При запуске целевого .exe Windows запустит «дебаггер» вместо него. Атакующий вписывает вредоносный .exe как дебаггер для calc.exe или notepad.exe.

**Почему это опасно:** Все три метода выглядят как нормальная работа ОС. Антивирус видит, что запускается легитимное приложение, и пропускает его. Реальная вредоносная нагрузка загружается как часть доверенного процесса.

### Индикаторы компрометации

| Метод | Что искать |
|-------|------------|
| DLL Hijacking | DLL не из System32/Program Files рядом с .exe |
| COM Hijacking | Изменения в `HKCU\SOFTWARE\Classes\CLSID` |
| IFEO | Ключ `Debugger` в IFEO |

```powershell
<#
.SYNOPSIS
    Аудит DLL Search Order Hijacking — поиск уязвимых приложений.
    Находит .exe файлы, рядом с которыми лежат DLL не из стандартного пути.
#>

function Find-DLLHijackRisk {
    param(
        [string]$ScanPath = "C:\Program Files"
    )

    Write-Host "[*] Сканирую $ScanPath на DLL hijacking риски..." -ForegroundColor Cyan

    $exeFiles = Get-ChildItem -Path $ScanPath -Filter "*.exe" -Recurse -ErrorAction SilentlyContinue
    $risks = @()

    foreach ($exe in $exeFiles) {
        $dir = $exe.DirectoryName
        $dlls = Get-ChildItem -Path $dir -Filter "*.dll" -ErrorAction SilentlyContinue

        foreach ($dll in $dlls) {
            $systemDll = "C:\Windows\System32\$($dll.Name)"
            if (Test-Path $systemDll) {
                $localSig = (Get-AuthenticodeSignature $dll.FullName).Status
                $sysSig = (Get-AuthenticodeSignature $systemDll).Status

                if ($localSig -ne "Valid") {
                    $risks += [PSCustomObject]@{
                        Exe       = $exe.Name
                        DLL       = $dll.Name
                        Path      = $dll.FullName
                        Signed    = $localSig
                        SysDLL    = "Exists"
                        Risk      = "HIGH - неподписанная DLL дублирует системную"
                    }
                }
            }
        }
    }

    Write-Host "[+] Найдено рисков: $($risks.Count)" -ForegroundColor $(if ($risks.Count -gt 0) {"Red"} else {"Green"})
    $risks | Format-Table -AutoSize
    return $risks
}
```

```powershell
function Find-IFEOHijack {
    Write-Host "[*] Проверяю IFEO Debugger записи..." -ForegroundColor Cyan

    $ifeoPath = "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options"
    $results = @()

    Get-ChildItem -Path $ifeoPath -ErrorAction SilentlyContinue | ForEach-Object {
        $debugger = (Get-ItemProperty -Path $_.PSPath -Name "Debugger" -ErrorAction SilentlyContinue).Debugger
        if ($debugger) {
            $results += [PSCustomObject]@{
                Target   = $_.PSChildName
                Debugger = $debugger
                Risk     = if ($debugger -notmatch "vsjitdebugger|windbg|devenv") {"HIGH"} else {"LOW"}
            }
        }
    }

    Write-Host "[+] IFEO записей с Debugger: $($results.Count)" -ForegroundColor Yellow
    $results | Where-Object { $_.Risk -eq "HIGH" } | Format-Table -AutoSize
    return $results
}

function Find-COMHijack {
    Write-Host "[*] Проверяю COM Hijacking в HKCU..." -ForegroundColor Cyan

    $comPath = "HKCU:\SOFTWARE\Classes\CLSID"
    $results = @()

    if (Test-Path $comPath) {
        Get-ChildItem -Path $comPath -ErrorAction SilentlyContinue | ForEach-Object {
            $inproc = Join-Path $_.PSPath "InprocServer32"
            if (Test-Path $inproc) {
                $dllPath = (Get-ItemProperty -Path $inproc -Name "(default)" -ErrorAction SilentlyContinue)."(default)"
                if ($dllPath -and $dllPath -notmatch "System32|Program Files") {
                    $results += [PSCustomObject]@{
                        CLSID    = $_.PSChildName
                        DLL      = $dllPath
                        Risk     = "HIGH"
                    }
                }
            }
        }
    }

    Write-Host "[+] Подозрительных COM-объектов: $($results.Count)" -ForegroundColor $(if ($results.Count -gt 0) {"Red"} else {"Green"})
    $results | Format-Table -AutoSize
    return $results
}
```

## Урок 6.3 · Kernel-уровень: драйверы, DKOM, PatchGuard — защита

### Теория

**Kernel-level атаки** — самые опасные, потому что работают на уровне ядра ОС и могут скрывать себя от всех средств защиты, работающих в user-mode (антивирус, EDR, Task Manager).

**DKOM (Direct Kernel Object Manipulation, T1014)** — атакующий напрямую модифицирует структуры данных ядра (EPROCESS, ETHREAD), чтобы скрыть процессы, драйверы, сетевые соединения от API-функций. Например, выгружает процесс из двусвязного списка ActiveProcessLinks — и Process Explorer его не видит.

**PatchGuard (Kernel Patch Protection)** — механизм защиты Microsoft, который периодически проверяет целостность критических структур ядра. Если обнаружено изменение — BSOD (синий экран). Атакующие пытаются обойти PatchGuard, чтобы модифицировать ядро без BSOD.

**Вредоносные драйверы** — загрузка неподписанного или подписанного украденным сертификатом драйвера. Даёт полный контроль над системой на уровне ring-0.

**Для SOC-аналитика:** прямого доступа к kernel-структурам из user-mode нет, поэтому детекция основана на:
- Мониторинге загрузки драйверов (Sysmon Event 6)
- Анализе дампов памяти (Volatility)
- Сравнении списков процессов из разных источников (API vs raw)
- Мониторинге BSOD и крэшей ядра

### Volatility: анализ дампа памяти для детекции DKOM

```bash
#!/bin/bash
# Скрипт форензик-анализа дампа памяти для обнаружения DKOM
# Требуется: Volatility 3

DUMP="$1"
if [ -z "$DUMP" ]; then
    echo "Использование: $0 <memory_dump.raw>"
    exit 1
fi

echo "=== DKOM Detection Analysis ==="
echo "[*] Дамп: $DUMP"
echo ""

echo "[1/5] Список процессов (pslist — из ActiveProcessLinks):"
vol -f "$DUMP" windows.pslist > /tmp/pslist.txt
wc -l /tmp/pslist.txt
echo ""

echo "[2/5] Скрытые процессы (psscan — из _POOL_HEADER):"
vol -f "$DUMP" windows.psscan > /tmp/psscan.txt
wc -l /tmp/psscan.txt
echo ""

echo "[3/5] Сравнение pslist vs psscan (DKOM detection):"
# Процессы в psscan но не в pslist = скрытые через DKOM
comm -13 <(awk '{print $1}' /tmp/pslist.txt | sort) \
         <(awk '{print $1}' /tmp/psscan.txt | sort) > /tmp/hidden.txt

HIDDEN_COUNT=$(wc -l < /tmp/hidden.txt)
if [ "$HIDDEN_COUNT" -gt 0 ]; then
    echo "[!!!] ОБНАРУЖЕНЫ СКРЫТЫЕ ПРОЦЕССЫ: $HIDDEN_COUNT"
    cat /tmp/hidden.txt
else
    echo "[OK] Скрытых процессов не обнаружено"
fi
echo ""

echo "[4/5] Загруженные драйверы (modules):"
vol -f "$DUMP" windows.modules > /tmp/modules.txt
echo "Всего драйверов: $(wc -l < /tmp/modules.txt)"
echo "Подозрительные (не из System32):"
grep -v "System32\|system32\|SYSTEM32" /tmp/modules.txt || echo "  (нет)"
echo ""

echo "[5/5] Сетевые соединения (netscan):"
vol -f "$DUMP" windows.netscan > /tmp/netscan.txt
echo "Активных соединений: $(wc -l < /tmp/netscan.txt)"
echo ""

echo "=== Анализ завершён ==="
echo "Файлы: /tmp/pslist.txt, /tmp/psscan.txt, /tmp/hidden.txt, /tmp/modules.txt, /tmp/netscan.txt"
```

## Урок 6.4 · Evasion: AMSI, ETW, Log Tampering — обнаружение

### Теория

Атакующие не только закрепляются — они **скрывают своё присутствие**, отключая или обходя механизмы логирования и детекции.

**AMSI (Antimalware Scan Interface, T1562.001)** — интерфейс Windows, через который PowerShell, VBScript, JScript и .NET передают код антивирусу перед выполнением. Обход AMSI позволяет запускать вредоносные скрипты без детекции.

**ETW (Event Tracing for Windows, T1562.006)** — система трассировки событий в Windows. Sysmon, Windows Defender, EDR — все используют ETW. Отключение ETW-провайдера «ослепляет» защитные инструменты.

**Log Tampering (T1070.001)** — очистка или модификация журналов событий Windows. Атакующий удаляет логи, чтобы скрыть следы (Event ID 1102 — очистка журнала Security).

**Для SOC:** Ирония в том, что мы должны детектировать попытки отключить нашу же систему детекции. Ключ — мониторинг самих механизмов защиты и централизованное хранение логов (что нельзя подделать локально).

```powershell
<#
.SYNOPSIS
    Проверка целостности системы логирования и защитных механизмов.
    Обнаруживает попытки ослепления SOC.
#>

function Test-DefenseIntegrity {
    [CmdletBinding()]
    param()

    $issues = @()

    # 1. Проверка AMSI
    Write-Host "[*] Проверяю AMSI..." -ForegroundColor Cyan
    try {
        $amsiDll = [System.IO.File]::Exists("$env:SystemRoot\System32\amsi.dll")
        $amsiSize = if ($amsiDll) { (Get-Item "$env:SystemRoot\System32\amsi.dll").Length } else { 0 }

        if (-not $amsiDll) {
            $issues += "CRITICAL: amsi.dll отсутствует!"
        } elseif ($amsiSize -lt 50000) {
            $issues += "WARNING: amsi.dll подозрительно маленький ($amsiSize bytes)"
        }
    } catch {
        $issues += "ERROR: Не удалось проверить AMSI: $_"
    }

    # 2. Проверка Sysmon
    Write-Host "[*] Проверяю Sysmon..." -ForegroundColor Cyan
    $sysmonService = Get-Service -Name "Sysmon*" -ErrorAction SilentlyContinue
    if ($sysmonService) {
        if ($sysmonService.Status -ne "Running") {
            $issues += "CRITICAL: Sysmon установлен, но НЕ ЗАПУЩЕН! Статус: $($sysmonService.Status)"
        } else {
            Write-Host "  [OK] Sysmon запущен" -ForegroundColor Green
        }
    } else {
        $issues += "WARNING: Sysmon не установлен"
    }

    # 3. Проверка Windows Event Log Service
    Write-Host "[*] Проверяю Event Log Service..." -ForegroundColor Cyan
    $evtService = Get-Service -Name "EventLog" -ErrorAction SilentlyContinue
    if ($evtService.Status -ne "Running") {
        $issues += "CRITICAL: Event Log Service не запущен!"
    }

    # 4. Проверка PowerShell Script Block Logging
    Write-Host "[*] Проверяю Script Block Logging..." -ForegroundColor Cyan
    $sblKey = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging"
    $sblEnabled = (Get-ItemProperty -Path $sblKey -Name "EnableScriptBlockLogging" -ErrorAction SilentlyContinue).EnableScriptBlockLogging
    if ($sblEnabled -ne 1) {
        $issues += "WARNING: PowerShell Script Block Logging отключён"
    }

    # 5. Проверка недавних очисток логов
    Write-Host "[*] Проверяю очистки журналов (Event 1102)..." -ForegroundColor Cyan
    $cleared = Get-WinEvent -LogName "Security" -FilterXPath "*[System[EventID=1102]]" -MaxEvents 10 -ErrorAction SilentlyContinue
    if ($cleared) {
        foreach ($evt in $cleared) {
            $issues += "ALERT: Журнал Security очищен $($evt.TimeCreated) пользователем $($evt.Properties[1].Value)"
        }
    }

    # 6. Проверка Windows Defender
    Write-Host "[*] Проверяю Windows Defender..." -ForegroundColor Cyan
    $defenderStatus = Get-MpComputerStatus -ErrorAction SilentlyContinue
    if ($defenderStatus) {
        if (-not $defenderStatus.RealTimeProtectionEnabled) {
            $issues += "WARNING: Windows Defender Real-Time Protection отключён"
        }
        if (-not $defenderStatus.BehaviorMonitorEnabled) {
            $issues += "WARNING: Windows Defender Behavior Monitor отключён"
        }
    }

    # Результат
    Write-Host "`n========================================" -ForegroundColor Yellow
    if ($issues.Count -eq 0) {
        Write-Host "[OK] Все защитные механизмы работают нормально." -ForegroundColor Green
    } else {
        Write-Host "[!!!] ОБНАРУЖЕНЫ ПРОБЛЕМЫ: $($issues.Count)" -ForegroundColor Red
        foreach ($issue in $issues) {
            Write-Host "  - $issue" -ForegroundColor Red
        }
    }
    Write-Host "========================================" -ForegroundColor Yellow

    return $issues
}
```

**Python: Мониторинг размера логов (детекция очистки)**

```python
#!/usr/bin/env python3
"""
Мониторинг размера файлов журналов Windows.
Резкое уменьшение размера = возможная очистка.
"""

import os
import json
import time
from pathlib import Path
from datetime import datetime

LOG_DIR = r"C:\Windows\System32\winevt\Logs"
STATE_FILE = "log_sizes_baseline.json"

CRITICAL_LOGS = [
    "Security.evtx",
    "System.evtx",
    "Application.evtx",
    "Microsoft-Windows-Sysmon%4Operational.evtx",
    "Microsoft-Windows-PowerShell%4Operational.evtx",
    "Microsoft-Windows-Windows Defender%4Operational.evtx",
]


def get_log_sizes():
    sizes = {}
    for log_name in CRITICAL_LOGS:
        path = os.path.join(LOG_DIR, log_name)
        if os.path.exists(path):
            sizes[log_name] = os.path.getsize(path)
    return sizes


def save_baseline(sizes):
    with open(STATE_FILE, "w") as f:
        json.dump({"timestamp": datetime.now().isoformat(), "sizes": sizes}, f, indent=2)
    print(f"[*] Baseline сохранён: {len(sizes)} логов")


def check_against_baseline(current):
    if not os.path.exists(STATE_FILE):
        print("[!] Baseline не найден. Создаю...")
        save_baseline(current)
        return

    with open(STATE_FILE) as f:
        baseline = json.load(f)

    alerts = []
    for log_name, current_size in current.items():
        base_size = baseline["sizes"].get(log_name, 0)
        if base_size > 0 and current_size < base_size * 0.5:
            drop_pct = round((1 - current_size / base_size) * 100, 1)
            alerts.append({
                "log": log_name,
                "baseline_size": base_size,
                "current_size": current_size,
                "drop_percent": drop_pct,
            })

    if alerts:
        print(f"\n[!!!] ОБНАРУЖЕНА ВОЗМОЖНАЯ ОЧИСТКА ЛОГОВ:")
        for a in alerts:
```

## Урок 6.5 · AD Persistence: Golden/Silver Ticket, DCSync, SID History

### Теория

**Active Directory** — центральная система аутентификации в корпоративных сетях. Компрометация AD = компрометация всей организации. Атакующие используют несколько техник для долгосрочного persistence в AD:

**Golden Ticket (T1558.001)** — атакующий получает хэш учётной записи `krbtgt` (ключ шифрования всех Kerberos-тикетов в домене) и генерирует TGT (Ticket Granting Ticket) с произвольными привилегиями. Такой тикет действителен 10 лет по умолчанию и даёт доступ ко всему в домене.

**Silver Ticket (T1558.002)** — то же самое, но для конкретного сервиса. Атакующий получает хэш учётной записи сервиса и генерирует TGS (Ticket Granting Service) для этого сервиса. Не требует обращения к DC.

**DCSync (T1003.006)** — имитация контроллера домена для репликации данных. Атакующий с правами «Replicating Directory Changes» запрашивает у DC хэши паролей всех пользователей, включая krbtgt.

**SID History Injection (T1134.005)** — добавление SID привилегированной группы (Domain Admins) в атрибут SID History обычного пользователя. При аутентификации Windows проверяет SID History и даёт соответствующие привилегия.

```powershell
.SYNOPSIS
    Аудит Active Directory на признаки persistence-атак.
    Проверяет: krbtgt, SID History, AdminSDHolder, DCSync-права.
#>

function Invoke-ADSecurityAudit {
    [CmdletBinding()]
    param()

    Import-Module ActiveDirectory -ErrorAction Stop

    $findings = @()

    # 1. Проверка krbtgt — когда последний раз менялся пароль
    Write-Host "[*] Проверяю krbtgt..." -ForegroundColor Cyan
    $krbtgt = Get-ADUser -Identity "krbtgt" -Properties PasswordLastSet
    $daysSinceReset = (New-TimeSpan -Start $krbtgt.PasswordLastSet -End (Get-Date)).Days
    Write-Host "  Пароль krbtgt последний раз менялся: $($krbtgt.PasswordLastSet) ($daysSinceReset дней назад)"

    if ($daysSinceReset -gt 180) {
        $findings += "HIGH: Пароль krbtgt не менялся $daysSinceReset дней (рекомендация: каждые 180 дней)"
    }

    # 2. Проверка SID History
    Write-Host "[*] Проверяю SID History..." -ForegroundColor Cyan
    $usersWithSidHistory = Get-ADUser -Filter * -Properties SIDHistory |
                           Where-Object { $_.SIDHistory.Count -gt 0 }

    if ($usersWithSidHistory) {
        foreach ($u in $usersWithSidHistory) {
            $findings += "CRITICAL: Пользователь $($u.SamAccountName) имеет SID History: $($u.SIDHistory -join ', ')"
        }
    } else {
        Write-Host "  [OK] Нет пользователей с SID History" -ForegroundColor Green
    }

    # 3. Проверка AdminSDHolder — кто имеет права на критические объекты
    Write-Host "[*] Проверяю AdminSDHolder..." -ForegroundColor Cyan
    $protectedUsers = Get-ADUser -Filter { AdminCount -eq 1 } -Properties AdminCount, MemberOf
    Write-Host "  Пользователей с AdminCount=1: $($protectedUsers.Count)"

    $domainAdmins = Get-ADGroupMember -Identity "Domain Admins" -ErrorAction SilentlyContinue
    Write-Host "  Членов Domain Admins: $($domainAdmins.Count)"

    if ($domainAdmins.Count -gt 5) {
        $findings += "WARNING: Слишком много Domain Admins ($($domainAdmins.Count)) — рекомендация: не более 5"
    }

    # 4. Проверка DCSync-прав
    Write-Host "[*] Проверяю DCSync-права..." -ForegroundColor Cyan
    $domain = Get-ADDomain
    $domainDN = $domain.DistinguishedName

    $aclEntries = (Get-Acl "AD:\$domainDN").Access |
        Where-Object {
            $_.ActiveDirectoryRights -match "ExtendedRight" -and
            $_.ObjectType -in @(
                "1131f6aa-9c07-11d1-f79f-00c04fc2dcd2",  # Replicating Directory Changes
                "1131f6ad-9c07-11d1-f79f-00c04fc2dcd2"   # Replicating Directory Changes All
            )
        }

    foreach ($ace in $aclEntries) {
        $identity = $ace.IdentityReference.Value
        if ($identity -notmatch "Domain Controllers|Enterprise Domain Controllers|SYSTEM") {
            $findings += "CRITICAL: Нестандартный субъект с DCSync-правами: $identity"
        }
    }

    # Результат
    Write-Host "`n========================================" -ForegroundColor Yellow
    if ($findings.Count -eq 0) {
        Write-Host "[OK] AD-аудит пройден без критических находок" -ForegroundColor Green
    } else {
        Write-Host "[!!!] НАХОДКИ: $($findings.Count)" -ForegroundColor Red
        foreach ($f in $findings) { Write-Host "  - $f" -ForegroundColor Red }
    }
    Write-Host "========================================`n" -ForegroundColor Yellow

    return $findings
}
```

## Урок 7.1 · C2 обнаружение: DNS tunneling, HTTPS beaconing, domain fronting

### Теория

**Command & Control (C2)** — канал связи между малварью на заражённом хосте и сервером атакующего. Через C2 атакующий отдаёт команды, получает данные, загружает дополнительные инструменты.

**DNS Tunneling (T1071.004)** — использование DNS-запросов для передачи данных. Данные кодируются в поддоменах (base32/base64) и отправляются через DNS-резолвер. Работает даже когда HTTP/HTTPS заблокирован, потому что DNS почти никогда не фильтруют.

Пример: `aGVsbG8gd29ybGQ.data.evil.com` — base64 «hello world» в поддомене.

**HTTPS Beaconing (T1071.001)** — малварь периодически «стучит» (beacon) на C2-сервер через HTTPS. Выглядит как обычный HTTPS-трафик. Ключевой индикатор — регулярность интервалов (jitter).

**Domain Fronting (T1090.004)** — техника маскировки C2 за CDN (CloudFront, Azure CDN). Внешне трафик идёт на docs.google.com, а внутри Host-заголовок указывает на C2-сервер. Очень сложно детектировать.

### Python: Анализ DNS-аномалий

```python
#!/usr/bin/env python3
"""
Детектор DNS tunneling: анализ DNS-логов на аномалии.
Работает с логами Suricata (eve.json) или DNS-логами в формате JSON.
"""

import json
import math
import sys
from collections import Counter, defaultdict
from datetime import datetime


def entropy(s):
    """Вычислить энтропию Шеннона строки."""
    if not s:
        return 0
    freq = Counter(s)
    length = len(s)
    return -sum((count / length) * math.log2(count / length) for count in freq.values())


def analyze_dns_log(filepath, threshold_entropy=3.5, threshold_length=50,
                     threshold_rate=50):
    """
    Анализ DNS-лога на признаки tunneling.

    Параметры:
    - threshold_entropy: порог энтропии поддомена (>3.5 подозрительно)
    - threshold_length: порог длины запроса
    - threshold_rate: порог количества запросов к одному домену за период
    """
    alerts = []
    domain_counts = defaultdict(int)
    domain_queries = defaultdict(list)

    with open(filepath, "r") as f:
        for line in f:
            try:
                record = json.loads(line)
            except json.JSONDecodeError:
                continue

            if record.get("event_type") != "dns":
                continue

            query = record.get("dns", {}).get("rrname", "")
            if not query:
                continue

            timestamp = record.get("timestamp", "")

            parts = query.split(".")
            if len(parts) < 2:
                continue

            base_domain = ".".join(parts[-2:])
            subdomain = ".".join(parts[:-2])

            domain_counts[base_domain] += 1
            domain_queries[base_domain].append({
                "full_query": query,
                "subdomain": subdomain,
                "timestamp": timestamp,
            })

            # Проверка 1: Длинный поддомен
            if len(subdomain) > threshold_length:
                alerts.append({
                    "type": "LONG_SUBDOMAIN",
                    "query": query,
                    "subdomain_length": len(subdomain),
                    "timestamp": timestamp,
                    "severity": "HIGH",
                })

            # Проверка 2: Высокая энтропия
            ent = entropy(subdomain)
            if ent > threshold_entropy and len(subdomain) > 10:
                alerts.append({
                    "type": "HIGH_ENTROPY",
                    "query": query,
                    "entropy": round(ent, 2),
                    "timestamp": timestamp,
                    "severity": "MEDIUM",
                })

    # Проверка 3: Высокая частота запросов к одному домену
    for domain, count in domain_counts.items():
        if count > threshold_rate:
            alerts.append({
                "type": "HIGH_RATE",
                "domain": domain,
                "count": count,
                "severity": "HIGH",
            })

    return alerts, dict(domain_counts)


def main():
    if len(sys.argv) < 2:
        print("Использование: python dns_tunnel_detector.py <eve.json>")
        sys.exit(1)

    filepath = sys.argv[1]
    print(f"[*] Анализирую DNS-логи: {filepath}")

    alerts, stats = analyze_dns_log(filepath)

    print(f"\n[*] Статистика:")
    print(f"    Уникальных доменов: {len(stats)}")
    top5 = sorted(stats.items(), key=lambda x: x[1], reverse=True)[:5]
    for domain, count in top5:
        print(f"    {domain}: {count} запросов")

    if alerts:
        print(f"\n[!!!] АЛЕРТЫ: {len(alerts)}")
        for a in alerts:
            print(f"  [{a['severity']}] {a['type']}: {a.get('query', a.get('domain', 'N/A'))}")
            if 'entropy' in a:
                print(f"         Энтропия: {a['entropy']}")
            if 'count' in a:
                print(f"         Запросов: {a['count']}")
    else:
        print("\n[OK] Аномалий не обнаружено.")

    output = filepath.replace(".json", "_dns_alerts.json")
    with open(output, "w", encoding="utf-8") as f:
        json.dump({"alerts": alerts, "stats": stats}, f, indent=2, ensure_ascii=False)
    print(f"\n[*] Сохранено: {output}")


if __name__ == "__main__":
    main()
```

## Урок 7.2 · LOLBins и fileless атаки — детекция

### Теория

### PowerShell: Мониторинг LOLBins

```powershell
<#
.SYNOPSIS
    Монитор LOLBins — поиск подозрительного использования системных утилит.
    Анализирует Sysmon-логи (Event ID 1 — Process Create).
#>

function Find-SuspiciousLOLBins {
    param(
        [int]$Hours = 24
    )

    $startTime = (Get-Date).AddHours(-$Hours)

    $lolbins = @{
        "certutil.exe"  = @("urlcache", "decode", "encode", "-f http")
        "mshta.exe"     = @("http://", "https://", "javascript:", "vbscript:")
        "regsvr32.exe"  = @("/i:http", "scrobj.dll")
        "rundll32.exe"  = @("javascript:", "http://", "shell32.dll,Control_RunDLL")
        "bitsadmin.exe" = @("/transfer", "/addfile", "http")
        "wmic.exe"      = @("process call create", "/node:", "os get")
        "msiexec.exe"   = @("/i http", "/q http", "/i https")
        "cscript.exe"   = @("http://", "https://", ".vbs")
        "wscript.exe"   = @("http://", "https://", ".vbs")
    }

    $alerts = @()

    Write-Host "[*] Анализирую Sysmon Event ID 1 за последние $Hours часов..." -ForegroundColor Cyan

    $events = Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -FilterXPath "*[System[EventID=1 and TimeCreated[timediff(@SystemTime) <= $($Hours * 3600000)]]]" -ErrorAction SilentlyContinue

    foreach ($evt in $events) {
        $image = ($evt.Properties | Where-Object { $_.Value -match '\.exe$' } | Select-Object -First 1).Value
        $cmdLine = ($evt.Properties[10]).Value  # CommandLine

        if (-not $image -or -not $cmdLine) { continue }

        $exeName = [System.IO.Path]::GetFileName($image).ToLower()

        if ($lolbins.ContainsKey($exeName)) {
            $suspiciousArgs = $lolbins[$exeName]
            foreach ($arg in $suspiciousArgs) {
                if ($cmdLine -match [regex]::Escape($arg)) {
                    $alerts += [PSCustomObject]@{
                        Time       = $evt.TimeCreated
                        LOLBin     = $exeName
                        CommandLine = $cmdLine
                        User       = ($evt.Properties[12]).Value
                        PID        = ($evt.Properties[3]).Value
                        ParentPID  = ($evt.Properties[19]).Value
                        Trigger    = $arg
                        Severity   = "HIGH"
                    }
                    break
                }
            }
        }
    }

    Write-Host "[+] Найдено подозрительных LOLBin-вызовов: $($alerts.Count)" -ForegroundColor $(if ($alerts.Count -gt 0) {"Red"} else {"Green"})
    $alerts | Format-Table Time, LOLBin, Trigger, User -AutoSize

    return $alerts
}

# Find-SuspiciousLOLBins -Hours 48
```

## Урок 7.3 · Process Injection: DLL injection, hollowing, APC — обнаружение

### Теория

**Process Injection (T1055)** — атакующий внедряет код в адресное пространство другого (легитимного) процесса. Это позволяет: скрыть вредоносный код за доверенным процессом, обойти application whitelisting, получить доступ к данным процесса.

**Основные методы:**

| Метод | Описание | Sysmon Events |
|-------|----------|---------------|
| DLL Injection | Загрузка вредоносной DLL в чужой процесс через CreateRemoteThread | 8 (CreateRemoteThread) |

| Thread Hijacking | Перехват существующего потока | 8, 10 |

## Урок 7.4 · Lateral Movement: Pass-the-Hash, PsExec, WinRM, RDP

### Теория

**Lateral Movement (TA0008)** — перемещение атакующего по сети от одного хоста к другому. После начальной компрометации атакующий «прыгает» на соседние машины, расширяя контроль.

**Pass-the-Hash (T1550.002)** — использование NTLM-хэша пароля (без знания самого пароля) для аутентификации. Windows принимает хэш вместо пароля при NTLM-аутентификации.

**PsExec / SMB Execution (T1570)** — удалённое выполнение команд через SMB. Создаёт сервис на удалённой машине, запускает его, получает результат.

**WinRM (T1021.006)** — Windows Remote Management. PowerShell Remoting использует WinRM (порт 5985/5986). Легитимный инструмент администрирования, часто используемый атакующими.

**RDP (T1021.001)** — Remote Desktop Protocol. Атакующий подключается к рабочему столу удалённой машины.

### Ключевые Event ID

| Technique | Event ID | Log | Что фиксирует |
|-----------|----------|-----|---------------|
| PtH/PsExec | 4624 (Type 3) | Security | Network logon |
| PtH | 4624 (NTLM) | Security | NTLM вместо Kerberos |
| PsExec | 7045 | System | Создание сервиса PSEXESVC |
| PsExec | 5145 | Security | Доступ к ADMIN$ share |
| WinRM | 4624 (Type 3) | Security | Network logon через WinRM |
| WinRM | 91 | WinRM | Session created |
| RDP | 4624 (Type 10) | Security | RemoteInteractive logon |
| RDP | 1149 | TerminalServices | RDP connection |

## Урок 7.5 · Credential Dumping: LSASS, SAM, NTDS.dit — защита

### Теория

**Credential Dumping (T1003)** — извлечение учётных данных (хэши паролей, Kerberos-тикеты, пароли в открытом виде) из памяти или файлов системы. Это ключевой шаг для lateral movement.

```powershell
# 1. Включить Credential Guard
# (защищает LSASS через виртуализацию)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Lsa" /v LsaCfgFlags /t REG_DWORD /d 1 /f
reg add "HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard" /v EnableVirtualizationBasedSecurity /t REG_DWORD /d 1 /f

# 2. Включить RunAsPPL (Protected Process Light для LSASS)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Lsa" /v RunAsPPL /t REG_DWORD /d 1 /f

# 3. Установить LAPS (Local Administrator Password Solution)
# LAPS автоматически ротирует пароли локальных админов
# Скачайте с Microsoft и установите:
# msiexec /i LAPS.x64.msi /quiet

# 4. Отключить WDigest (хранение паролей в открытом виде)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest" /v UseLogonCredential /t REG_DWORD /d 0 /f

# 5. Проверка текущего состояния
Write-Host "=== Credential Protection Status ===" -ForegroundColor Cyan
$lsaPPL = (Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\Lsa" -Name "RunAsPPL" -ErrorAction SilentlyContinue).RunAsPPL
$wdigest = (Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest" -Name "UseLogonCredential" -ErrorAction SilentlyContinue).UseLogonCredential
$credGuard = (Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Control\Lsa" -Name "LsaCfgFlags" -ErrorAction SilentlyContinue).LsaCfgFlags

Write-Host "  RunAsPPL (LSASS Protected): $(if ($lsaPPL -eq 1) {'ENABLED'} else {'DISABLED'})"
Write-Host "  WDigest (plaintext passwords): $(if ($wdigest -eq 0) {'DISABLED (safe)'} else {'ENABLED (dangerous!)'})"
Write-Host "  Credential Guard: $(if ($credGuard -ge 1) {'ENABLED'} else {'DISABLED'})"
```

## Урок 8.1 · Ransomware: поведенческое обнаружение и предотвращение

### Теория

**Ransomware (T1486)** — вредоносное ПО, которое шифрует файлы жертвы и требует выкуп за расшифровку. Это одна из самых разрушительных атак: средний ущерб от инцидента — миллионы рублей, а recovery может занять недели.

**Ключевые поведенческие индикаторы:**

| Индикатор | Описание |
|-----------|----------|
| Массовое переименование файлов | Файлы получают новое расширение (.encrypted, .locked) |
| Удаление Volume Shadow Copies | `vssadmin delete shadows /all /quiet` |
| Изменение множества файлов за короткое время | Entropy файлов резко растёт |
| Создание ransom note | README.txt, DECRYPT.html в каждой папке |
| Остановка сервисов | SQL, Exchange, backup-сервисы останавливаются |

### Canary Files — техника раннего обнаружения

**Идея:** разместить специальные файлы-приманки (canary) в важных директориях. Легитимные пользователи их не трогают, но ransomware шифрует всё подряд. Изменение canary-файла = алерт.

```python
#!/usr/bin/env python3
"""
Canary Files Monitor — ранняя детекция ransomware.
Создаёт файлы-приманки и мониторит их изменение.
"""

import os
import hashlib
import json
import time
import sys
from pathlib import Path
from datetime import datetime

CANARY_CONTENT = "This file is used for ransomware detection monitoring. DO NOT MODIFY."
STATE_FILE = "canary_state.json"

WATCH_DIRS = [
    r"C:\Users\Public\Documents",
    r"C:\Users\Public\Desktop",
    r"C:\Shares\Finance",
    r"C:\Shares\HR",
]

CANARY_NAMES = [
    "~$budget_2026.xlsx",
    "~$quarterly_report.docx",
    "~$passwords.txt",
    "_DO_NOT_DELETE_monitoring.dat",
]


def sha256(filepath):
    h = hashlib.sha256()
    with open(filepath, "rb") as f:
        h.update(f.read())
    return h.hexdigest()


def create_canaries():
    created = []
    for dir_path in WATCH_DIRS:
        os.makedirs(dir_path, exist_ok=True)
        for name in CANARY_NAMES:
            fpath = os.path.join(dir_path, name)
            if not os.path.exists(fpath):
                with open(fpath, "w") as f:
                    f.write(CANARY_CONTENT)
                os.system(f'attrib +h +s "{fpath}"')  # скрытый + системный
                created.append(fpath)

    state = {}
    for dir_path in WATCH_DIRS:
        for name in CANARY_NAMES:
            fpath = os.path.join(dir_path, name)
            if os.path.exists(fpath):
                state[fpath] = {
                    "hash": sha256(fpath),
                    "size": os.path.getsize(fpath),
                    "mtime": os.path.getmtime(fpath),
                }

    with open(STATE_FILE, "w") as f:
        json.dump(state, f, indent=2)

    print(f"[+] Создано canary-файлов: {len(created)}")
    print(f"[+] State сохранён: {STATE_FILE}")
    return state


def check_canaries():
    if not os.path.exists(STATE_FILE):
        print("[!] State не найден. Запустите с параметром --create")
        sys.exit(1)

    with open(STATE_FILE) as f:
        state = json.load(f)

    alerts = []
    for fpath, baseline in state.items():
        if not os.path.exists(fpath):
            alerts.append({
                "type": "DELETED",
                "file": fpath,
                "severity": "CRITICAL",
                "message": f"Canary-файл УДАЛЁН: {fpath}",
            })
            continue

        current_hash = sha256(fpath)
        current_size = os.path.getsize(fpath)

        if current_hash != baseline["hash"]:
            alerts.append({
                "type": "MODIFIED",
                "file": fpath,
                "severity": "CRITICAL",
                "message": f"Canary-файл ИЗМЕНЁН: {fpath}",
                "old_hash": baseline["hash"][:16] + "...",
                "new_hash": current_hash[:16] + "...",
            })

    if alerts:
        print(f"\n{'='*60}")
        print(f"[!!!] RANSOMWARE ALERT — {len(alerts)} canary-файлов скомпрометированы!")
        print(f"{'='*60}")
        for a in alerts:
            print(f"  [{a['severity']}] {a['type']}: {a['file']}")
        print(f"\nДЕЙСТВИЯ:")
        print(f"  1. Изолировать хост от сети НЕМЕДЛЕННО")
        print(f"  2. Снять дамп памяти")
        print(f"  3. Уведомить IR-команду")
        print(f"  4. НЕ выключать машину (данные в памяти)")
    else:
        print(f"[OK] Все {len(state)} canary-файлов в норме. ({datetime.now()})")

    return alerts


if __name__ == "__main__":
    if "--create" in sys.argv:
        create_canaries()
    else:
        check_canaries()
```

### Python: Анализ email-заголовков

```python
#!/usr/bin/env python3
"""
Анализатор email-заголовков для обнаружения фишинга.
"""

import email
import re
import sys
from email import policy


def analyze_headers(eml_path):
    with open(eml_path, "rb") as f:
        msg = email.message_from_binary_file(f, policy=policy.default)

    findings = []

    # 1. Проверка SPF
    auth_results = msg.get("Authentication-Results", "")
    if "spf=fail" in auth_results or "spf=softfail" in auth_results:
        findings.append("WARNING: SPF FAILED — отправитель не авторизован")
    elif "spf=pass" in auth_results:
        print("[OK] SPF: pass")

    # 2. Проверка DKIM
    if "dkim=fail" in auth_results:
        findings.append("WARNING: DKIM FAILED — подпись недействительна")
    elif "dkim=pass" in auth_results:
        print("[OK] DKIM: pass")

    # 3. Проверка DMARC
    if "dmarc=fail" in auth_results:
        findings.append("CRITICAL: DMARC FAILED")

    # 4. Несоответствие From и Return-Path
    from_header = msg.get("From", "")
    return_path = msg.get("Return-Path", "")
    from_domain = re.search(r"@([\w.-]+)", from_header)
    return_domain = re.search(r"@([\w.-]+)", return_path)

    if from_domain and return_domain:
        if from_domain.group(1) != return_domain.group(1):
            findings.append(f"WARNING: From domain ({from_domain.group(1)}) != Return-Path ({return_domain.group(1)})")

    # 5. Подозрительные заголовки
    x_mailer = msg.get("X-Mailer", "")
    if x_mailer and ("PHP" in x_mailer or "Python" in x_mailer):
        findings.append(f"WARNING: Подозрительный X-Mailer: {x_mailer}")

    # Результат
    if findings:
        print(f"\n[!!!] ПОДОЗРИТЕЛЬНОЕ ПИСЬМО — {len(findings)} находок:")
        for f_item in findings:
            print(f"  - {f_item}")
    else:
        print("\n[OK] Заголовки выглядят нормально")

    return findings


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Использование: python email_analyzer.py <message.eml>")
        sys.exit(1)
    analyze_headers(sys.argv[1])
```

```bash
echo "[10/10] Проверка anti-forensics..."
{
    echo "=== Anti-Forensics Check ==="

    # Пустые логи
    for log in /var/log/auth.log /var/log/syslog /var/log/messages; do
        if [ -f "$log" ] && [ ! -s "$log" ]; then
            echo "ALERT: $log существует, но пуст (возможная очистка)"
        fi
    done

    # .bash_history пуст или удалён
    for home in /root /home/*; do
        hist="$home/.bash_history"
        if [ -d "$home" ] && { [ ! -f "$hist" ] || [ ! -s "$hist" ]; }; then
            echo "ALERT: $hist отсутствует или пуст (возможная очистка)"
        fi
    done

    # Проверка secure_delete / shred
    which shred >/dev/null 2>&1 && echo "INFO: shred установлен"
    which srm >/dev/null 2>&1 && echo "ALERT: secure-delete (srm) установлен"

} > "$OUTDIR/anti_forensics_check.txt"

echo ""
echo "=== Триаж завершён ==="
echo "Результаты: $OUTDIR"
echo "Файлов: $(ls $OUTDIR | wc -l)"
tar czf "${OUTDIR}.tar.gz" -C "$(dirname $OUTDIR)" "$(basename $OUTDIR)" 2>/dev/null
echo "Архив: ${OUTDIR}.tar.gz"
```

### PowerShell: Форензик-триаж Windows

```powershell
<#
.SYNOPSIS
    Быстрый форензик-триаж Windows-системы.
    Собирает ключевые артефакты для анализа инцидента.
#>

$OutDir = "C:\ForensicTriage_$(hostname)_$(Get-Date -Format yyyyMMdd_HHmmss)"
New-Item -ItemType Directory -Path $OutDir -Force | Out-Null

Write-Host "=== Форензик-триаж: $env:COMPUTERNAME ===" -ForegroundColor Cyan
Write-Host "Результаты: $OutDir"

# 1. Процессы
Get-Process | Select-Object Id, ProcessName, Path, StartTime, CPU |
    Export-Csv "$OutDir\processes.csv" -NoTypeInformation

# 2. Сетевые соединения
Get-NetTCPConnection | Select-Object LocalAddress, LocalPort, RemoteAddress, RemotePort, State, OwningProcess |
    Export-Csv "$OutDir\network.csv" -NoTypeInformation

# 3. Автозапуск
Get-CimInstance Win32_StartupCommand |
    Export-Csv "$OutDir\startup.csv" -NoTypeInformation

# 4. Сервисы
Get-CimInstance Win32_Service | Select-Object Name, State, StartMode, PathName |
    Export-Csv "$OutDir\services.csv" -NoTypeInformation

# 5. Scheduled Tasks
Get-ScheduledTask | Where-Object { $_.State -ne 'Disabled' } |
    Select-Object TaskName, TaskPath, State |
    Export-Csv "$OutDir\tasks.csv" -NoTypeInformation

# 6. Последние установленные программы
Get-CimInstance Win32_Product | Select-Object Name, Version, InstallDate |
    Export-Csv "$OutDir\installed.csv" -NoTypeInformation

# 7. Event Logs (последние 100 Security)
Get-WinEvent -LogName Security -MaxEvents 100 |
    Select-Object TimeCreated, Id, Message |
    Export-Csv "$OutDir\security_events.csv" -NoTypeInformation

# 8. Prefetch файлы
Get-ChildItem "C:\Windows\Prefetch\*.pf" -ErrorAction SilentlyContinue |
    Select-Object Name, CreationTime, LastWriteTime, Length |
    Export-Csv "$OutDir\prefetch.csv" -NoTypeInformation

# 9. Anti-forensics check
$antiForensics = @()
$secLog = Get-WinEvent -LogName Security -FilterXPath "*[System[EventID=1102]]" -MaxEvents 5 -ErrorAction SilentlyContinue
if ($secLog) {
    $antiForensics += "ALERT: Security log was cleared at $($secLog[0].TimeCreated)"
}
$prefetchCount = (Get-ChildItem "C:\Windows\Prefetch\*.pf" -ErrorAction SilentlyContinue).Count
if ($prefetchCount -lt 10) {
    $antiForensics += "WARNING: Only $prefetchCount prefetch files (possible deletion)"
}
$antiForensics | Out-File "$OutDir\anti_forensics.txt"

Write-Host "[+] Триаж завершён. Файлов: $((Get-ChildItem $OutDir).Count)" -ForegroundColor Green

Compress-Archive -Path $OutDir -DestinationPath "$OutDir.zip"
Write-Host "[+] Архив: $OutDir.zip" -ForegroundColor Green
```
