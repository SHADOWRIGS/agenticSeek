## Модуль 26: Обнаружение сетевого сканирования — Network Scanning Detection

### Что это за угроза

Сетевое сканирование — первый шаг любой атаки. Злоумышленник использует инструменты (Nmap, Masscan, Zmap, RustScan) для определения живых хостов, открытых портов и топологии сети. Задача защитника — обнаружить сканирование на ранней стадии и заблокировать источник до перехода к эксплуатации.

**MITRE ATT&CK:** T1046 — Network Service Discovery, T1018 — Remote System Discovery

### Индикаторы компрометации (IoC)

- Множественные SYN-пакеты к разным портам одного хоста за короткий промежуток (< 5 секунд)
- Пакеты с необычными TCP-флагами: FIN без предшествующего соединения, XMAS (FIN+PSH+URG), NULL (без флагов)
- ICMP Echo Request к последовательным IP-адресам (ping sweep)
- ARP-запросы к большому количеству адресов подсети
- Соединения к портам, на которых нет сервисов (honeypot-порты)
- Аномально высокая скорость новых TCP-соединений от одного IP

**Артефакты в логах:**

#### Скрипт обнаружения на Python (анализ логов firewall)

```python
#!/usr/bin/env python3
"""scan_detector.py — обнаружение сканирования в логах iptables/nftables."""

import re
import sys
from collections import defaultdict
from datetime import datetime, timedelta

THRESHOLD_PORTS = 15       # Уникальных портов
THRESHOLD_SECONDS = 30     # За период (секунды)

def parse_firewall_log(logfile):
    pattern = re.compile(
        r'(\w+ \d+ [\d:]+).*SRC=([\d.]+).*DPT=(\d+)'
    )
    connections = defaultdict(list)

    with open(logfile) as f:
        for line in f:
            m = pattern.search(line)
            if m:
                timestamp_str, src_ip, dst_port = m.groups()
                ts = datetime.strptime(
                    f"2026 {timestamp_str}", "%Y %b %d %H:%M:%S"
                )
                connections[src_ip].append((ts, int(dst_port)))

    alerts = []
    for ip, conns in connections.items():
        conns.sort()
        window_start = 0
        for i, (ts, port) in enumerate(conns):
            while (ts - conns[window_start][0]).total_seconds() > THRESHOLD_SECONDS:
                window_start += 1
            unique_ports = len(set(c[1] for c in conns[window_start:i+1]))
            if unique_ports >= THRESHOLD_PORTS:
                alerts.append({
                    'ip': ip,
                    'time': ts.isoformat(),
                    'unique_ports': unique_ports,
                    'severity': 'CRITICAL' if unique_ports > 50 else 'HIGH'
                })
                break

    return alerts

if __name__ == '__main__':
    logfile = sys.argv[1] if len(sys.argv) > 1 else '/var/log/syslog'
    for alert in parse_firewall_log(logfile):
        print(f"[{alert['severity']}] Сканирование от {alert['ip']} "
              f"в {alert['time']}: {alert['unique_ports']} портов")
```

### Защита и предотвращение

#### 1. Настройка iptables для ограничения сканирования

```bash
#!/bin/bash
# anti_scan.sh — защита от сканирования портов через iptables

# Создать цепочку для обнаружения сканирования
iptables -N SCAN_DETECT 2>/dev/null

# Логирование и блокировка XMAS-сканирования
iptables -A SCAN_DETECT -p tcp --tcp-flags ALL FIN,PSH,URG -j LOG \
  --log-prefix "[XMAS_SCAN] " --log-level 4
iptables -A SCAN_DETECT -p tcp --tcp-flags ALL FIN,PSH,URG -j DROP

# Логирование и блокировка NULL-сканирования
iptables -A SCAN_DETECT -p tcp --tcp-flags ALL NONE -j LOG \
  --log-prefix "[NULL_SCAN] " --log-level 4
iptables -A SCAN_DETECT -p tcp --tcp-flags ALL NONE -j DROP

# Ограничение скорости новых TCP-соединений (rate limiting)
iptables -A INPUT -p tcp --syn -m recent --name scanners --set
iptables -A INPUT -p tcp --syn -m recent --name scanners --update \
  --seconds 10 --hitcount 20 -j LOG --log-prefix "[PORT_SCAN] "
iptables -A INPUT -p tcp --syn -m recent --name scanners --update \
  --seconds 10 --hitcount 20 -j DROP

# Подключить цепочку SCAN_DETECT
iptables -A INPUT -j SCAN_DETECT
```

## Модуль 27: Обнаружение и предотвращение сканирования портов — Port Scan Detection & Prevention

### Что это за угроза

Сканирование портов — целенаправленная разведка конкретного хоста для определения открытых портов и доступных сервисов. В отличие от сетевого сканирования (модуль 26), здесь атакующий уже выбрал цель и углубляется. Методы варьируются от грубого TCP Connect до скрытного idle scan.

**MITRE ATT&CK:** T1046 — Network Service Discovery

### Индикаторы компрометации (IoC)

- TCP SYN к десяткам портов одного хоста за секунды
- RST-ответы на большинство попыток (закрытые порты)
- UDP-пакеты к диапазону портов (UDP scan)
- Характерный TTL и Window Size для известных сканеров:
  - Nmap SYN scan: window=1024
  - Masscan: ttl=255, window=1024
  - Zmap: window=65535, специфичный IP-ID
- ACK-пакеты без предшествующего SYN (ACK scan для определения файрволов)

**Ключевые логи:**
```
# Linux conntrack log
conntrack -E -e NEW -p tcp | grep -c "SRC=suspicious_ip"

# Zeek (Bro) conn.log
# Много записей с одинаковым id.orig_h и разными id.resp_p

1636589673.234567 CHhAvVGS1DHFjwGM9 10.0.0.55 54322 192.168.1.10 80 tcp ...
```

#### Zeek-скрипт для обнаружения сканирования

```zeek
# scan_detect.zeek — обнаружение сканирования портов в Zeek
@load base/frameworks/notice

module ScanDetect;

export {
    redef enum Notice::Type += {
        Port_Scan_Detected,
        Slow_Port_Scan_Detected
    };

    const scan_threshold = 15 &redef;
    const scan_interval = 30sec &redef;
}

global scan_attempts: table[addr] of set[port]
    &create_expire=1min;

event connection_attempt(c: connection)
{
    local scanner = c$id$orig_h;
    local target_port = c$id$resp_p;

    if ( scanner !in scan_attempts )
        scan_attempts[scanner] = set();

    add scan_attempts[scanner][target_port];

    if ( |scan_attempts[scanner]| >= scan_threshold )
    {
        NOTICE([
            $note=Port_Scan_Detected,
            $src=scanner,
            $msg=fmt("Хост %s просканировал %d портов", scanner,
                     |scan_attempts[scanner]|),
            $identifier=cat(scanner)
        ]);
        delete scan_attempts[scanner];
    }
}
```

### Защита и предотвращение

#### 1. nftables — комплексная защита

```bash
#!/usr/sbin/nft -f
# /etc/nftables.d/anti-portscan.nft

table inet anti_scan {
    set scanners_v4 {
        type ipv4_addr
        flags dynamic,timeout
        timeout 1h
    }

    chain input {
        type filter hook input priority -10; policy accept;

        # Блокировка уже отмеченных сканеров
        ip saddr @scanners_v4 counter drop

        # Обнаружение: > 15 новых TCP за 10 секунд
        tcp flags syn ct state new \
          meter portscan_meter { ip saddr limit rate over 15/second } \
          add @scanners_v4 { ip saddr } \
          log prefix "PORTSCAN_BLOCKED " \
          counter drop

        # Блокировка аномальных TCP-флагов
        tcp flags & (fin|syn|rst|psh|ack|urg) == fin|psh|urg \
          log prefix "XMAS_SCAN " counter drop
        tcp flags & (fin|syn|rst|psh|ack|urg) == 0x0 \
          log prefix "NULL_SCAN " counter drop
    }
}
```

## Модуль 28: Обнаружение перечисления сервисов — Service Enumeration Detection

### Что это за угроза

После определения открытых портов атакующий переходит к определению версий и типов запущенных сервисов (banner grabbing, version detection). Это позволяет найти конкретные уязвимости. Инструменты: `nmap -sV`, `Nikto`, `WhatWeb`, ручное подключение через netcat/telnet.

**MITRE ATT&CK:** T1046 — Network Service Discovery

### Индикаторы компрометации (IoC)

- Подключения к портам с отправкой минимальных данных и немедленным отключением (banner grab)
- HTTP-запросы с характерными User-Agent: `Nmap Scripting Engine`, `Nikto`, `WhatWeb`
- Последовательные подключения к множеству сервисов одного хоста с чтением баннера
- Характерные зонды Nmap service detection (NULL probe, GenericLines, GetRequest, HTTPOptions)
- Запросы OPTIONS / HEAD к веб-серверам для определения допустимых методов

**Артефакты:**
```
# Apache access.log — Nmap HTTP probe
10.0.0.55 - - [11/Nov/2026:02:15:00] "GET / HTTP/1.0" 200 1234 "-" "-"
10.0.0.55 - - [11/Nov/2026:02:15:00] "OPTIONS / HTTP/1.1" 200 0 "-" "Mozilla/5.0"

# SSH auth.log — banner grab (подключение без аутентификации)
Nov 11 02:15:01 server sshd[1234]: Connection from 10.0.0.55 port 54321 
  on 192.168.1.10 port 22 rdomain ""
Nov 11 02:15:01 server sshd[1234]: Received disconnect from 10.0.0.55 port 54321:
  11: [preauth]
```

## Модуль 29: Обнаружение DNS-разведки — DNS Reconnaissance Detection

### Что это за угроза

DNS-разведка — сбор информации о домене через DNS: передача зоны (AXFR), перечисление записей, brute-force субдоменов, reverse DNS lookup. Позволяет атакующему составить карту инфраструктуры без единого прямого соединения с целевыми серверами.

**MITRE ATT&CK:** T1596.001 — Search Open Technical Databases: DNS/Passive DNS

### Индикаторы компрометации (IoC)

- Запросы AXFR (передача зоны) от неавторизованных IP
- Большое количество DNS-запросов типа A/AAAA к несуществующим субдоменам (NXDOMAIN)
- Запросы ANY для получения всех записей
- Reverse DNS lookup для последовательных IP-адресов
- Запросы TXT, MX, NS, SOA, SRV из внешней сети
- Нетипичный объём DNS-трафика от одного источника

#### Скрипт мониторинга DNS-запросов

```python
#!/usr/bin/env python3
"""dns_recon_detector.py — мониторинг DNS-логов для обнаружения разведки."""

import re
import sys
from collections import defaultdict, Counter

NXDOMAIN_THRESHOLD = 30     # NXDOMAIN за период
QUERY_RATE_THRESHOLD = 100  # Запросов за 60 секунд

def analyze_dns_log(logfile):
    nxdomain_by_ip = defaultdict(int)
    queries_by_ip = defaultdict(int)
    axfr_attempts = []
    query_types = defaultdict(lambda: Counter())

    pattern = re.compile(
        r'client.*?(\d+\.\d+\.\d+\.\d+)#\d+.*?query:\s+(\S+)\s+IN\s+(\w+)'
    )
    nxdomain_pattern = re.compile(
        r'client.*?(\d+\.\d+\.\d+\.\d+).*NXDOMAIN'
    )

    with open(logfile) as f:
        for line in f:
            m = pattern.search(line)
            if m:
                ip, domain, qtype = m.groups()
                queries_by_ip[ip] += 1
                query_types[ip][qtype] += 1

                if qtype == 'AXFR':
                    axfr_attempts.append((ip, domain))

            mx = nxdomain_pattern.search(line)
            if mx:
                nxdomain_by_ip[mx.group(1)] += 1

    alerts = []
    for ip, attempts in axfr_attempts:
        alerts.append(f"[CRITICAL] AXFR-запрос от {ip} к домену {attempts}")

    for ip, count in nxdomain_by_ip.items():
        if count > NXDOMAIN_THRESHOLD:
            alerts.append(
                f"[HIGH] DNS brute-force от {ip}: {count} NXDOMAIN-ответов"
            )

    for ip, count in queries_by_ip.items():
        if count > QUERY_RATE_THRESHOLD:
            types = dict(query_types[ip])
            alerts.append(
                f"[MEDIUM] Высокая DNS-активность от {ip}: {count} запросов, "
                f"типы: {types}"
            )

    return alerts

if __name__ == '__main__':
    logfile = sys.argv[1] if len(sys.argv) > 1 else '/var/log/named/query.log'
    for alert in analyze_dns_log(logfile):
        print(alert)
```

- Использование SNMPv1/v2c (без шифрования)

#### 2. Мониторинг Certificate Transparency

```python
#!/usr/bin/env python3
"""ct_monitor.py — мониторинг новых сертификатов для домена через CT логи."""

import json
import urllib.request
import sys

def check_ct_logs(domain):
    url = f"https://crt.sh/?q=%.{domain}&output=json"
    req = urllib.request.Request(url, headers={'User-Agent': 'CT-Monitor/1.0'})
    try:
        with urllib.request.urlopen(req, timeout=30) as resp:
            certs = json.loads(resp.read())
    except Exception as e:
        print(f"Ошибка: {e}")
        return

    subdomains = set()
    for cert in certs:
        name = cert.get('name_value', '')
        for line in name.split('\n'):
            line = line.strip().lower()
            if line.endswith(f'.{domain}') or line == domain:
                subdomains.add(line)

    print(f"Найдено {len(subdomains)} субдоменов для {domain}:")
    for sd in sorted(subdomains):
        print(f"  {sd}")

if __name__ == '__main__':
    domain = sys.argv[1] if len(sys.argv) > 1 else 'example.com'
    check_ct_logs(domain)
```

#### 3. Инвентаризация и очистка субдоменов

```bash

dig -t AXFR example.com @ns1.example.com  # только с авторизованного сервера

# Удаление устаревших субдоменов (dangling DNS)
# Проверить, что каждый субдомен ведёт на живой ресурс
for sub in $(cat subdomains.txt); do
    ip=$(dig +short $sub)
    if [ -z "$ip" ] || ! ping -c 1 -W 2 "$ip" > /dev/null 2>&1; then
        echo "DANGLING: $sub -> $ip"
    fi
done
```

#### Скрипт обнаружения deauth-атак

```python
#!/usr/bin/env python3
"""deauth_detector.py — обнаружение deauthentication-атак."""

# Требует: pip install scapy
# Запуск: sudo python3 deauth_detector.py wlan0mon

import sys

try:
    from scapy.all import sniff, Dot11, Dot11Deauth
except ImportError:
    print("Установите scapy: pip install scapy")
    sys.exit(1)

from collections import defaultdict
import time

THRESHOLD = 10  # Deauth-фреймов за интервал
INTERVAL = 5    # Секунды

deauth_count = defaultdict(int)
last_reset = time.time()

def detect_deauth(pkt):
    global last_reset
    now = time.time()

    if now - last_reset > INTERVAL:
        for src, count in deauth_count.items():
            if count > THRESHOLD:
                print(f"[ALERT] Deauth-атака от {src}: "
                      f"{count} фреймов за {INTERVAL}с")
        deauth_count.clear()
        last_reset = now

    if pkt.haslayer(Dot11Deauth):
        src = pkt[Dot11].addr2
        if src:
            deauth_count[src] += 1

if __name__ == '__main__':
    iface = sys.argv[1] if len(sys.argv) > 1 else 'wlan0mon'
    print(f"Мониторинг deauth-атак на {iface}...")
    sniff(iface=iface, prn=detect_deauth, store=0)
```

## Модуль 40: Обнаружение атак на цепочку поставок — Supply Chain Attack Detection

## Модуль 41: Обнаружение Credential Stuffing — Credential Stuffing Detection

### Что это за угроза

Credential stuffing — массовая проверка украденных пар «логин/пароль» из утечек на различных сервисах. Автоматизированные атаки с использованием ботнетов, TOR, прокси-сетей. Отличается от brute-force тем, что используются реальные пароли из дампов.

**MITRE ATT&CK:** T1110.004 — Brute Force: Credential Stuffing

### Индикаторы компрометации (IoC)

- Массовые неудачные аутентификации с разными логинами от одного IP или диапазона
- Аутентификация с TOR exit-нод или известных прокси
- Аномальный User-Agent (отсутствие или нетипичный)
- Высокая скорость попыток аутентификации (> 1 в секунду)
- Географически распределённые IP (ботнет)
- Успешный вход после серии неудачных с разными учётками

**Логи:**
```
# Nginx — массовые POST к /login
10.0.0.55 - - [11/Nov/2026:02:40:00] "POST /api/login HTTP/1.1" 401 45 
10.0.0.55 - - [11/Nov/2026:02:40:00] "POST /api/login HTTP/1.1" 401 45
10.0.0.55 - - [11/Nov/2026:02:40:01] "POST /api/login HTTP/1.1" 401 45
10.0.0.55 - - [11/Nov/2026:02:40:01] "POST /api/login HTTP/1.1" 200 128  # Успех!
```

#### Скрипт обнаружения

```python
#!/usr/bin/env python3
"""credential_stuffing_detector.py — обнаружение stuffing-атак в auth-логах."""

import re
import sys
from collections import defaultdict

FAIL_THRESHOLD = 10    # Неудачных попыток за период
SUCCESS_AFTER_FAIL = 3 # Успех после N неудач = подозрение

def analyze_auth_log(logfile):
    fail_pattern = re.compile(
        r'(\d+\.\d+\.\d+\.\d+).*"POST /(?:api/)?login.*" (401|403)'
    )
    success_pattern = re.compile(
        r'(\d+\.\d+\.\d+\.\d+).*"POST /(?:api/)?login.*" (200|302)'
    )

    failures = defaultdict(int)
    successes = defaultdict(int)

    with open(logfile) as f:
        for line in f:
            fm = fail_pattern.search(line)
            if fm:
                failures[fm.group(1)] += 1

            sm = success_pattern.search(line)
            if sm:
                successes[sm.group(1)] += 1

    alerts = []
    for ip, fail_count in failures.items():
        if fail_count >= FAIL_THRESHOLD:
            succ = successes.get(ip, 0)
            severity = 'CRITICAL' if succ > 0 else 'HIGH'
            alerts.append(
                f"[{severity}] Credential stuffing от {ip}: "
                f"{fail_count} неудач, {succ} успехов"
            )

    return alerts

if __name__ == '__main__':
    logfile = sys.argv[1] if len(sys.argv) > 1 else '/var/log/nginx/access.log'
    for alert in analyze_auth_log(logfile):
        print(alert)
```

```python
"""check_pwned.py — проверка пароля по HaveIBeenPwned (k-anonymity)."""

import hashlib
import sys
import urllib.request

def check_password_pwned(password):
    sha1 = hashlib.sha1(password.encode()).hexdigest().upper()
    prefix, suffix = sha1[:5], sha1[5:]

    url = f"https://api.pwnedpasswords.com/range/{prefix}"
    req = urllib.request.Request(url, headers={'User-Agent': 'PwnCheck/1.0'})

        data = resp.read().decode()

    for line in data.splitlines():
        hash_suffix, count = line.split(':')
        if hash_suffix == suffix:
            return int(count)
    return 0

if __name__ == '__main__':
```

## Модуль 42: Обнаружение Password Spraying — Password Spraying Detection

### Что это за угроза

Password spraying — атака, при которой один пароль (часто простой: `Company2026!`, `Welcome1`) проверяется на множестве учётных записей. Обходит блокировку по количеству попыток, т.к. на каждую учётку приходится одна попытка.

**MITRE ATT&CK:** T1110.003 — Brute Force: Password Spraying

### Индикаторы компрометации (IoC)

- Множество неудачных логинов с разными учётками, но одинаковым паролем
- Event ID 4625 (Windows) с SubStatus 0xC000006A (wrong password) для множества учёток
- Одинаковый User-Agent для всех попыток
- Равномерный интервал между попытками (автоматизация)
- Одна неудачная попытка на учётку (ниже порога блокировки)

**Windows Event:**
```
Event ID: 4625
Logon Type: 3 (Network)
Sub Status: 0xC000006A (wrong password)
Account Name: user1, user2, user3, user4...  # Разные пользователи
Source Network Address: 10.0.0.55             # Один IP
```

## Модуль 43: Обнаружение Kerberoasting — Kerberoasting Detection

### Что это за угроза

Kerberoasting — атака на Active Directory, при которой злоумышленник запрашивает TGS-билеты для сервисных аккаунтов (с SPN), а затем оффлайн подбирает пароль. Не требует привилегий — любой доменный пользователь может запросить TGS.

**MITRE ATT&CK:** T1558.003 — Steal or Forge Kerberos Tickets: Kerberoasting

### Индикаторы компрометации (IoC)

- Event ID 4769 (TGS requested) с шифрованием RC4 (0x17) вместо AES
- Массовые TGS-запросы от одной учётки за короткий период
- TGS-запросы к сервисным аккаунтам с SPN, к которым пользователь обычно не обращается
- Использование инструментов Rubeus, GetUserSPNs.py (Impacket), Invoke-Kerberoast

**Windows Event:**
```
Event ID: 4769
Service Name: MSSQLSvc/sql01.corp.local:1433
Client Address: ::ffff:10.0.0.55
Ticket Encryption Type: 0x17  # ← RC4! Подозрительно!
# AES256 = 0x12, AES128 = 0x11 — нормально
```

## Модуль 44: Обнаружение AS-REP Roasting — AS-REP Roasting Detection

### Что это за угроза

- Использование Rubeus asreproast, GetNPUsers.py (Impacket)

## Модуль 45: Обнаружение LLMNR/NBT-NS Poisoning — LLMNR/NBT-NS Poisoning Detection

### Что это за угроза

LLMNR (Link-Local Multicast Name Resolution) и NBT-NS (NetBIOS Name Service) — протоколы резолвинга имён в локальной сети. Атакующий отвечает на широковещательные запросы, перенаправляя жертву на свой хост и перехватывая NTLMv2-хеш. Инструменты: `Responder`, `Inveigh`.

**MITRE ATT&CK:** T1557.001 — Adversary-in-the-Middle: LLMNR/NBT-NS Poisoning

### Индикаторы компрометации (IoC)

- Ответы на LLMNR/NBT-NS от неавторизованных IP
- NTLMv2-аутентификация к неизвестным SMB/HTTP-серверам
- Аномальный трафик на порту 5355 (LLMNR) и 137 (NBT-NS)
- Множественные резолвы несуществующих имён (опечатки в именах шар)
- Появление нового SMB-сервера в сети

**Сетевые артефакты:**
```
# Wireshark filter для LLMNR poisoning
llmnr && ip.src != <legitimate_dns_server>

# Wireshark filter для NBT-NS poisoning  
nbns && ip.src != <legitimate_wins_server>

# Подозрительная NTLMv2 аутентификация
ntlmssp && ip.dst == <unknown_ip>
```

#### Sigma-правила

#### PowerShell — обнаружение Responder в сети

```powershell
# Обнаружение LLMNR-ответов от неавторизованных хостов
# Запуск: .\Detect-LLMNRPoisoning.ps1

$LegitDNS = @('10.0.0.1', '10.0.0.2')

# Мониторинг LLMNR-трафика
$Filter = "udp port 5355"
$Capture = & tshark -i Ethernet -f $Filter -T fields `
    -e ip.src -e ip.dst -e llmnr.query_name `
    -c 100 2>$null

foreach ($line in $Capture) {
    $parts = $line -split "\t"
    $src = $parts[0]
    if ($src -notin $LegitDNS -and $parts.Count -ge 3) {
        Write-Warning "[ALERT] LLMNR poisoning suspected from $src for '$($parts[2])'"
    }
}
```

### Защита и предотвращение

#### 1. Отключить LLMNR и NBT-NS

```powershell
# Отключить LLMNR через GPO
# Computer Configuration → Administrative Templates → Network →
# DNS Client → "Turn off Multicast Name Resolution" = Enabled

# Или через реестр (все машины):
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\DNSClient" `
    -Name "EnableMulticast" -Value 0

# Отключить NBT-NS через реестр
$adapter = Get-WmiObject Win32_NetworkAdapterConfiguration | 
    Where-Object { $_.IPEnabled -eq $true }
$adapter | ForEach-Object {
    $_.SetTcpipNetbios(2)  # 2 = Disable NetBIOS over TCP/IP
}

# Или через DHCP: DHCP Option 001 (Microsoft Disable NetBIOS) = 0x2
```

#### 2. Включить SMB Signing

```powershell
# Обязательная подпись SMB — предотвращает NTLM relay
# GPO: Computer Configuration → Windows Settings → Security Settings →
# Local Policies → Security Options

# "Microsoft network client: Digitally sign communications (always)" = Enabled
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\LanmanWorkstation\Parameters" `
    -Name "RequireSecuritySignature" -Value 1

# "Microsoft network server: Digitally sign communications (always)" = Enabled
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\LanManServer\Parameters" `
    -Name "RequireSecuritySignature" -Value 1
```

#### 3. Network Access Restriction (EPA)

```powershell
# Включить Extended Protection for Authentication (EPA)
# Предотвращает NTLM relay к веб-сервисам

# Для IIS:
# IIS Manager → Sites → Authentication → Windows Authentication →
# Advanced Settings → Extended Protection = Require

# Для LDAP Signing:
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\NTDS\Parameters" `
    -Name "LDAPServerIntegrity" -Value 2  # 2 = Require
```
