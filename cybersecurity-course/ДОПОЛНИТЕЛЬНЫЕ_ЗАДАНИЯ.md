**Шаг 3: Python-скрипт для полного анализа**

```python
#!/usr/bin/env python3
"""Анализатор brute force в auth.log"""

import re
from collections import defaultdict

failed = defaultdict(lambda: {"count": 0, "users": defaultdict(int), "first": None, "last": None})
success_after_fail = []

with open("auth.log") as f:
    for line in f:
        m_fail = re.search(
            r"(\w+ \d+ [\d:]+).*Failed password for (?:invalid user )?(\S+) from (\S+)",
            line
        )
        if m_fail:
            ts, user, ip = m_fail.groups()
            failed[ip]["count"] += 1
            failed[ip]["users"][user] += 1
            if not failed[ip]["first"]:
                failed[ip]["first"] = ts
            failed[ip]["last"] = ts

        m_ok = re.search(
            r"(\w+ \d+ [\d:]+).*Accepted password for (\S+) from (\S+)", line
        )
        if m_ok:
            ts, user, ip = m_ok.groups()
            if ip in failed:
                success_after_fail.append(
                    {"time": ts, "user": user, "ip": ip,
                     "prior_fails": failed[ip]["count"]}
                )

print("=== BRUTE FORCE REPORT ===\n")
for ip, data in sorted(failed.items(), key=lambda x: -x[1]["count"]):
    print(f"IP: {ip}")
    print(f"  Попыток: {data['count']}")
    print(f"  Период: {data['first']} — {data['last']}")
    print(f"  Целевые аккаунты: ", end="")
    print(", ".join(f"{u}({c})" for u, c in
                    sorted(data["users"].items(), key=lambda x: -x[1])))
    print()

if success_after_fail:
    print("!!! УСПЕШНЫЙ ВХОД ПОСЛЕ BRUTE FORCE !!!")
    for s in success_after_fail:
        print(f"  IP {s['ip']} вошёл как {s['user']} в {s['time']} "
              f"(после {s['prior_fails']} неудач)")
```

### Подсказки

1. Logon Type 3 = сетевой вход (SMB, net use), Logon Type 10 = RDP
2. Event 4648 показывает использование альтернативных учётных данных — ключевой индикатор
3. Обратите внимание на ADMIN$ share и загрузку exe — типичный PsExec-паттерн
4. ntdsutil с параметром `ifm create full` = дамп Active Directory

### Решение

**Восстановленная цепочка:**

```
09:15 — Атакующий входит на WS-PC042 под i.petrov (RDP)
  ↓
09:45 — С WS-PC042 используются учётные данные svc_backup (Event 4648)
  ↓ (Lateral Movement через SMB — PsExec-паттерн)
09:45 — svc_backup входит на FS-01 (Network Logon Type 3)
09:46 — Доступ к ADMIN$ share → загрузка svc.exe → запуск
09:46 — svc.exe запускается с аргументом "10.0.5.42 4444" (обратная связь)
  ↓ (Lateral Movement с FS-01)
09:50 — С FS-01 используются учётные данные admin.dc (Event 4648)
  ↓
09:50 — admin.dc входит на DC-01 (Network Logon + Special Privileges)
09:52 — RDP-сессия admin.dc на DC-01
09:53 — ntdsutil dump = ДАМП БАЗЫ ACTIVE DIRECTORY (NTDS.dit)
```

**Sigma-правило для обнаружения:**

```yaml
title: Lateral Movement via ADMIN$ Share and Remote Execution
status: experimental
logsource:
    product: windows
    service: security
detection:
    admin_share:
        EventID: 5140
        ShareName|contains: 'ADMIN$'
    exe_drop:
        EventID: 5145
        ShareName|contains: 'ADMIN$'
        RelativeTargetName|endswith: '.exe'
        AccessList|contains: 'WriteData'
    condition: admin_share and exe_drop
level: high
tags:
    - attack.lateral_movement
    - attack.t1021.002
```

### Объяснение

**Ключевые индикаторы lateral movement:**

1. **Event 4648** (Explicit Credentials) — атакующий использует чужие учётные данные, это главный маркер. Легитимные пользователи редко делают `runas`.

2. **Logon Type 3 + ADMIN$ share** — классический паттерн PsExec / psexec.py. Загрузка .exe в `ADMIN$\Temp` и запуск через services.exe.

3. **Цепочка хопов**: WS-PC042 → FS-01 → DC-01. Каждый хоп использует новые учётные данные — это эскалация привилегий + lateral movement.

4. **ntdsutil IFM** — дамп полной базы AD включая хеши всех паролей. Это game over для домена.

**Действия SOC:**
1. Немедленно изолировать WS-PC042, FS-01
2. Сбросить пароли: i.petrov, svc_backup, admin.dc, krbtgt (дважды!)
3. Проверить C:\temp\dump на DC-01 — удалить дамп
4. Полный аудит AD: новые учётки, изменения GPO

**Детальный разбор Письма B:**

1. `From: security@corp-example.com` — притворяется внутренним отделом безопасности
2. `Return-Path: <bounce@attacker-vps.net>` — ответы уходят на сервер атакующего
3. `Received: from unknown (HELO smtp-relay.attacker-vps.net) (45.33.100.200)` — реальный отправитель это VPS
4. `spf=fail` — IP 45.33.100.200 не авторизован отправлять от имени corp-example.com

**SPF (Sender Policy Framework)** — DNS-запись, которая перечисляет серверы, имеющие право отправлять почту от домена. `spf=fail` означает, что IP отправителя не в списке разрешённых.

**DKIM (DomainKeys Identified Mail)** — криптографическая подпись письма. `dkim=none` — подписи нет, `dkim=fail` — подпись не совпадает.

**DMARC (Domain-based Message Authentication)** — политика, объединяющая SPF и DKIM. `dmarc=fail action=quarantine` — домен требует отправлять такие письма в карантин.

- Настроить email-gateway для блокировки писем с `dmarc=fail`
- Обучить сотрудников проверять Reply-To

```python
#!/usr/bin/env python3
"""Объединение логов из разных источников в timeline"""

import re
from datetime import datetime

events = []

def parse_apache(line):
    m = re.match(r'(\S+).*\[(\d+/\w+/\d+:[\d:]+).*\] "(\S+ \S+)', line)
    if m:
        ip, ts_str, req = m.groups()
        ts = datetime.strptime(ts_str, "%d/%b/%Y:%H:%M:%S")
        return {"time": ts, "source": "Apache", "ip": ip, "detail": req}
    return None

def parse_auth(line):
    m = re.match(r'(\w+ \d+ [\d:]+) \S+ (\S+)\[.*\]: (.*)', line)
    if m:
        ts_str, service, msg = m.groups()
        ts = datetime.strptime(f"2026 {ts_str}", "%Y %b %d %H:%M:%S")
        return {"time": ts, "source": "auth.log", "detail": f"{service}: {msg}"}
    return None

def parse_sysmon(block):
    m_eid = re.search(r'EventID: (\d+)', block)
    m_ts = re.search(r'\| ([\w ]+ \d+ [\d:]+)', block)
    m_img = re.search(r'Image: (.+)', block)
    m_cmd = re.search(r'CommandLine: (.+)', block)
    if m_eid and m_ts:
        ts = datetime.strptime(f"2026 {m_ts.group(1).strip()}", "%Y %b %d %H:%M:%S")
        detail = f"EID:{m_eid.group(1)}"
        if m_img:
            detail += f" {m_img.group(1)}"
        if m_cmd:
            detail += f" [{m_cmd.group(1)}]"
        return {"time": ts, "source": "Sysmon", "detail": detail}
    return None

# Сортировка и вывод
events.sort(key=lambda e: e["time"])
for e in events:
    print(f"{e['time'].strftime('%H:%M:%S')} | {e['source']:10s} | {e['detail']}")
```

### Объяснение

**Полная kill chain атаки:**

1. **Reconnaissance** → SQLi-проба (`' OR 1=1--`)
2. **Initial Access** → Эксплуатация SQLi, извлечение credentials из БД
3. **Persistence** → Загрузка web shell (shell.php) через admin upload
4. **Execution** → Выполнение команд через web shell
5. **Discovery** → `id`, `cat /etc/passwd`, попытка `sudo`
6. **Collection** → Архивация БД (`tar czf`)
7. **Exfiltration** → Отправка архива по HTTP на C2-сервер

Корреляция логов критически важна: без Sysmon мы видим только HTTP-запросы, без auth.log не узнали бы о попытке SSH brute force, без iptables не подтвердили бы exfiltration.

```python
#!/usr/bin/env python3
"""Обнаружение DNS tunneling по логам запросов"""

import math
import base64
from collections import Counter

def entropy(s):
    """Энтропия Шеннона строки"""
    if not s:
        return 0
    freq = Counter(s)
    length = len(s)
    return -sum((c / length) * math.log2(c / length) for c in freq.values())

def analyze_dns_log(lines):
    suspicious = []
    normal = []

    for line in lines:
        if line.startswith("#") or not line.strip():
            continue
        parts = [p.strip() for p in line.split(",")]
        if len(parts) < 5:
            continue
        ts, src_ip, query, qtype, rsize = parts

        # Извлекаем subdomain (до первой точки домена)
        labels = query.split(".")
        if len(labels) >= 3:
            subdomain = labels[0]
        else:
            subdomain = ""

        ent = entropy(subdomain)
        sub_len = len(subdomain)

        is_suspicious = (
            sub_len > 30 or
            ent > 3.8 or
            qtype == "TXT" and sub_len > 20
        )

        record = {
            "time": ts, "ip": src_ip, "query": query,
            "type": qtype, "subdomain_len": sub_len,
            "entropy": round(ent, 2)
        }

        if is_suspicious:
            suspicious.append(record)
            # Попробуем декодировать Base64
            try:
                decoded = base64.b64decode(subdomain + "==").decode("utf-8", errors="replace")
                record["decoded"] = decoded
            except Exception:
                record["decoded"] = "[не Base64]"
        else:
            normal.append(record)

    # Отчёт
    print("=== НОРМАЛЬНЫЕ DNS-ЗАПРОСЫ ===")
    for r in normal:
        print(f"  {r['time']} | {r['query']} ({r['type']})")

    print(f"\n=== ПОДОЗРИТЕЛЬНЫЕ ЗАПРОСЫ ({len(suspicious)}) ===")
```

```python
"""Обнаружение web shell в access.log"""

import re
from collections import defaultdict

SUSPICIOUS_DIRS = ["/uploads/", "/tmp/", "/images/", "/media/", "/cache/"]
SUSPICIOUS_EXT = [".php", ".asp", ".aspx", ".jsp", ".phtml"]

stats = defaultdict(lambda: {"requests": 0, "total_bytes": 0,
                              "ips": set(), "methods": set()})

with open("access.log") as f:
    for line in f:
        m = re.match(
            r'(\S+).*"(\S+) (\S+).*" (\d+) (\d+)',
            line
        )
        if not m:
            continue
        ip, method, path, status, size = m.groups()
        size = int(size)

        # Проверка: PHP-файл в подозрительной директории
        in_suspicious_dir = any(d in path for d in SUSPICIOUS_DIRS)
        has_suspicious_ext = any(path.endswith(e) for e in SUSPICIOUS_EXT)

        if in_suspicious_dir and has_suspicious_ext:
            stats[path]["requests"] += 1
            stats[path]["total_bytes"] += size
            stats[path]["ips"].add(ip)
            stats[path]["methods"].add(method)

for path, data in stats.items():
    print(f"[!] ПОДОЗРИТЕЛЬНЫЙ ФАЙЛ: {path}")
    print(f"    Запросов: {data['requests']}")
    print(f"    Всего байт ответа: {data['total_bytes']:,}")
    print(f"    IP-адреса: {data['ips']}")
    print(f"    Методы: {data['methods']}")
    if "POST" in data["methods"] and data["requests"] > 3:
        print(f"    ⚠ ВЕРОЯТНЫЙ WEB SHELL!")
```

## Задание 16: Suricata-правило для обнаружения port scan

**Инструменты:** Suricata

Напишите Suricata-правила для обнаружения различных видов сканирования портов.

### Решение

```
# SYN scan (множество SYN без ACK)
alert tcp any any -> $HOME_NET any (msg:"PORT SCAN - SYN Scan Detected"; \
  flags:S,12; threshold:type both, track by_src, count 20, seconds 5; \
  classtype:attempted-recon; sid:1000100; rev:1;)

# NULL scan (нет флагов)
alert tcp any any -> $HOME_NET any (msg:"PORT SCAN - NULL Scan Detected"; \
  flags:0,12; threshold:type both, track by_src, count 10, seconds 10; \
  classtype:attempted-recon; sid:1000101; rev:1;)

alert tcp any any -> $HOME_NET any (msg:"PORT SCAN - XMAS Scan Detected"; \
  flags:FPU,12; threshold:type both, track by_src, count 10, seconds 10; \
  classtype:attempted-recon; sid:1000102; rev:1;)

# FIN scan
alert tcp any any -> $HOME_NET any (msg:"PORT SCAN - FIN Scan Detected"; \
  flags:F,12; threshold:type both, track by_src, count 15, seconds 10; \
  classtype:attempted-recon; sid:1000103; rev:1;)

# UDP scan (множество UDP к разным портам)
alert udp any any -> $HOME_NET any (msg:"PORT SCAN - UDP Scan Detected"; \

alert tcp any any -> $HOME_NET any (msg:"SERVICE SCAN - Nmap Service Detection"; \
```

## Задание 17: Suricata-правило для SQL Injection

**Уровень:** Средний
**Тема:** IDS/IPS
**Время:** 30 минут
**Инструменты:** Suricata

### Условие

### Решение

```
# UNION SELECT injection
alert http any any -> $HOME_NET any (msg:"SQL INJECTION - UNION SELECT in URI"; \
  flow:established,to_server; http.uri; \
  content:"UNION"; nocase; content:"SELECT"; nocase; distance:0; within:20; \
  classtype:web-application-attack; sid:1000200; rev:1;)

# OR 1=1 / AND 1=1
alert http any any -> $HOME_NET any (msg:"SQL INJECTION - Boolean-based in URI"; \
  flow:established,to_server; http.uri; \
  pcre:"/(\%27|')\s*(OR|AND)\s*\d+\s*=\s*\d+/i"; \
  classtype:web-application-attack; sid:1000201; rev:1;)

# Comment injection (--, #, /*...*/)
alert http any any -> $HOME_NET any (msg:"SQL INJECTION - Comment in URI"; \
  flow:established,to_server; http.uri; \
  pcre:"/(\%27|').*(--%20|%23|\/\*)/i"; \
  classtype:web-application-attack; sid:1000202; rev:1;)

# Error-based (extractvalue, updatexml)
alert http any any -> $HOME_NET any (msg:"SQL INJECTION - Error-based in URI"; \
  flow:established,to_server; http.uri; \
  content:"extractvalue"; nocase; \
  classtype:web-application-attack; sid:1000203; rev:1;)

# Time-based (SLEEP, BENCHMARK, WAITFOR)
alert http any any -> $HOME_NET any (msg:"SQL INJECTION - Time-based in URI"; \
  flow:established,to_server; http.uri; \
  pcre:"/(SLEEP|BENCHMARK|WAITFOR\s+DELAY|pg_sleep)\s*\(/i"; \
  classtype:web-application-attack; sid:1000204; rev:1;)

# POST body injection
alert http any any -> $HOME_NET any (msg:"SQL INJECTION - UNION SELECT in POST body"; \
  flow:established,to_server; http.request_body; \
  content:"UNION"; nocase; content:"SELECT"; nocase; distance:0; within:20; \
  classtype:web-application-attack; sid:1000205; rev:1;)
```

### Объяснение

Правила покрывают основные типы SQLi: UNION-based, boolean-based, error-based, time-based. Используются и URI, и POST-body. `pcre` нужен для сложных паттернов, `content` — для быстрого предварительного фильтра (fast_pattern).

```python
#!/usr/bin/env python3
"""
Парсер Apache access.log для обнаружения SQL Injection и XSS.
Использование: python3 detect_web_attacks.py access.log
"""

import re
import sys
import urllib.parse
from collections import defaultdict
from datetime import datetime

# === ПАТТЕРНЫ АТАК ===

SQLI_PATTERNS = [
    (r"(\%27|')\s*(OR|AND)\s*\d+\s*=\s*\d+", "Boolean-based SQLi"),
    (r"UNION\s+(ALL\s+)?SELECT", "UNION-based SQLi"),
    (r"(SELECT|INSERT|UPDATE|DELETE|DROP|ALTER)\s+.*(FROM|INTO|TABLE|SET)", "SQL keyword chain"),
    (r"(SLEEP|BENCHMARK|WAITFOR\s+DELAY|pg_sleep)\s*\(", "Time-based SQLi"),
    (r"(extractvalue|updatexml)\s*\(", "Error-based SQLi"),
    (r"(\%27|');\s*(DROP|DELETE|INSERT|UPDATE)", "Stacked queries"),
    (r"INFORMATION_SCHEMA", "Schema enumeration"),
    (r"(GROUP_CONCAT|CONCAT_WS|LOAD_FILE|INTO\s+OUTFILE)", "Data extraction"),
    (r"0x[0-9a-fA-F]{8,}", "Hex-encoded payload"),
]

XSS_PATTERNS = [
    (r"<script[\s>]", "Script tag injection"),
    (r"javascript\s*:", "JavaScript URI"),
    (r"on(error|load|click|mouse|focus|blur|submit|change)\s*=", "Event handler injection"),
    (r"<img\s+.*src\s*=\s*['\"]?javascript:", "IMG src JavaScript"),
    (r"<iframe", "IFrame injection"),
    (r"<svg[\s/].*on\w+\s*=", "SVG event injection"),
    (r"document\.(cookie|location|write)", "DOM manipulation"),
    (r"(alert|confirm|prompt)\s*\(", "Alert/Confirm/Prompt"),
    (r"eval\s*\(", "Eval injection"),
]

# === ПАРСЕР ===

APACHE_LOG_RE = re.compile(
    r'^(\S+)\s+\S+\s+\S+\s+\[([^\]]+)\]\s+"(\S+)\s+(\S+)\s+\S+"\s+(\d+)\s+(\S+)'
)

def parse_line(line):
    m = APACHE_LOG_RE.match(line)
    if not m:
        return None
    ip, ts_str, method, uri, status, size = m.groups()
    try:
        ts = datetime.strptime(ts_str, "%d/%b/%Y:%H:%M:%S %z")
    except ValueError:
        ts = ts_str
    decoded_uri = urllib.parse.unquote(uri)
    return {
        "ip": ip, "timestamp": ts, "method": method,
        "uri": uri, "decoded_uri": decoded_uri,
        "status": int(status), "size": size
    }

def check_patterns(text, patterns):
    findings = []
    for pattern, name in patterns:
        if re.search(pattern, text, re.IGNORECASE):
            findings.append(name)
    return findings

def analyze_log(filepath):
    attacks = []
    ip_stats = defaultdict(lambda: {"sqli": 0, "xss": 0, "total": 0})

    with open(filepath) as f:
        for lineno, line in enumerate(f, 1):
            entry = parse_line(line.strip())
            if not entry:
                continue

            text = entry["decoded_uri"]
            sqli = check_patterns(text, SQLI_PATTERNS)
            xss = check_patterns(text, XSS_PATTERNS)

            if sqli or xss:
                entry["sqli_findings"] = sqli
                entry["xss_findings"] = xss
                entry["line"] = lineno
                attacks.append(entry)
                ip_stats[entry["ip"]]["sqli"] += len(sqli)
                ip_stats[entry["ip"]]["xss"] += len(xss)
            ip_stats[entry["ip"]]["total"] += 1

    # === ОТЧЁТ ===
    print(f"{'='*60}")
    print(f"ОТЧЁТ ОБ АТАКАХ НА ВЕБ-ПРИЛОЖЕНИЕ")
    print(f"Файл: {filepath}")
    print(f"Всего атак обнаружено: {len(attacks)}")
    print(f"{'='*60}\n")

    if attacks:
        print("--- SQL INJECTION ---")
        for a in attacks:
            if a["sqli_findings"]:
                print(f"  [{a['timestamp']}] {a['ip']}")
                print(f"  URI: {a['decoded_uri'][:100]}")
                print(f"  Тип: {', '.join(a['sqli_findings'])}")
                print()

        print("\n--- XSS ---")
        for a in attacks:
            if a["xss_findings"]:
                print(f"  [{a['timestamp']}] {a['ip']}")
                print(f"  URI: {a['decoded_uri'][:100]}")
                print(f"  Тип: {', '.join(a['xss_findings'])}")
                print()

        print("\n--- СТАТИСТИКА ПО IP ---")
        for ip, stats in sorted(ip_stats.items(), key=lambda x: -(x[1]["sqli"]+x[1]["xss"])):
            if stats["sqli"] or stats["xss"]:
                print(f"  {ip}: SQLi={stats['sqli']}, XSS={stats['xss']}, Total requests={stats['total']}")

    return attacks

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print(f"Использование: {sys.argv[0]} <access.log>")
        sys.exit(1)
    analyze_log(sys.argv[1])
```

## Задание 20: Обнаружение DGA-доменов по энтропии

```python
#!/usr/bin/env python3
"""
Обнаружение DGA-доменов по энтропии, частоте согласных и длине.
"""

import math
import re
from collections import Counter

VOWELS = set("aeiou")
CONSONANTS = set("bcdfghjklmnpqrstvwxyz")
# Известные легитимные домены (whitelist)
WHITELIST = {
    "google.com", "facebook.com", "microsoft.com", "amazon.com",
    "cloudflare.com", "akamaihd.net", "googleapis.com", "gstatic.com",
    "windows.net", "office365.com", "outlook.com", "live.com"
}

def shannon_entropy(s):
    """Энтропия Шеннона"""
    if not s:
        return 0
    freq = Counter(s.lower())
    length = len(s)
    return -sum((c / length) * math.log2(c / length) for c in freq.values())

def consonant_ratio(s):
    """Доля согласных"""
    s = s.lower()
    letters = [c for c in s if c.isalpha()]
    if not letters:
        return 0
    return sum(1 for c in letters if c in CONSONANTS) / len(letters)

def digit_ratio(s):
    """Доля цифр"""
    if not s:
        return 0
    return sum(1 for c in s if c.isdigit()) / len(s)

def longest_consonant_run(s):
    """Максимальная серия согласных подряд"""
    max_run = 0
    current = 0
    for c in s.lower():
        if c in CONSONANTS:
            current += 1
            max_run = max(max_run, current)
        else:
            current = 0
    return max_run

def is_dga(domain):
    """
    Оценка: DGA или нет.
    Возвращает (score, reasons)
    """
    # Извлекаем основную часть (без TLD)
    parts = domain.split(".")
    if len(parts) < 2:
        return 0, []

    sld = parts[-2]  # second-level domain
    full_domain = ".".join(parts[:-1])

    # Whitelist
    registered = ".".join(parts[-2:])
    if registered in WHITELIST:
        return 0, []

    score = 0
    reasons = []

    # 1. Энтропия
    ent = shannon_entropy(sld)
    if ent > 3.8:
        score += 30
        reasons.append(f"Высокая энтропия: {ent:.2f}")

    # 2. Длина
    if len(sld) > 20:
        score += 20
        reasons.append(f"Длинный домен: {len(sld)} символов")
    elif len(sld) > 15:
        score += 10
        reasons.append(f"Умеренно длинный: {len(sld)}")

    # 3. Соотношение согласных
    cr = consonant_ratio(sld)
    if cr > 0.75:
        score += 25
        reasons.append(f"Много согласных: {cr:.0%}")

    # 4. Цифры в домене
    dr = digit_ratio(sld)
    if dr > 0.3:
        score += 20
        reasons.append(f"Много цифр: {dr:.0%}")

    # 5. Серия согласных
    lcr = longest_consonant_run(sld)
    if lcr >= 5:
        score += 15
        reasons.append(f"Серия согласных: {lcr}")

    # 6. Нет словарных слов (простая эвристика)
    common = ["mail", "web", "shop", "news", "blog", "cloud", "app",
              "data", "info", "help", "home", "test", "dev", "api"]
    has_word = any(w in sld.lower() for w in common)
    if not has_word and len(sld) > 8:
        score += 10
        reasons.append("Нет словарных слов")

    return score, reasons

def analyze_dns_queries(queries):
    """Анализирует список DNS-запросов"""
    results = []
    for q in queries:
        q = q.strip().lower()
        if not q:
            continue
        score, reasons = is_dga(q)
        results.append({
            "domain": q,
            "score": score,
            "verdict": "DGA" if score >= 50 else "SUSPICIOUS" if score >= 30 else "CLEAN",
            "reasons": reasons
        })

    # Сортировка по score
    results.sort(key=lambda x: -x["score"])

    print(f"{'Domain':<45} {'Score':>5} {'Verdict':<12} Reasons")
    print("-" * 100)
    for r in results:
        marker = "!!!" if r["verdict"] == "DGA" else " ! " if r["verdict"] == "SUSPICIOUS" else "   "
        print(f"{marker} {r['domain']:<42} {r['score']:>5} {r['verdict']:<12} {'; '.join(r['reasons'])}")

    return results

# === ТЕСТ ===
test_domains = [
    "google.com",
    "mail.corp-example.com",
    "xjkqpvmz8bnw3ld.evil.com",
    "a7b3c9d2e5f1g8h4.malware-c2.net",
    "qxznvbjfpwmtrkls.bad-domain.org",
    "cdn.cloudflare.com",
    "api.github.com",
    "kj38dh47fj29dk47sm.top",
    "helpdesk.corp-example.com",
    "newsletter.marketing-partner.com",
    "3k8j2m5n9p1r4t7w.xyz",
    "support-center.legitimate-company.com",
]

if __name__ == "__main__":
    analyze_dns_queries(test_domains)
```

```python
                "handle": data.get("handle", "N/A"),
                "country": data.get("country", "N/A"),
                "startAddress": data.get("startAddress", "N/A"),
                "endAddress": data.get("endAddress", "N/A"),
```

## Задание 22: Мониторинг файлов в web root

**Уровень:** Средний
**Тема:** Python, File Integrity
**Время:** 45 минут
**Инструменты:** Python 3

### Условие

Напишите скрипт для мониторинга изменений файлов в web-директории (обнаружение web shell).

### Решение

```python
#!/usr/bin/env python3
"""
Мониторинг изменений файлов в web-директории.
Обнаруживает: новые файлы, изменённые файлы, удалённые файлы.
"""

import hashlib
import json
import os
import sys
import time
from pathlib import Path

SUSPICIOUS_EXTENSIONS = {".php", ".asp", ".aspx", ".jsp", ".phtml", ".php5", ".cgi"}
STATE_FILE = "/var/lib/webmon/state.json"

def hash_file(filepath):
    """SHA-256 хеш файла"""
    sha256 = hashlib.sha256()
    try:
        with open(filepath, "rb") as f:
            while chunk := f.read(8192):
                sha256.update(chunk)
        return sha256.hexdigest()
    except (PermissionError, FileNotFoundError):
        return None

def scan_directory(path):
    """Сканирование директории, возвращает dict {path: {hash, size, mtime}}"""
    files = {}
    for root, dirs, filenames in os.walk(path):
        for fname in filenames:
            fpath = os.path.join(root, fname)
            try:
                stat = os.stat(fpath)
                files[fpath] = {
                    "hash": hash_file(fpath),
                    "size": stat.st_size,
                    "mtime": stat.st_mtime,
                }
            except (PermissionError, FileNotFoundError):
                continue
    return files

def load_state():
    """Загрузка предыдущего состояния"""
    if os.path.exists(STATE_FILE):
        with open(STATE_FILE) as f:
            return json.load(f)
    return {}

def save_state(state):
    """Сохранение текущего состояния"""
    os.makedirs(os.path.dirname(STATE_FILE), exist_ok=True)
    with open(STATE_FILE, "w") as f:
        json.dump(state, f, indent=2)

def check_suspicious(filepath):
    """Проверка файла на подозрительность"""
    reasons = []
    ext = Path(filepath).suffix.lower()

    if ext in SUSPICIOUS_EXTENSIONS:
        parent = os.path.basename(os.path.dirname(filepath))
        if parent in ("uploads", "images", "media", "tmp", "cache", "static"):
            reasons.append(f"Исполняемый файл ({ext}) в upload-директории ({parent})")

    if ext in SUSPICIOUS_EXTENSIONS:
        try:
            with open(filepath, "r", errors="ignore") as f:
                content = f.read(10000)
                danger_patterns = ["eval(", "exec(", "system(", "passthru(",
                                   "shell_exec(", "base64_decode(", "$_GET[",
                                   "$_POST[", "$_REQUEST["]
                for pat in danger_patterns:
                    if pat in content:
                        reasons.append(f"Содержит подозрительную функцию: {pat}")
        except Exception:
            pass

    return reasons

def monitor(web_root):
    """Основная функция мониторинга"""
    print(f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] Сканирование: {web_root}")

    current = scan_directory(web_root)
    previous = load_state()

    alerts = []

    # Новые файлы
    for fpath in set(current) - set(previous):
        suspicious = check_suspicious(fpath)
        severity = "CRITICAL" if suspicious else "INFO"
        alert = {
            "type": "NEW_FILE",
            "severity": severity,
            "path": fpath,
            "size": current[fpath]["size"],
            "reasons": suspicious
        }
        alerts.append(alert)

    # Изменённые файлы
    for fpath in set(current) & set(previous):
        if current[fpath]["hash"] != previous[fpath]["hash"]:
            suspicious = check_suspicious(fpath)
            severity = "HIGH" if suspicious else "MEDIUM"
            alert = {
                "type": "MODIFIED",
                "severity": severity,
                "path": fpath,
                "old_hash": previous[fpath]["hash"][:16] + "...",
                "new_hash": current[fpath]["hash"][:16] + "...",
                "reasons": suspicious
            }
            alerts.append(alert)

    # Удалённые файлы
    for fpath in set(previous) - set(current):
        alerts.append({
            "type": "DELETED",
            "severity": "MEDIUM",
            "path": fpath
        })

    # Вывод
    if alerts:
        for a in sorted(alerts, key=lambda x: {"CRITICAL": 0, "HIGH": 1, "MEDIUM": 2, "INFO": 3}.get(x["severity"], 4)):
            marker = {"CRITICAL": "!!!!", "HIGH": " !! ", "MEDIUM": " !  ", "INFO": "    "}
            print(f"{marker.get(a['severity'], '    ')} [{a['severity']}] {a['type']}: {a['path']}")
            if a.get("reasons"):
                for r in a["reasons"]:
                    print(f"        → {r}")
    else:
        print("  Изменений не обнаружено.")

    save_state(current)
    return alerts

if __name__ == "__main__":
    web_root = sys.argv[1] if len(sys.argv) > 1 else "/var/www/html"
    monitor(web_root)
```

```python
    "9": "NewCredentials", "10": "RemoteInteractive", "11": "CachedInteractive"
}

def parse_xml_export(filepath):
    """Парсинг XML-экспорта из Event Viewer"""
    events = []
    ns = {"e": "http://schemas.microsoft.com/win/2004/08/events/event"}

    try:
        tree = ET.parse(filepath)
        root = tree.getroot()
    except ET.ParseError:
        # Возможно, файл содержит несколько корневых элементов
        with open(filepath) as f:
            content = f"<Events>{f.read()}</Events>"
        root = ET.fromstring(content)

    for event_elem in root.iter():
        if event_elem.tag.endswith("Event") or event_elem.tag == "Event":
            try:
                system = event_elem.find(".//e:System", ns) or event_elem.find(".//System")
                if system is None:
                    continue

                eid_elem = system.find("e:EventID", ns) or system.find("EventID")
                time_elem = system.find("e:TimeCreated", ns) or system.find("TimeCreated")

                if eid_elem is None or time_elem is None:
                    continue

                eid = int(eid_elem.text)
                timestamp = time_elem.get("SystemTime", "")

                # Извлечение данных из EventData
                event_data = {}
                data_section = event_elem.find(".//e:EventData", ns) or event_elem.find(".//EventData")
                if data_section is not None:
                    for data in data_section:
                        name = data.get("Name", "")
                        value = data.text or ""
                        if name:
                            event_data[name] = value

                events.append({
                    "timestamp": timestamp,
                    "event_id": eid,
                    "description": EVENT_DESCRIPTIONS.get(eid, f"Event {eid}"),
                    "data": event_data
                })
            except Exception:
                continue

    return events

def build_timeline(events):
    """Построение timeline из событий"""
    timeline = []

    for evt in events:
        eid = evt["event_id"]
        data = evt["data"]
        row = {
            "Timestamp": evt["timestamp"],
            "EventID": eid,
            "Description": evt["description"],
            "User": data.get("TargetUserName", data.get("SubjectUserName", data.get("User", "N/A"))),
            "Source": data.get("IpAddress", data.get("SourceAddress", data.get("WorkstationName", ""))),
            "Target": data.get("TargetServerName", data.get("DestinationAddress", data.get("ShareName", ""))),
            "Detail": ""
        }

        # Специфичная обработка
        if eid == 4624:
            lt = LOGON_TYPES.get(data.get("LogonType", ""), data.get("LogonType", ""))
            row["Detail"] = f"LogonType={lt}"
        elif eid == 4688 or eid == 1:
            row["Detail"] = data.get("CommandLine", data.get("NewProcessName", ""))[:200]
        elif eid in (5140, 5145):
            row["Detail"] = data.get("ShareName", "") + " " + data.get("RelativeTargetName", "")
        elif eid == 3:
            row["Detail"] = f"{data.get('DestinationIp', '')}:{data.get('DestinationPort', '')}"
        elif eid == 11:
            row["Detail"] = data.get("TargetFilename", "")
        elif eid in (12, 13):
            row["Detail"] = data.get("TargetObject", "")

        timeline.append(row)

    timeline.sort(key=lambda x: x["Timestamp"])
    return timeline

def export_csv(timeline, output_path):
    """Экспорт в CSV"""
    fields = ["Timestamp", "EventID", "Description", "User", "Source", "Target", "Detail"]
    with open(output_path, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=fields)
        writer.writeheader()
        writer.writerows(timeline)
    print(f"Экспортировано {len(timeline)} событий в {output_path}")

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print(f"Использование: {sys.argv[0]} <events.xml> [-o timeline.csv]")
        sys.exit(1)

    output = "timeline.csv"
    files = []
    i = 1
```

### Решение

```python
#!/usr/bin/env python3
"""
Обнаружение C2-beaconing: анализ периодичности соединений.
Beacon = регулярные соединения с малым jitter (стд. отклонение / среднее < 0.3).
"""

import math
from collections import defaultdict

def analyze_beaconing(connections):
    """
    connections: список dict {timestamp_epoch, src_ip, dst_ip, dst_port, bytes}
    """
    # Группируем соединения по (src → dst:port)
    groups = defaultdict(list)
    for c in connections:
        key = (c["src_ip"], c["dst_ip"], c["dst_port"])
        groups[key].append(c["timestamp_epoch"])

    results = []
    for (src, dst, port), timestamps in groups.items():
        if len(timestamps) < 5:
            continue

        timestamps.sort()
        intervals = [timestamps[i+1] - timestamps[i] for i in range(len(timestamps)-1)]

        if not intervals:
            continue

        mean = sum(intervals) / len(intervals)
        if mean == 0:
            continue
        variance = sum((x - mean) ** 2 for x in intervals) / len(intervals)
        std_dev = math.sqrt(variance)
        jitter = std_dev / mean if mean > 0 else 999

        # Beacon score: низкий jitter = высокая регулярность
        is_beacon = jitter < 0.30 and mean < 3600 and len(timestamps) >= 5

        results.append({
            "src": src,
            "dst": dst,
            "port": port,
            "connections": len(timestamps),
            "mean_interval": round(mean, 1),
            "std_dev": round(std_dev, 1),
            "jitter": round(jitter, 3),
            "is_beacon": is_beacon,
            "first_seen": min(timestamps),
            "last_seen": max(timestamps),
        })

    results.sort(key=lambda x: x["jitter"])
    return results

test_data = [

    results = analyze_beaconing(test_data)
```

## Задание 25: Проверка SSL-сертификатов

**Уровень:** Начальный
**Тема:** Python, мониторинг
**Время:** 30 минут
**Инструменты:** Python 3, ssl

### Решение

```python
#!/usr/bin/env python3
"""Проверка SSL-сертификатов и алерт при скором истечении."""

import ssl
import socket
import sys
from datetime import datetime

def check_cert(hostname, port=443, warn_days=30):
    """Проверяет SSL-сертификат хоста"""
    context = ssl.create_default_context()
    try:
        with socket.create_connection((hostname, port), timeout=5) as sock:
            with context.wrap_socket(sock, server_hostname=hostname) as ssock:
                cert = ssock.getpeercert()
                not_after = datetime.strptime(cert["notAfter"], "%b %d %H:%M:%S %Y %Z")
                not_before = datetime.strptime(cert["notBefore"], "%b %d %H:%M:%S %Y %Z")
                issuer = dict(x[0] for x in cert.get("issuer", []))
                subject = dict(x[0] for x in cert.get("subject", []))
                days_left = (not_after - datetime.utcnow()).days

                status = "OK"
                if days_left < 0:
                    status = "EXPIRED"
                elif days_left < warn_days:
                    status = "EXPIRING SOON"

                return {
                    "hostname": hostname,
                    "status": status,
                    "days_left": days_left,
                    "not_before": not_before.isoformat(),
                    "not_after": not_after.isoformat(),
                    "issuer": issuer.get("organizationName", "N/A"),
                    "subject_cn": subject.get("commonName", "N/A"),
                    "serial": cert.get("serialNumber", "N/A"),
                }
    except ssl.SSLCertVerificationError as e:
        return {"hostname": hostname, "status": "INVALID", "error": str(e)}
    except (socket.timeout, ConnectionRefusedError, OSError) as e:
        return {"hostname": hostname, "status": "UNREACHABLE", "error": str(e)}

def main():
    hosts = sys.argv[1:] if len(sys.argv) > 1 else [
        "google.com", "github.com", "expired.badssl.com"
    ]

    print(f"{'Host':<30} {'Status':<15} {'Days Left':<10} {'Expires':<20} {'Issuer'}")
    print("-" * 100)

    for host in hosts:
        result = check_cert(host)
        status = result["status"]
        marker = "!!!" if status in ("EXPIRED", "INVALID") else " ! " if status == "EXPIRING SOON" else "   "
        days = result.get("days_left", "N/A")
        expires = result.get("not_after", result.get("error", "N/A"))[:19]
        issuer = result.get("issuer", "N/A")
        print(f"{marker}{host:<27} {status:<15} {str(days):<10} {expires:<20} {issuer}")

if __name__ == "__main__":
    main()
```

| 9 | Port | 22 | **2222** (опц.) | Стандартный порт — больше brute force (security through obscurity, но уменьшает шум) |

**Тема:** Hardening Windows
**Время:** 45 минут

### Условие

Создайте список из 10 GPO-настроек для hardening Windows рабочих станций.

### Решение

```
# 10 GPO для hardening Windows workstation

1. ОТКЛЮЧИТЬ МАКРОСЫ В OFFICE
   Computer → Administrative Templates → Microsoft Office → Security → VBA Macro Notification Settings
   Значение: "Disable all macros except digitally signed macros"

2. ВКЛЮЧИТЬ CREDENTIAL GUARD
   Computer → Administrative Templates → System → Device Guard →
   "Turn On Virtualization Based Security" → Enabled
   Credential Guard Configuration → Enabled with UEFI lock

3. БЛОКИРОВАТЬ POWERSHELL V2
   Computer → Administrative Templates → Windows Components → Windows PowerShell →
   "Turn on PowerShell Script Block Logging" → Enabled
   + Удалить feature: Disable-WindowsOptionalFeature -Online -FeatureName MicrosoftWindowsPowerShellV2

4. НАСТРОИТЬ WINDOWS FIREWALL
   Computer → Windows Settings → Security → Windows Firewall with Advanced Security
   → Inbound: Block all (кроме необходимого)
   → Outbound: Block all (кроме необходимого)

5. ВКЛЮЧИТЬ BITLOCKER
   Computer → Administrative Templates → Windows Components → BitLocker Drive Encryption
   → "Require additional authentication at startup" → Enabled (TPM + PIN)

6. ВКЛЮЧИТЬ SYSMON
   (через GPO Scheduled Task или Startup Script):
   Script: \\DC\NETLOGON\Deploy-Sysmon.bat
   Содержание: sysmon -accepteula -i \\DC\NETLOGON\sysmonconfig.xml

7. НАСТРОИТЬ AUDIT POLICY
   Computer → Windows Settings → Security → Advanced Audit Policy Configuration:
   - Logon/Logoff → Audit Logon: Success, Failure
   - Object Access → Audit File System: Success, Failure
   - Privilege Use → Audit Sensitive Privilege Use: Success, Failure
   - Process Tracking → Audit Process Creation: Success

8. ВКЛЮЧИТЬ COMMAND LINE В PROCESS CREATION EVENTS
   Computer → Administrative Templates → System → Audit Process Creation
   → "Include command line in process creation events" → Enabled

9. ОГРАНИЧИТЬ USB-УСТРОЙСТВА
   Computer → Administrative Templates → System → Device Installation → Device Installation Restrictions
   → "Prevent installation of removable devices" → Enabled
   (Исключения для мыши/клавиатуры)

10. НАСТРОИТЬ PASSWORD POLICY
    Computer → Windows Settings → Security → Account Policies → Password Policy:
    - Minimum password length: 14
    - Password complexity: Enabled
    - Maximum password age: 90 days
    - Account lockout threshold: 5 invalid attempts
    - Account lockout duration: 30 minutes
```

## Задание 39: fail2ban для SSH, Apache, Postfix

**Уровень:** Начальный
**Тема:** Hardening Linux
**Время:** 30 минут

### Условие

Настройте fail2ban для защиты трёх сервисов.

### Решение

```ini
# /etc/fail2ban/jail.local

[DEFAULT]
bantime = 3600
findtime = 600
maxretry = 5
banaction = iptables-multiport
backend = auto
ignoreip = 127.0.0.1/8 10.0.0.0/8

# === SSH ===
[sshd]
enabled = true
port = ssh,2222
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
bantime = 86400
findtime = 300

# === APACHE ===
[apache-auth]
enabled = true
port = http,https
filter = apache-auth
logpath = /var/log/apache2/error.log
maxretry = 5
bantime = 3600

[apache-badbots]
enabled = true
port = http,https
filter = apache-badbots
logpath = /var/log/apache2/access.log
maxretry = 2
bantime = 86400

[apache-noscript]
enabled = true
port = http,https
filter = apache-noscript
logpath = /var/log/apache2/error.log
maxretry = 5
bantime = 3600

# Кастомный фильтр для SQLi/XSS
[apache-sqli]
enabled = true
port = http,https
filter = apache-sqli
logpath = /var/log/apache2/access.log
maxretry = 1
bantime = 604800

# === POSTFIX ===
[postfix]
enabled = true
port = smtp,465,587
filter = postfix
logpath = /var/log/mail.log
maxretry = 5
bantime = 3600

[postfix-sasl]
enabled = true
port = smtp,465,587
filter = postfix[mode=auth]
logpath = /var/log/mail.log
maxretry = 3
bantime = 86400
```

**Кастомный фильтр для SQLi:**
```ini
# /etc/fail2ban/filter.d/apache-sqli.conf
[Definition]
failregex = ^<HOST> -.*(UNION.*SELECT|OR\s+1=1|AND\s+1=1|SELECT.*FROM|SLEEP\(|BENCHMARK\().*$
ignoreregex =
```

**Управление:**
```bash
# Установка
sudo apt install fail2ban

# Запуск
sudo systemctl enable fail2ban
sudo systemctl start fail2ban

# Проверка статуса
sudo fail2ban-client status
sudo fail2ban-client status sshd

# Разбанить IP
sudo fail2ban-client set sshd unbanip 203.0.113.50
```

## Задание 40: Аудит Active Directory Security

**Уровень:** Продвинутый
**Тема:** Hardening Windows
**Время:** 60 минут

### Условие

Дан вывод аудита Active Directory. Найдите уязвимости.

### Входные данные

```powershell
# === Администраторы домена ===
PS> Get-ADGroupMember "Domain Admins" | Select Name, SamAccountName
Name                SamAccountName
----                --------------
Administrator       Administrator
Иванов Алексей      a.ivanov
Петров Дмитрий      d.petrov
Сидоров Михаил      m.sidorov
svc_backup          svc_backup
SQL_Admin           sql_admin
Helpdesk            helpdesk.user

# === Kerberoastable аккаунты ===
PS> Get-ADUser -Filter {ServicePrincipalName -like "*"} -Properties ServicePrincipalName,PasswordLastSet | Select Name, ServicePrincipalName, PasswordLastSet
Name          SPN                         PasswordLastSet
----          ---                         ---------------
svc_sql       MSSQLSvc/DB-01:1433         2020-03-15
svc_http      HTTP/web-01.corp.local      2024-01-10
svc_backup    CIFS/FS-01.corp.local       2019-08-22

# === Учётки с "Password Never Expires" ===
PS> Get-ADUser -Filter {PasswordNeverExpires -eq $true} -Properties PasswordLastSet | Select Name, PasswordLastSet
Name              PasswordLastSet
----              ---------------
Administrator     2019-01-15
svc_backup        2019-08-22
svc_sql           2020-03-15
test.user         2021-06-01
old.admin         2018-12-01

# === Неактивные аккаунты (90+ дней) ===
PS> Get-ADUser -Filter * -Properties LastLogonDate | Where {$_.LastLogonDate -lt (Get-Date).AddDays(-90)} | Measure
Count: 47

# === GPO: Password Policy ===
PS> Get-ADDefaultDomainPasswordPolicy
MinPasswordLength: 8
MaxPasswordAge: 00:00:00 (never)
PasswordHistoryCount: 3
ComplexityEnabled: True
LockoutThreshold: 0
```

### Решение

**Найденные уязвимости:**

| # | Проблема | Severity | Исправление |
|---|----------|----------|-------------|
| 1 | **7 Domain Admins** (слишком много) | HIGH | Оставить 2-3, остальных — в отдельные группы с минимальными правами |
| 2 | **svc_backup в Domain Admins** | CRITICAL | Сервисный аккаунт не должен быть DA! Создать отдельные права |
| 3 | **sql_admin в Domain Admins** | CRITICAL | Аналогично — права только на SQL серверы |
| 4 | **helpdesk.user в Domain Admins** | CRITICAL | Helpdesk никогда не должен быть DA |
| 5 | **svc_backup Kerberoastable + пароль с 2019** | CRITICAL | Kerberoasting → offline brute force → DA. Сменить пароль, использовать gMSA |
| 6 | **svc_sql пароль с 2020, Kerberoastable** | HIGH | Аналогично — gMSA или 120-символьный пароль |
| 7 | **Password Never Expires у 5 аккаунтов** | HIGH | Установить срок действия, ротацию |
| 8 | **old.admin — пароль с 2018, never expires** | CRITICAL | Вероятно заброшенный аккаунт. Отключить |
| 9 | **47 неактивных аккаунтов** | MEDIUM | Отключить все, через 30 дней удалить |
| 10 | **MinPasswordLength: 8** | MEDIUM | Увеличить до 14 |
| 11 | **MaxPasswordAge: never** | HIGH | Установить 90 дней |
| 12 | **LockoutThreshold: 0** | HIGH | Установить 5 попыток (защита от password spraying) |
| 13 | **PasswordHistoryCount: 3** | MEDIUM | Увеличить до 24 |

**Скрипт исправления:**

```powershell
# 1. Удалить лишних из Domain Admins
Remove-ADGroupMember -Identity "Domain Admins" -Members svc_backup,sql_admin,helpdesk.user -Confirm:$false

# 2. Отключить неактивные аккаунты
$inactive = Get-ADUser -Filter * -Properties LastLogonDate |
    Where-Object {$_.LastLogonDate -lt (Get-Date).AddDays(-90) -and $_.Enabled}
$inactive | Disable-ADAccount
$inactive | Set-ADUser -Description "Disabled: inactive 90+ days $(Get-Date -Format yyyy-MM-dd)"

# 3. Обновить Password Policy
Set-ADDefaultDomainPasswordPolicy -Identity corp.local `
    -MinPasswordLength 14 `
    -MaxPasswordAge "90.00:00:00" `
    -PasswordHistoryCount 24 `
    -LockoutThreshold 5 `
    -LockoutDuration "00:30:00" `
    -LockoutObservationWindow "00:30:00"

# 4. Преобразовать сервисные аккаунты в gMSA
New-ADServiceAccount -Name gMSA_SQL -DNSHostName gMSA_SQL.corp.local `
    -PrincipalsAllowedToRetrieveManagedPassword "DB-01$"
```

### Объяснение

Active Directory — главная цель атакующих. Kerberoasting + слабый пароль сервисного аккаунта с правами DA = полная компрометация домена за часы. gMSA (Group Managed Service Accounts) решают проблему — AD сам генерирует и ротирует 120-символьные пароли.
