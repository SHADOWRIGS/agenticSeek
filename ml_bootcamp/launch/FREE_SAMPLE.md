# Бесплатный образец курса

Что открыть бесплатно, зачем именно это и какой текст поставить рядом. Образец — главный аргумент
для аудитории разработчиков: они хотят увидеть материал, а не описание материала.

## Что входит

| Материал | Файлы | Почему он |
|---|---|---|
| Урок 2.1.1 «MultiIndex, сводные таблицы, сложные группировки» | `module_02/topic_2_1/lesson_2_1_1.md`, `sales_data.py` | показывает стандарт курса: каждый приём с реальным выводом, утечка данных продемонстрирована в числах, замеры скорости |
| Практика 2.1.4 «Анализ временных рядов продаж» | `module_02/topic_2_1/lesson_2_1_4.md`, папка `practice/` | показывает главное отличие курса — проект с заготовкой и 24 тестами, которые сами проверяют решение |
| Урок 3.1.2 «Интерпретируемость: коэффициенты, p-value, доверительные интервалы» | `module_03/topic_3_1/lesson_3_1_2.md`, `flats_data.py` | показывает глубину: тема, которую в других курсах дают формулой, здесь проверена экспериментами |

Образец самодостаточен: урок 2.1.1 и практика 2.1.4 проходятся без остальных уроков темы тем, кто знаком
с pandas; для практики желательно прочитать уроки 2.1.2 и 2.1.3, о чём в ней сказано.

Чего в образце нет намеренно: эталонных решений и уроков модуля 1 — он продаётся как отдельный продукт.

## Как опубликовать

Образец должен лежать отдельно от платных материалов — см. решение 1 в
[OWNER_DECISIONS.md](OWNER_DECISIONS.md): пока весь курс находится в публичном репозитории, «бесплатный
образец» ничем не отличается от остального.

1. После переноса курса в приватный репозиторий создать публичный репозиторий-витрину только с файлами
   из таблицы выше и коротким `README.md` (текст ниже).
2. Поставить ссылку на витрину на лендинге — в первом экране и в блоке «Чем курс отличается».
3. В `README.md` витрины — ссылка обратно на лендинг и на страницу оплаты.

## Текст для README витрины

```markdown
# Machine Learning Bootcamp — бесплатный образец

Три материала из курса «Инженер по машинному обучению». Они здесь целиком, без сокращений.

- Урок о группировках и сводных таблицах в pandas — с реальными выводами и замерами.
- Практический проект: анализ продаж сети магазинов. Заготовка кода и 24 теста:
  когда все тесты проходят, проект готов.
- Урок о том, как читать коэффициенты и p-value и когда им нельзя верить.

## Как попробовать за 10 минут

    git clone <адрес витрины> && cd <папка>
    uv init --python 3.12 && uv add pandas numpy pyarrow && uv add --dev pytest
    cd module_02/topic_2_1/practice
    uv run pytest -q

Все тесты упадут — так и задумано. Откройте `sales_analysis.py`: в каждой функции описано, что она должна
делать. Реализуйте первую — и часть тестов станет зелёной.

Программа и условия — <ссылка на лендинг>.
```

## Что измерять

Чтобы понять, работает ли образец, достаточно трёх чисел: сколько человек открыли витрину, сколько из них
перешли на лендинг и сколько купили. Счётчики переходов нужно настроить до публикации — это часть
решения 13 о площадке.
