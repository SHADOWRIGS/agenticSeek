# Оферта и политика конфиденциальности: черновики для юриста

Это **не готовые документы**, а заготовки, с которыми разговор с юристом займёт час вместо нескольких.
Составлены под продажу одного цифрового товара — архива курса «Классический ML для табличных данных» —
физическим лицам за разовый платёж. Публиковать без проверки юристом нельзя (решение 3
в [OWNER_DECISIONS.md](OWNER_DECISIONS.md)).

В квадратных скобках — то, что заполняет владелец. Пометка **[юрист]** стоит там, где формулировка зависит
от формы продавца, площадки или требует профессиональной оценки.

## Что решить до разговора с юристом

| Вопрос | От чего зависит |
|---|---|
| Кто продавец: самозанятый, ИП или ООО | реквизиты в оферте, порядок выдачи чеков, налоги |
| Где принимается оплата | если площадка сама является продавцом для покупателя, часть условий задаёт она, и своя оферта может быть не нужна **[юрист]** |
| Из каких стран покупатели | применимое право, требования к обработке персональных данных |
| Срок возврата и его условия | в текстах курса обещано 14 дней; нужно подтвердить, что это условие продавец готов выполнять |
| Получают ли покупатели обновления | решение 21 |

## Часть 2. Политика конфиденциальности (план)

Полный текст зависит от площадки и страны, поэтому здесь — что в нём должно быть.

| Раздел | Содержание для этого продукта |
|---|---|
| Кто обрабатывает данные | продавец из оферты; контакт для обращений |
| Какие данные | адрес электронной почты; имя, если его запрашивает форма оплаты; сведения о заказе. Данные карт обрабатывает платёжный сервис, продавец их не получает |
| Зачем | передать материалы, выдать чек, ответить на обращение, оформить возврат |
| Рассылка | только с отдельного согласия; отписка в каждом письме |
| Кому передаются | платёжному сервису и площадке — назвать их; почтовому сервису, если используется рассылка |
| Сколько хранятся | назвать срок и основание: например, срок хранения документов об оплате |
| Права человека | узнать, какие данные хранятся; исправить; удалить; отозвать согласие — и куда писать |
| Счётчики на странице | если стоят — назвать, какие и зачем |

**[юрист]**: нужно ли уведомлять надзорный орган об обработке данных и где должны храниться данные
покупателей из выбранных стран.
