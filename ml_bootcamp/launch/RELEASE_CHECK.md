# Проверка архива перед выпуском

Перед загрузкой каждой новой версии архива на площадку — один прогон, который отвечает на вопрос
«работает ли у покупателя то, что мы продаём». Занимает около трёх минут.

## Что проверяется

Скрипт `tools/release_check.py` распаковывает архив продукта и архив эталонных решений и для каждой
практики с тестами pytest проверяет:

1. на заготовке, как её получит покупатель, тесты падают;
2. с эталонным решением все тесты проходят, причём под `-W error` — без предупреждений библиотек.

Важно, что всё запускается **в одном окружении** — так, как курс проходит покупатель: один проект,
в который по ходу уроков добавляются библиотеки. Проверка каждой темы по отдельности этого не ловит.

## Как запустить

```bash
# окружение со всеми библиотеками модулей 1–4
mkdir release_env && cd release_env
uv init --bare --python 3.12
uv add pandas numpy scipy scikit-learn statsmodels pyarrow xgboost lightgbm catboost optuna dash plotly
uv add --dev pytest
cd ..

python3 ml_bootcamp/tools/build_package.py --owner "Имя правообладателя"
uv run --project release_env python ml_bootcamp/tools/release_check.py \
    ml_bootcamp/dist/classic-ml-tabular-1.0.zip путь/к/reference-solutions.zip
```

Архив эталонных решений в репозитории не хранится (решение 2 в [OWNER_DECISIONS.md](OWNER_DECISIONS.md)).

**Что нашла первая проверка.** Плагин Dash для pytest при загрузке вызывает предупреждение, и в общем
окружении строгий запуск тестов `python -W error -m pytest` обрывался во всех практиках — после темы 2.4
ученик не смог бы выполнить критерий приёмки практик 4.3.4 и 4.4.4. Исправлено: в этих практиках
команда дополнена ключом `-p no:dash`, а в уроке 2.4.1 объяснено, откуда берётся ошибка.

## Что эта проверка не покрывает

| Что | Как проверить |
|---|---|
| Практики без pytest: 1.1.4 (проверочный скрипт), 1.3.4 (шаблон проекта), 1.4.4 (тесты на bash) | проверены при приёмке тем; повторять вручную при изменениях |
| Код внутри уроков | проверен при написании; при обновлении библиотек — выборочный повторный запуск |
| macOS и Windows с WSL | один сквозной прогон модуля 1 человеком — до продаж |
