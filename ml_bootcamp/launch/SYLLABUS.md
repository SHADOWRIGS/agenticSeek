# Программа курса: цель и результат каждого урока

Machine Learning Bootcamp — 11 модулей, 43 темы, 172 урока (129 теоретических и 43 практических проекта).

В каждой теме три теоретических урока и один практический проект. «Цель» — чему учит урок, «Результат» —
что ученик умеет или что у него есть после урока. Для практик результат — готовый артефакт в портфолио.

Статус готовности материалов — в [оглавлении курса](../README.md).
