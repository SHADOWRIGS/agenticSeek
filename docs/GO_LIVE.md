# GO-LIVE — что сделать владельцу, чтобы пошли деньги

Фабрика готовит материалы сама. Деньги включаются после этих разовых шагов.
Порядок — от самого быстрого к деньгам. Галочки ставь по мере готовности.

---

## Трек A — Приём оплаты (основа, ~10 мин) ⬜

**Gumroad** — проще всего: хостинг продукта + оплата картой в одном месте.
1. ⬜ Зайди на **gumroad.com** → Sign up (почта или Google).
2. ⬜ Settings → **Payments** → подключи выплату (PayPal — работает в Израиле; или банк через Stripe).
3. ⬜ Settings → заполни профиль (имя продавца, страна).
4. ⬜ Готово. Создавать продукты будем позже — файлы курсов я подготовлю.

_Альтернатива: Stripe (stripe.com) — если хочешь свой лендинг и приём карт напрямую. Дольше, но гибче._

**Что прислать мне:** просто напиши «Gumroad готов» (ссылку на продукт сделаем вместе).

---

## Трек B — Реферальный бизнес AliExpress (быстрее всего к первым $) ⬜

1. ⬜ Партнёрка: зарегистрируйся в одной из —
   - **ePN** (epn.bz) или **Admitad** — проще для новичка, есть генератор ссылок;
   - либо **AliExpress Portals** (portals.aliexpress.com) напрямую.
2. ⬜ Подтверди аккаунт, найди **генератор партнёрских ссылок (deeplink)**.
3. ⬜ Создай **Telegram-канал**: Telegram → новое → «Канал» → название → публичный, задай @username.
4. ⬜ (Опц.) Привяжи аккаунты TikTok/YouTube Shorts для видео-трафика.

**Что прислать мне:**
- @username твоего Telegram-канала;
- доступ к генератору ссылок есть (да/нет) — тогда я дам список точных товаров, ты вставишь свои партнёрские ссылки, а я соберу готовые посты.

---

## Трек C — Курсы на продажу (ML + этичный хакинг) ⬜

1. ⬜ Реши площадку: **Gumroad** (из трека A, быстро) или **Teachable** (teachable.com, если нужен «полноценный» курс с уроками-видео).
2. ⬜ Как Gumroad готов — я дам: готовый файл курса (PDF/архив), текст-описание, цену, картинку-обложку. Ты жмёшь Create product → загружаешь → Publish.

**Что прислать мне:** выбор площадки (Gumroad / Teachable).

---

## После go-live

Как только есть оплата + канал + ссылки — фабрика замыкается:
генерит → ты публикуешь (или планировщик) → приходят продажи → аналитик
оптимизирует. Я подготовлю первую партию материалов заранее, чтобы в день
запуска только вставить ссылки и нажать «опубликовать».
